# Host capability contract drafts

Status: **provider proposal only**; not part of `zicode.devtools-plugin/1.0.0-rc.1`, not implemented by Studio, and not advertised by any plugin manifest.

`schemas/` contains five proposed request/response/event envelopes for `service.v1` and `desktop.v1`; `examples/` illustrates normal and denied calls. Host derives plugin and scene identities from the authenticated View and injects request IDs; these values are deliberately absent from provider request bodies.

Draft constraints: current Agent goal at most 2 KiB of UTF-8 bytes, session materials at most 32 items/32 KiB aggregate UTF-8 bytes. JSON Schema `maxLength` is only a character-count guard; the Host must enforce these byte limits before dispatch. The explicit `x-host-utf8-*` schema annotations document those runtime checks. Model-consent and clipboard-gesture IDs are opaque references only: Studio must issue them from trusted user interaction, consume them once, and bind them to plugin, scene, operation, and permission generation; a provider-supplied string never proves consent. MCP read-only calls require one-shot Host consent and at most four calls per run. Their argument digest is proposed as SHA-256 over UTF-8 bytes of an [RFC 8785 JCS](https://www.rfc-editor.org/rfc/rfc8785) canonical argument value; this is still a provider proposal requiring Studio review. Clipboard subscriptions are Windows-first, per-format and revocable; file/image bodies are opaque resource handles, OCR runs in the Host, and non-Windows platforms remain unsupported until separately implemented and tested. `plugin-market`, `plugin-updates`, and Explorer registration remain Host-owned.

The examples and vectors are illustrative provider-side evidence, not executable Studio acceptance evidence. The draft guard checks UTF-8 byte-budget and token-binding scenarios structurally, but is not a JSON Schema engine or Host conformance test. Before use, Studio must version and freeze an agreed schema, implement Host callbacks, validate every fixture with its contract validator, and run the conformance and lifecycle tests.
