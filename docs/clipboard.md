# 超级剪贴板0.1.0（开发中）

程序0.82.0-dev.24。工具搜索“剪贴板”“连续复制”或统一前缀后V进入。默认不采集；点击开启后监听Windows剪贴板新变化，只读取文本。已有剪贴板不会主动导入，其他格式跳过；占用/无效/超限显示错误，极快事件可能遗漏。

历史仅存于本次程序内存，退出清空，不写盘、不联网。隐藏到托盘仍采集；私密暂停不补采，关闭采集保留会话历史直到退出。应用排除尚未完成，复制敏感内容前可暂停。来源只显示应用文件名，可显示未知，不保证识别所有密码或来源。

文本按内容去重，更新复制时间与来源，保留ID及置顶状态。最多500条、单条1 MiB、总文本32 MiB；超出时淘汰最旧非置顶内容，全部置顶导致不足时拒绝新增并提示。置顶条目优先显示，删除/确认清空可主动释放内存。

按勾选先后组合为段落、编号、JSON数组或CSV单列，先看预览，再复制。CSV对可能的公式加单引号，原文不变；输出上限1 MiB。复制会替换系统当前剪贴板，本工具输出不回流采集，外部应用重新复制相同内容仍更新历史。关闭采集后复制使用原有UI剪贴板出口。

组合结果可通过现有接力入口发送到备忘草稿、数据工作台和其他文本工具，沿用目标输入保护及预览；不自动执行目标、不自动保存草稿。示例按钮追加合成示例，不读取系统剪贴板，不清空原有历史。

## 边界与后续

当前只实现文本会话历史闭环。主动开启本机持久化与Windows用户保护、保留期、应用排除、标签/分组、图片/富文本/文件引用、模板变量、自动粘贴和完整来源链仍待开发。不能宣传为已完备，也不声称功能为市场独有。

通知与内存读写须有Windows独立窗口站的隔离验证；若创建不支持，明确记录未验，不回退测试到用户剪贴板。深浅UI仅使用合成示例截图。

本机隔离窗口站创建返回访问拒绝（5），测试在访问任何剪贴板前停止；不回退到交互剪贴板。公开Windows CI另外运行同一隔离夹具，结果单独记录。
