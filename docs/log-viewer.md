# 日志工作台

日志工作台用于在本机只读浏览普通日志文本，适合 Java/Django 服务日志、构建输出和应用诊断记录。入口由工具库和全局启动器提供。

## 当前能力

- 选择普通文件后在后台扫描，不递归目录、不跟随文件符号链接；可以取消扫描。
- 按行流式读取并将时间戳行、非缩进行识别为新事件，将缩进、`at ...`、`Caused by:`、`Suppressed:` 等行归并为多行事件。
- 尝试识别 `FATAL/CRITICAL`、`ERROR/ERR`、`WARN/WARNING`、`INFO`、`DEBUG`、`TRACE` 级别；未知级别单独筛选。
- 每页加载最多 100 条事件，支持按级别过滤和定位到指定时间及之后的第一条已识别时间戳事件。
- 支持对已索引事件正文做区分大小写的 UTF-8 字节子串搜索。后台按 64 KiB 块读取，可取消；查询最长 256 字节。结果仍可与级别筛选、分页和时间定位组合。
- 扫描最多建立 500,000 条事件索引；每行索引前缀不超过 4 KiB，每条事件界面预览不超过 16 KiB。超大文件和超长行不会整体读入内存。
- 索引前后复核文件类型、文件身份、大小及修改时间；发现源文件变化时拒绝按旧索引显示正文，需重新索引。
- 仅将当前页事件暂存在内存，不写入源文件，不持久化索引或日志正文。

## 当前限制

时间格式固定为 `YYYY-MM-DD HH:MM:SS` 或 `YYYY-MM-DDTHH:MM:SS`；尚不支持时区、毫秒和自定义格式。正文搜索区分大小写，按 UTF-8 字节匹配，不做 Unicode 规范化或忽略大小写。多行事件按通用启发式归并，尚未提供日志格式模板、JSON 字段过滤、日志轮转跟踪或尾随实时刷新。索引达到 500,000 条后显示已扫描部分，不自动继续加载后续片段。二进制文件没有专门识别器，非法 UTF-8 字节在预览中使用替换字符呈现。

真实生产日志规模、原生文件选择器、高 DPI 和各类应用格式仍需实际使用验收；当前工具目录状态保持“进行中”。
