# 工具访问与导航（v0.78.0）

本轮实现整体评审的第一部分：稳定主导航、统一目录与按用途搜索。数据实例已继续接入，见工作实例说明；跨工具项目空间、通用结果对象和授权写入仍按清单推进。

## 从哪里开始

- **开始**：搜索、从文件开始、常用收藏、最近使用、按用途浏览。
- **工具库**：内置工具与已启用插件的连续列表，支持全部/收藏/最近/常用和分类。列表按可见行渲染，不再同时要求翻页和页内滚动。
- **后台任务**：查看已接入工具的运行状态、取消任务并返回所属工具。目录扫描、复制预览和执行复制已接入，切换页面后仍可收取结果；取消复制保留已完成文件。其他工具尚未全部接入。
- **扩展与连接器**：插件安装、启用、连接设置与模型等能力；插件启用后自动进入相同工具目录。

侧栏最多显示六个已收藏的工具；更多收藏可从“全部收藏”访问。专业工作台保留原有界面，通过工具库、分类、搜索、收藏和托盘打开。当前工作台提供返回工具库和浏览同类工具；返回保留库内查询及筛选，不把查询词带进工作台内部的工具筛选。

侧栏顶部品牌与搜索固定，中部主导航 / 收藏列表独立滚动并保留滚动条；“当前工作台”、返回工具库、同类工具以及底部主题 / 托盘 / 设置固定在下方。在支持的最小 980×640 逻辑窗口中，无需先滚到底就能返回或进入设置。较长工具名省略显示，悬停查看完整标题。快捷访问增加“常用排行”，直接打开按使用频次排序的工具库；工具库与快捷面板的常用顺序一致：使用频次高的在前，频次相同时最近使用的在前，仍相同时保持目录原有的稳定顺序。收藏、最近、常用仍是不同入口。

“最近使用”目前仍是最近的工具入口。开始页另有“继续数据工作”，可回到本次运行的数据实例，或打开主动保存的快照；范围见[数据工作实例](work-instances.md)。入口共享同一工作台时，按所选入口记录一次访问，不用另一个通用入口替代，也不重复增加次数。

## 搜索

应用内使用 Ctrl K；系统全局热键和托盘面板继续可用。输入名称或用途，例如“压缩图片”“合并表格”“时间戳转换”，也可以多个词组合查询。全角英文、大小写和空白会规范化。

目录包含明确维护的用途与别名，部分常用项包括拼音或首字母，例如 `luping`、`sjc`；这不是通用拼音引擎或自然语言理解。对 4–32 字符的单个英文/数字词支持一次编辑或相邻换位的拼写纠正；长句和多词查询不会模糊放宽。结果显示用途说明、匹配原因以及开发中标记。

相关程度优先于收藏、最近和使用次数。在收藏、最近或常用范围内搜索也遵守这一规则；清空查询后恢复该视图的收藏顺序、访问时间或使用频次排序。精确匹配优先于近似匹配；同为近似结果时，名称匹配优先于说明中的近似词；同分排序稳定。Enter 打开当前结果，方向键移动，Esc 关闭；打开不会直接执行转换、网络请求或写入。停用插件不会继续出现在可用结果中，原收藏 ID 保留。

## 目录与代码维护

工具库每个条目的“版本”菜单显示当前独立工具版本和按时间倒序排列的变更记录；长历史可在菜单内滚动。插件未声明独立版本历史时明确提示，不继承插件包版本。

`docs/tools.json` 中的 `discovery` 是已接入入口的名称、简短说明、领域、关键词和别名来源。原 `category` 保留历史文档统计口径，实际浏览分类使用 `discovery.category`，两者不混用。规划条目不需要 discovery，也不会自动出现在可运行目录。

目录同步检查要求每个已接入路由（包含开发中的部分可用工具）至少声明两个规范化后不重复的搜索别名，以及非空关键词；不同内置路由之间的稳定 ID、显示名称和别名也不能共享规范化后的完全相同词项，避免一个精确搜索词指向多个工具。缺少这些信息会阻止清单同步，避免可用入口只靠内部 ID 才能找到。

`src/app/registry.rs` 将稳定 ID 绑定到实际 Rust 页面/工具；只有明确注册的路由进入目录。内置描述在进程中只解析一次，搜索文本预先规范化。插件清单仍沿用 V1，通过同一评分接口参与检索。插件生成的搜索目录项按包 ID、清单摘要和启用状态缓存；插件增删改、升级或启停后重建。每次查询仍使用当前搜索词和偏好重新匹配/排序。启用的插件若与其他入口共用精确名称或别名，会在命中的搜索结果中提示“同词还有其他入口”；不会静默隐藏结果或自动替用户选择。托盘原生菜单没有查询词可用于提示匹配数，因此重复标题会在“全部工具”、收藏、最近和常用列表中附加分类，分类仍相同则附加稳定工具 ID；重名检测按 NFKC、大小写和空白规范化，并且长标题最多显示 36 个字符且保留末尾分类或 ID。

修改目录后运行 `python scripts/sync_tools.py` 与 `--check`。Rust 测试核对实际路由、状态、分类和描述完整性；脚本检查文档生成与声明 ID。运行时不依赖外部的可编辑清单文件，也不会通过文本描述执行代码。

## 工具集合（v0.1.0 开发中）

工具库提供自定义集合筛选；输入名称即可新建，选择集合后可重命名或经确认删除。每个工具行的“集合”菜单可加入或移除入口。集合只保存稳定工具 ID 与加入顺序，不复制工具数据；打开工具仍走原有注册路由。已停用或暂不可用的 ID 会保留在集合中，工具恢复可用后重新出现。

全局快捷面板新增“集合”页签，可选集合并搜索其中的工具；方向键和 Enter 仍按普通工具结果使用。集合保存在本机 UI 偏好文件。多窗口保存按集合 ID 合并不同集合，以及相同集合里独立添加/移除的工具；同一集合名称的并发修改以最后保存为准，集合被一窗口删除后，另一个窗口的陈旧修改不会恢复它。

工具集合 v0.3.0 支持集合文件的预览导入与导出、冲突改名和未知工具 ID 保留，并支持在工具库拖动调整顺序；并发成员变化会合并，搜索仍按匹配相关度排序。设备间自动同步和工作区级配置迁移仍规划。集合不是访问控制或执行流程，不会因为加入工具就自动运行它。

Rust 回归测试覆盖常见用途/别名/中英混合/拼写查询、精确结果与收藏优先级、300 条合成注册信息及实际入口路由；新增全目录精确词用例逐一检查已接入工具的稳定 ID、显示名称和每个别名是否把所属工具排在首位。300 条注册信息测试不等于 100 个重型工作台并发性能或真实用户可用性测试。键盘/导航与截图使用无凭据合成夹具；数据实例的主动保存和恢复已继续接入，验证见工作实例说明；通用文件修改及 Agent 写入仍待后续实现与验收。

## 结果接力的目标查找（v0.80.0-dev.4）

“发送结果到工具…”的目标搜索复用同一工具目录里的名称、别名、分类、关键词与用途，支持 Unicode 兼容字符规范化、多词过滤和已有单词近似拼写；按匹配程度排序，CSV/TSV及对比左右侧优先匹配具体入口。分类可单独筛选，目标数量和空结果有明确提示。搜索或切分类不替用户更换已选目标，下方继续显示当前选择。

没有搜索词时显示最多三个推荐目标和原因。仅在打开接力窗口时对最多128 KiB正文做一次JSON识别：非空、全为对象、最多10000行且列并集1–128列的数组推荐新数据实例；其他合法JSON推荐格式化。较小文本可推荐备忘/日程草稿，超过128 KiB只提示文本对比；CSV/TSV推荐使用目标解析器的有界检查，详见下文；不从来源名称或大正文推断格式。

推荐只改变列表展示。点击推荐项只选中目标，仍需明确点击底部应用按钮；新数据实例为默认，原材料和旧数据工作保留。格式验证与解析错误仍由目标工具报告，推荐不保证处理成功。目标搜索缓存相同查询与分类的匹配列表，不每帧重做目录评分。

接力只显示已实现的接收路由；除文本小工具、数据格式、对比、备忘和日程外，已逐步接入离线诊断、资料草稿、知识收集、Agent资料、计算器与类型化流程。可用目标仍取决于本次材料类型，不将未接入的插件或工作台伪装成可接收目标。

## 从结果继续处理表格

统一结果接力会对不超过128 KiB的文本快照检查CSV和TSV候选，复用数据工作台的表头、列数、行数和行宽规则；至少两列且有一行数据才推荐。分隔符两种解释都成立时不推荐，不改变默认目标或原始内容。建议不是自动执行：先选择推荐目标，再确认；默认新建数据实例，保留已有草稿和导出。确认后进行本地表格解析预览，不保存文件或上传数据。超过建议预算的内容仍可以手动选择目标，接收上限沿用原工具规则。

接力弹窗重新打开时正文与目标列表回到顶部；改变搜索词或分类时，目标列表回顶并停止旧滚动动画/惯性。普通重绘、选中目标和等价规范化搜索不会强制回顶。筛选不自动改变已选目标，确认目标仍明确显示在底部。


接力目标增加“全部 / 收藏 / 最近 / 常用”范围，沿用打开弹窗时工具库的偏好快照。收藏按用户顺序，最近按工具访问顺序，常用按次数并以最近访问破同分；有搜索词时优先保持相关度。多个格式或左右侧入口仍独立显示，不把工具级最近记录解释为某个格式的使用历史。个人范围不把推荐插到前面；未接入或材料不兼容的收藏不会显示。清除筛选可回到全部，当前选择保留在确认区；浏览筛选不会记录访问、改正文或执行目标动作。


接力接收成功后按真实目标的目录ID登记一次访问；文本流程和同类诊断共用页面时也不会借用该页面第一个通用工具。接收失败、取消与筛选不登记访问。重开或筛选回顶后，接力会消费框架残留的平滑滚轮输出，直到新的真实滚轮输入恢复正常滚动；不会重置键盘和指针状态。


接力每次打开会聚焦搜索框，可直接输入关键词；Ctrl+K在弹窗内返回搜索，不打开全局工具搜索。Tab可移走焦点，后续重绘不抢回。分类下拉框打开时第一次Esc只关闭下拉框，第二次Esc取消接力。搜索框中的Enter或Ctrl+Enter不自动接收；确认仍需明确激活底部按钮。


多词查询在每个词都命中的前提下，优先展示名称或ID加上下文、名称词组合和别名加上下文，再展示仅历史说明或普通关键词命中的工具。比如“JSON 工具”优先显示JSON；附加不存在的词仍无结果。完整名称/别名、版本号和单词拼写规则不变，收藏与最近记录不越过相关度等级。混合命中显示“名称与关键词匹配”或“别名与关键词匹配”。


接力搜索框聚焦时可用↑↓按显示顺序选择目标，首次↓从首项、首次↑从末项开始，边界不回绕；所选行自动滚动到可见位置。选择后Tab直达确认按钮，仍须明确激活按钮才接收。筛选或空结果保留已选目标，新的方向键从新列表开始；IME组合中不接管导航，Shift+Tab保持常规逆向控件访问。


共用图片页面的单张转换、批量、元数据、裁剪标注、截图和图片流程现在按工具稳定ID选择实际视图。从搜索、工具库、收藏或公共启动入口重新打开“图片工作台”会明确回到单张图片，而不是保留上次的裁剪等视图。打开入口只切换视图，不自动转换、读取或保存；已有原图、编码结果和转换参数保留。


主窗口搜索与托盘快捷面板会在输入法组合及提交/停用同帧把方向键、Enter、Esc留给输入法，避免选词时关闭或打开工具；只有未加修饰键的方向键/Enter/Esc用于结果导航，Shift等按键保留文本编辑行为。仅开启输入法但尚未开始组合不会长期禁用搜索快捷键。


## 后退与前进

固定侧栏按钮和Alt+←/Alt+→在本次运行内返回工具与工作实例，悬停显示目标名称。最多记录64个位置；在同一工具中输入或编辑不会重复加入历史，后退后打开新位置会替换前进分支。工具库每次访问分别保留查询、分类/集合及滚动位置。

数据工作台和图片流程按实例ID恢复，关闭的实例和停用/卸载的插件自动跳过，不恢复文件或重新创建草稿。OCR/文档导入、MCP服务/导出等共页入口保留实际入口身份。返回不会重跑接力解析、改变录屏音频设置、停止后台任务或保存数据；插件切换仍遵守既有清除临时凭据规则。

全局搜索/快捷面板、接力、退出或清空确认、数据保存/恢复和审核、图片流程导入/关闭审核、截图/录屏选区及弹出菜单期间不执行历史跳转；输入法组合与提交同帧也不接管Alt方向键。历史仅保存导航标识与工具库查询上下文，不保存文档正文、结果、账号凭据或数据文件；重启后清空。Windows实际输入法和多显示器的实机兼容性按后续验收记录追踪。

## 查找当前工作实例

Ctrl K的“工作实例”范围（Ctrl 5）和快捷面板同名页签可按名称、数据或图片查找当前已打开的实例；“全部”搜索也包含这些结果。名称相关度优先，同等相关度按本次会话最近访问排列，未访问项保持创建顺序。结果显示实际视图、运行/待确认状态及当前实例；同类同名实例额外显示短标识。长名称截断，悬停可查看完整内容。

打开只切换到目标的当前视图，保留输入、结果和后台任务，并进入后退/前进历史。结果改名或消失时按稳定ID维护选择；原选中项不再匹配后，需用方向键或鼠标重新选择，Enter不会打开占据原行的新结果。搜索和确认之间再次检查实例是否仍存在及审核状态，失败保留当前工作。

仅搜索当前进程的实例名称和工具元数据，不搜索材料正文、不读取文件或已保存快照；未打开的保存项仍从“已保存实例”恢复。数据16份、图片流程8份的现有限额不变。输入法组合或没有有效目标时，Enter不会使搜索框失去焦点；指针引起的焦点切换保留正常行为。原生预检使用受控egui事件及内嵌快捷面板，独立子窗口、真实Windows输入法、多屏及混合DPI兼容性另行验证。
