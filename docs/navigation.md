# 工具访问与导航（v0.78.0）

本轮实现整体评审的第一部分：稳定主导航、统一目录与按用途搜索。数据实例已继续接入，见工作实例说明；跨工具项目空间、通用结果对象和授权写入仍按清单推进。

## 从哪里开始

- **开始**：搜索、从文件开始、常用收藏、最近使用、按用途浏览。
- **工具库**：内置工具与已启用插件的连续列表，支持全部/收藏/最近/常用和分类。列表按可见行渲染，不再同时要求翻页和页内滚动。
- **后台任务**：现有数据解析、合并、文件校验状态。其他工具尚未全部接入，不能据此声称已经统一后台运行。
- **扩展与连接器**：插件安装、启用、连接设置与模型等能力；插件启用后自动进入相同工具目录。

侧栏最多显示六个已收藏的工具；更多收藏可从“全部收藏”访问。专业工作台保留原有界面，通过工具库、分类、搜索、收藏和托盘打开。当前工作台提供返回工具库和浏览同类工具；返回保留库内查询及筛选，不把查询词带进工作台内部的工具筛选。

侧栏顶部品牌与搜索固定，中部主导航 / 收藏列表独立滚动并保留滚动条；“当前工作台”、返回工具库、同类工具以及底部主题 / 托盘 / 设置固定在下方。在支持的最小 980×640 逻辑窗口中，无需先滚到底就能返回或进入设置。较长工具名省略显示，悬停查看完整标题。快捷访问增加“常用排行”，直接打开按使用频次排序的工具库；收藏、最近、常用仍是不同入口。

“最近使用”目前仍是最近的工具入口。开始页另有“继续数据工作”，可回到本次运行的数据实例，或打开主动保存的快照；范围见[数据工作实例](work-instances.md)。入口共享同一工作台时，按所选入口记录一次访问，不用另一个通用入口替代，也不重复增加次数。

## 搜索

应用内使用 Ctrl K；系统全局热键和托盘面板继续可用。输入名称或用途，例如“压缩图片”“合并表格”“时间戳转换”，也可以多个词组合查询。全角英文、大小写和空白会规范化。

目录包含明确维护的用途与别名，部分常用项包括拼音或首字母，例如 `luping`、`sjc`；这不是通用拼音引擎或自然语言理解。对 4–32 字符的单个英文/数字词支持一次编辑或相邻换位的拼写纠正；长句和多词查询不会模糊放宽。结果显示用途说明、匹配原因以及开发中标记。

相关程度优先于收藏、最近和使用次数。在收藏、最近或常用范围内搜索也遵守这一规则；清空查询后恢复该视图的收藏顺序、访问时间或使用频次排序。精确匹配优先于近似匹配；同为近似结果时，名称匹配优先于说明中的近似词；同分排序稳定。Enter 打开当前结果，方向键移动，Esc 关闭；打开不会直接执行转换、网络请求或写入。停用插件不会继续出现在可用结果中，原收藏 ID 保留。

## 目录与代码维护

`docs/tools.json` 中的 `discovery` 是已接入入口的名称、简短说明、领域、关键词和别名来源。原 `category` 保留历史文档统计口径，实际浏览分类使用 `discovery.category`，两者不混用。规划条目不需要 discovery，也不会自动出现在可运行目录。

`src/app/registry.rs` 将稳定 ID 绑定到实际 Rust 页面/工具；只有明确注册的路由进入目录。内置描述在进程中只解析一次，搜索文本预先规范化。插件清单仍沿用 V1，通过同一评分接口参与检索。

修改目录后运行 `python scripts/sync_tools.py` 与 `--check`。Rust 测试核对实际路由、状态、分类和描述完整性；脚本检查文档生成与声明 ID。运行时不依赖外部的可编辑清单文件，也不会通过文本描述执行代码。

验证包括 34 条用途/别名/中英混合/拼写查询、精确结果与收藏优先级、300 条合成注册信息及实际入口路由。300 条注册信息测试不等于 100 个重型工作台并发性能或真实用户可用性测试。键盘/导航与截图使用无凭据合成夹具；数据实例的主动保存和恢复已继续接入，验证见工作实例说明；通用文件修改及 Agent 写入仍待后续实现与验收。

## 结果接力的目标查找（v0.80.0-dev.4）

“发送结果到工具…”的目标搜索复用同一工具目录里的名称、别名、分类、关键词与用途，支持 Unicode 兼容字符规范化、多词过滤和已有单词近似拼写；按匹配程度排序，CSV/TSV及对比左右侧优先匹配具体入口。分类可单独筛选，目标数量和空结果有明确提示。搜索或切分类不替用户更换已选目标，下方继续显示当前选择。

没有搜索词时显示最多三个推荐目标和原因。仅在打开接力窗口时对最多128 KiB正文做一次JSON识别：非空、全为对象、最多10000行且列并集1–128列的数组推荐新数据实例；其他合法JSON推荐格式化。较小文本可推荐备忘/日程草稿，超过128 KiB只提示文本对比；不猜测CSV/TSV，不从来源名称或大正文推断格式。

推荐只改变列表展示。点击推荐项只选中目标，仍需明确点击底部应用按钮；新数据实例为默认，原材料和旧数据工作保留。格式验证与解析错误仍由目标工具报告，推荐不保证处理成功。目标搜索缓存相同查询与分类的匹配列表，不每帧重做目录评分。

接力目标仅涵盖已经接入的文本小工具、数据格式入口、文本对比、备忘和日程；不将未接入的插件/工作台展示为可接收目标。可组合管线、类型化长期结果与配方继续规划。
