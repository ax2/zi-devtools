# SHA256SUMS 校验清单

从侧栏“校验清单”、工具首页搜索或收藏进入。生成时选择同一目录内 1–64 个普通文件，后台流式计算 SHA-256；检查预览后填写新路径保存。每行采用 `64 位十六进制摘要 + 两个空格 + 文件名`，与常见 SHA256SUMS 格式兼容。原文件不修改，已有清单不覆盖。

验证时选择不超过 32 KiB 的 UTF-8 清单。程序仅在清单所在目录查找列出的普通文件，逐项标记匹配、缺失、摘要不匹配或读取失败。为避免清单读取任意位置，条目不能包含路径分隔符、冒号、控制字符或重复文件名；符号链接不跟随。空清单、格式错误或超过 64 项会拒绝。运行期间可取消，取消后不会保存清单。

摘要用于检查文件内容是否与清单一致。若清单本身来自不可信来源，匹配不代表来源可信或软件已签名。
