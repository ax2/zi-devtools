# 全能计算器（开发中）

程序开发版 0.82.0-dev.4；独立工具版本见工具清单。目前提供基础计算闭环，不代表矩阵/绘图等完整规划已完成。

在工具库搜索“计算器”，或系统前缀（默认 Ctrl+Alt+Space）后松开修饰键按 C。输入时实时预览，Enter 或“固定结果”写入本次历史并更新 ans；复制结果不改变变量。变量赋值也先预览，例如 `price = 19.90`，固定后再输入 `price * 3`。历史最多 100 条、变量最多 64 个（含 ans），仅在当前进程内存保留；清空历史不会清空变量，变量可单独清空。

| 示例 | 结果 / 含义 |
| --- | --- |
| `0.1 + 0.2` | 精确 0.3 |
| `1/3` | 精确最简分数 1/3 |
| `-2^2` / `2^3^2` | -4 / 512；幂右结合 |
| `sin(30)` | DEG 模式约 0.5；RAD 是不同含义 |
| `0xff & 0x0f` | 15，同时显示其它进制 |
| `5 km -> m` | 5000 |
| `25 C -> F` | 77；温度含偏移 |
| `1 GiB -> MB` | 1073.741824；二进制/十进制单位明确区分 |

运算符：`+ - * / ^ % & | << >> ~`。位运算要求精确整数，用有符号 128 位补码；右移补符号位，左移丢弃高位。支持 0x/0o/0b 与科学计数法。需要显式乘号，不支持 `2pi` 这样的隐式乘法。

函数：sin/cos/tan/sqrt/ln/log10/exp/abs/floor/ceil/round/min/max/xor，常量 pi/e。科学函数使用 f64，结果标 `≈`，很小/很大值用科学计数法显示；精确算式使用约分后的 i128 有理数，超出范围报错，不悄悄改为近似值。精确幂的整数指数限 -128–128，非整数幂为近似值。

单位区分大小写：长度 mm/cm/m/km/in/ft/mi；质量 mg/g/kg/lb；时长 ms/s/min/h/day（day 固定 86400 秒，不是日历日）；存储 B/KB/MB/GB/KiB/MiB/GiB；温度 C/F/K。表达式末尾用 `来源单位 -> 目标单位`，维度不一致拒绝转换；单位不是可自由参与乘除的代数对象。

表达式最多 2048 字节、512 个词元、64 层嵌套；不运行脚本、不访问文件或网络。定义域、零除、整数范围错误显示在结果区；错误固定操作不改写 ans、变量或历史。

后续：任意精度大整数、矩阵/复数/方程与绘图、日期时间、可选持久历史和工作表、通用结果接力。当前版本不能称为完整 CAS 或替代专业计算软件。
