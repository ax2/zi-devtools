# 全能计算器（开发中）

程序开发版 0.82.0-dev.52；独立工具版本见工具清单。独立工具0.9.0新增日期与工作日，0.8.0新增接收区域统计，0.7.0新增统计与组合计算，0.6.0新增函数绘图与采样接力，0.5.1完善大快照接收的固定操作区域，0.5.0新增视图数值映射和矩阵A/B接收，0.4.0新增数值类型双向接力，0.3.0新增可另存和恢复的工作表，0.2.0新增矩阵与线性方程工作区；完整规划继续开发。

在工具库搜索“计算器”，或系统前缀（默认 Ctrl+Alt+Space）后松开修饰键按 C。输入时实时预览，Enter 或“固定结果”写入本次历史并更新 ans；复制结果不改变变量。变量赋值也先预览，例如 `price = 19.90`，固定后再输入 `price * 3`。历史最多 100 条、变量最多 64 个（含 ans），默认在当前进程内存保留，可主动另存工作表；清空历史不会清空变量，变量可单独清空。

| 示例 | 结果 / 含义 |
| --- | --- |
| `0.1 + 0.2` | 精确 0.3 |
| `1/3` | 精确最简分数 1/3 |
| `-2^2` / `2^3^2` | -4 / 512；幂右结合 |
| `sin(30)` | DEG 模式约 0.5；RAD 是不同含义 |
| `0xff & 0x0f` | 15，同时显示其它进制 |
| `5 km -> m` | 5000 |
| `25 C -> F` | 77；温度含偏移 |
| `1 GiB -> MB` | 1073.741824；二进制/十进制单位明确区分 |

运算符：`+ - * / ^ % & | << >> ~`。位运算要求精确整数，用有符号 128 位补码；右移补符号位，左移丢弃高位。支持 0x/0o/0b 与科学计数法。需要显式乘号，不支持 `2pi` 这样的隐式乘法。

函数：sin/cos/tan/sqrt/ln/log10/exp/abs/floor/ceil/round/min/max/xor，常量 pi/e。科学函数使用 f64，结果标 `≈`，很小/很大值用科学计数法显示；精确算式使用约分后的 i128 有理数，超出范围报错，不悄悄改为近似值。精确幂的整数指数限 -128–128，非整数幂为近似值。

单位区分大小写：长度 mm/cm/m/km/in/ft/mi；质量 mg/g/kg/lb；时长 ms/s/min/h/day（day 固定 86400 秒，不是日历日）；存储 B/KB/MB/GB/KiB/MiB/GiB；温度 C/F/K。表达式末尾用 `来源单位 -> 目标单位`，维度不一致拒绝转换；单位不是可自由参与乘除的代数对象。

表达式最多 2048 字节、512 个词元、64 层嵌套；不运行脚本、不访问文件或网络。定义域、零除、整数范围错误显示在结果区；错误固定操作不改写 ans、变量或历史。

后续：任意精度大整数、复数/非线性方程和高级绘图、时区与日期时间换算、原文件更新、通用结果接力。当前版本不能称为完整 CAS 或替代专业计算软件。

## 矩阵与线性方程（0.2.0）

切换到“矩阵与线性方程”，选择操作并设置A/B行列数，每轴1–8。单元格支持同样的表达式、现有变量及当前RAD/DEG，例如 `1/3` 或 `price`；不执行赋值。每格512字节、参与的所有单元格总16KiB。默认单位矩阵A和单列B；“载入方程示例”提供需要交换主元行的三元、两组右端方程。每个矩阵可展开“批量粘贴TSV”，粘贴制表符/换行数据，预览识别行列数并确认应用；空格、空单元格及不齐行不能冒充完整表格。应用后仍须显式计算。点击“计算矩阵结果”，不是逐帧求逆。

支持同维加减、矩形乘法、转置、方阵行列式/逆以及AX=B。B可为多列，各列是一个右端；结果各列是对应唯一解。奇异A明确拒绝唯一解/逆，不猜测欠定解；维度不符、单元格未知变量、零除或精确范围溢出会指出错误，不覆盖ans或变量。

精确单元格沿用i128有理数，超范围报错。含科学函数的近似值保留≈标识；浮点消元采用按绝对值选择主元，未估计条件数，不能作为病态数值问题的误差保证。修改输入、操作、已有变量或角度后显示“上次结果”，重新计算前禁止复制；派生结果仅在内存，不自动写文件；工作表快照保存输入，恢复后须重新计算。

“复制结果TSV”用制表符分列、换行分行，可贴到表格软件或CSV/JSON工作台。近似值输出当前12位显示精度并去除≈，复制前留意精度说明；最简分数保持1/3形式，不假装小数精确。复数、非线性方程/符号CAS、高级绘图、任意精度、原文件更新和更多工具间的类型协议仍未完成。

## 工作表快照（0.3.0）

点击“另存工作表”选择新的.json文件。界面显示保存范围：名称、当前表达式、RAD/DEG、视图、变量/ans、最多100条历史，以及A/B维度、64格内容和TSV粘贴草稿。默认不写文件、不自动加载最近路径。文件是明文JSON，最多1MiB；分子的i128与正分母用规范十进制字符串，近似f64用独立类型的完整科学计数法字符串，保持正负零/最小非零浮点等位值，不采用12位显示结果。

写入在后台，先同目录暂存、同步，再无覆盖发布，需NTFS等支持硬链接的文件系统；不支持时明确失败，不以部分文件冒充成功。已有文件、数据流/设备名或不明链接位置拒绝。该功能为快照另存，尚不支持覆盖更新原文件。保存捕获开始时的工作，之后继续编辑的内容仍标未保存；保存失败保留旧基线和当前工作。

“读取工作表”只读取选择的普通JSON文件，校验schema1–5、内容/数值/维度/字节限制，再显示名称、来源工具版本、文件声明UTC、表达式、角度、变量/历史数量及矩阵范围。元数据不证明内容真实。当前工作未改动前保留；存在未保存修改时勾选替换并确认恢复。可在读取预览期间先另存当前工作；保存中禁用恢复。不想恢复时“放弃本次读取”保持当前工作。

恢复不重放历史赋值、不创建模型/文件任务；表达式确认后仍有原来的即时算术预览，赋值需按固定结果，矩阵派生结果清除且须手动重算。历史为文件保存的结果记录，不代表曾在当前变量状态下执行。未知schema、字段、重复变量、非约分或非有限数值拒绝。

未保存工作、待读取确认和后台I/O进入托盘完全退出、无托盘关闭及程序更新保护；隐藏到托盘保留内存。可在工作表页明确放弃修改并恢复上次保存/初始基线。完全退出不能中断进行中的保存；保存结束仍可选择放弃未保存内容退出。原文件更新、加密工作表、工作表库/自动恢复、其他工具的精确类型接力仍在后续计划。

## 数值类型接力（0.4.0）

表达式结果和未过期矩阵结果可用顶部“发送数值到工具”。发送时捕获1–8行/列、最多64数值的快照；不会固定赋值或修改源输入。默认保留类型，以c1..cN列的JSON对象数组传递，每格包含独立数值类型、规范精确分子分母或完整f64字符串。默认新建数据实例，原输入/导出与计算器结果保留。过期矩阵须先重算。

弹窗可明确选完整数值文本（分数和完整近似文本，近似值带≈）或近似f64数字（大整数/分数会有精度损失）；这些模式支持JSON/CSV/TSV，却不保留可回传的数值类型。类型保留只支持JSON，CSV/TSV目标不可用。预览最多1200字符，发送完整有界快照；源继续编辑不会改变已经捕获的快照。

数据工作台保持单元格JSON对象，在JSON导出后通过“发送结果到工具”选择“计算器 · 数值表格填入矩阵”。仅完整规范c1..cN、1–8行/列、<=128KiB的数值类型JSON接受；重复/缺失列、非法数值、普通数字或文本被拒绝，不把近似数字误认成精确值。替换A，保留B、变量与表达式，不执行计算；现有未保存工作需先保存/放弃或明确允许替换所选矩阵；待恢复确认和后台文件任务须先处理，不能悄悄覆盖。普通表格变换如果改变对象类型，回传校验会明确失败。

接收单元格保留原数值类型而不重新解析显示文本，正负零与最小浮点值可保留。修改单格即清除该格原类型，作为普通表达式处理；近似显示中的≈需要移除，科学计数法仍受精确表达式范围限制。清零/单位阵/应用TSV清除对应矩阵的类型字面量。新工作表schema2保存这些字面量并检查显示一致；仍可读旧schema1（无typed字段默认空），dev31及更早不能读schema2。明文和无覆盖另存边界保持。工作台选行列与A/B接收见下节；外部JSON任意列直接映射、一次多矩阵接收和其他工具协议继续开发。

## 表格行列选择与A/B接收（0.5.0 / 数据工作台1.2.0）

数据工作台完成解析后，在筛选/排序控件下展开“选取数值区域 → 计算器”。开始行和行数对应当前已解析的可见视图，最多8行；选择最多8个具名列，按选择顺序构成矩阵，可前移/后移。点击“预览发送”才转换最多64格并捕获快照，原表格输入和导出不改动。不是发送整个数据集，不受下表只预览200行的显示限制。来源提示显示行范围与列映射，确认前不修改计算器。

CSV字符串精确模式仅接受十进制/科学计数法/分数字面量，使用现有i128有理数边界；不执行函数、算式或赋值。文本近似模式是明确选择，允许≈标识和f64科学计数法；可能舍入/下溢或丢失大整数精度，溢出/零分母拒绝。JSON整数在解析整数范围内保留，JSON小数或超出其整数范围而解析成f64的数字标近似；要保留超大整数应使用数字字符串或规范数值类型对象。已有类型对象保持类型。空值、布尔、数组和未知对象拒绝，错误显示视图行及列名。基础JSON解析后的对象按当前表格内容转换，不声称重新验证原始文本中已被解析器折叠的重复键。

统一接力弹窗选择计算器后，可以选矩阵A/B。默认不覆盖未保存计算工作；明确勾选“允许替换未保存的所选矩阵”后，只替换该矩阵，保留另一矩阵、变量、当前表达式与历史，清除旧派生结果但不计算。改变A/B目标会重置许可。待读取工作表和后台I/O必须先处理，不能通过该复选框绕过。因此可以先送A，再明确允许送B以组成方程，最后手动计算；不需要为了传入B而丢弃A。

小窗口的接力正文可滚动，取消和确认固定在底部；单元格悬浮显示完整长数值。来源选择器在本次内存中保留，不写入数据实例快照；接收后的矩阵数值继续由schema2工作表主动保存。任意精度、复数/CAS/高级绘图、其他工具协议及物理长期性能继续开发。

数据工作台可从首屏“选取数值 → 计算器…”打开独立选取窗口，无须滚动到表格下方。取消不发送；预览捕获快照后仍走现有A/B确认流程。

## 大快照接收操作（0.5.1）

数值接力弹窗将矩阵A/B选择、未保存内容替换许可和接收按钮放在固定底部；长JSON预览及目标列表在正文滚动，错误提示单独限制高度。8×8数值接收仍须显式授权替换，保留另一矩阵、算式、变量和源数据，不自动计算。

## 函数绘图与采样接力（0.6.0）

在计算器选择“函数绘图”，输入y=f(x)，设置采样范围并点击绘制。最多4条函数，每条17–2049个点（常用档位129/257/513/1025/2049），公式仍采用现有运算/科学函数；x临时作为近似采样坐标，其他变量/ans只读快照，不写入历史。函数使用显式乘号，不接受赋值或单位箭头。

拖动图形平移，图内滚轮缩放，悬停读最近采样值；“适应曲线”恢复视窗。视窗变化不改变采样区间，若要计算新区间，请修改采样范围并主动更新。可自动Y范围或手动设置；显示范围限制±1e12，不可区分的浮点坐标拒绝采样。不是数学连续性或所有奇点的证明：定义域错误留空，中点探测拒绝的间隔不连线，高频、尖峰或未命中的奇点仍可能漏检，应缩小范围和提高采样数。

改动公式/启用曲线/采样范围/数量/变量/角度后，旧图标记过期，复制、文件导出和发送均须重新绘制。后台结果保持启动快照，后续编辑不会被当作当前结果。可以取消；失败保持旧图。

采样CSV保留完整f64文本，列x及y1..y4，无效值为空。顶部“发送采样表到工具”默认选择CSV新实例并预览确认，保留既有数据工作；接力仍限128 KiB，超限可减少采样或主动另存。复制/文件输出限1 MiB。CSV与SVG另存不覆盖已有文件，SVG是当前视窗的矢量图；本地导出不作为落地网站配图上传。

工作表升级schema3，保存曲线、范围、采样档位、Y设置和当前工作区，不保存派生曲线或视窗临时拖动状态。兼容读取schema1/2（旧工作表补默认绘图参数），旧版计算器无法读取schema3。恢复只加载参数，须手动重新绘制，现有未保存内容仍需确认。


## 统计与组合计算（0.7.0）

展开“统计与组合 · 点选示例”可按类别填写算式；点选只修改输入，按Enter/固定结果才写入变量、ans和历史。最多64个参数、沿用2048字节/512词元/64层嵌套限制，可引用变量及分数。

| 函数 | 意义与示例 |
| --- | --- |
| `sum` / `mean` / `median` | 总和/平均数/中位数：`mean(1/3,2/3)` 精确0.5 |
| `varp` / `stdp` | 总体方差/标准差，分母n：`varp(1,2,3)` 精确2/3 |
| `vars` / `stds` | 样本方差/标准差，分母n−1，至少2值：`vars(1,2,3)` 精确1 |
| `fact(n)` | n的阶乘，0!=1；`fact(20)` 精确2432902008176640000 |
| `perm(n,r)` / `comb(n,r)` | 有序排列/无序组合，要求0≤r≤n≤10000；`comb(52,5)` 精确2598960 |
| `gcd(a,b)` / `lcm(a,b)` | 两整数公约数/非负最小公倍数，负号按绝对值处理；gcd(0,0)=0，任一值为0时lcm=0 |

全部精确参数时总和、均值、中位数和方差保留i128有理数；标准差经过平方根为近似值，混入近似参数的统计结果也标近似。方差采用偏移中心化计算，减少大共同偏移的误差，不保证任意精度。包含近似值的中位数按f64排序，可能无法区分超过浮点分辨率的相邻大整数。排列组合先约分再乘；33!可表示，34!超过i128拒绝。不支持权重/缺失值策略或把方差当作误差保证。

数值或中间精确运算超界会明确报错，不悄悄切换f64。不会修改统计参数或已有变量；固定后结果可使用现有数值接力。工作表仍schema3；旧版恢复含新函数的算式不会回放，重新计算会提示未知函数，应使用新版本。


## 表格区域统计与接力（0.8.0）

数据工作台按现有行列选取和确认流程将数值区域送入A，然后在“矩阵与数据统计”的运算菜单选择“数值区域统计”。按“计算区域统计”才执行，接收不会自动计算。可对A当前行列范围的全部1–64格求总和、均值、中位数、总体/样本方差和标准差，0计入；空值或错误不自动跳过，错误指出源格子。B不参与、不解析、不修改；表达式、变量、ans与历史保留。

结果是保留精确/近似类型的1×1数值，顶部“发送数值到工具”可继续送到新JSON数据实例，或明确选择完整文本/近似数字的CSV/TSV。修改输入、操作、变量或角度后结果过期，须重新计算。运算菜单将矩阵与统计分组，避免平铺更多按钮。原先矩阵计算、TSV和A/B保护仍保留。

输入仍限矩阵每轴1–8、最多64值，不代表支持任意长整列。较大列统计仍需后续独立有界工作台。精度和样本/总体定义与上一节相同；i128或f64超界明确失败。此阶段工作表使用schema4，保存所选运算与输入，兼容读取旧schema1/2/3，恢复不执行、不保存派生统计结果。旧版本不能读取schema4；声明旧schema却携带区域统计操作的文件被拒绝。

## 日期与工作日（0.9.0）

在计算器选择「日期与工作日」，填写日期后主动计算。日期必须是 `YYYY-MM-DD`，范围公历0001–9999年；不处理时区或夏令时。

- 日期差：结束日期减开始日期，同一天为0，结束在前时为负数。
- 日期加减：天/月/年整数偏移，正数向后、负数向前。目标月没有原日期时默认报错，可主动选择截到月末。例如2024-01-31加1个月截到2024-02-29；2024-02-29加1年截到2025-02-28。
- 工作日计数：只统计周一至周五，结束日期始终包含，开始日期可选择是否包含；结束早于开始时拒绝计算。
- 工作日加减：不计开始日期，按偏移方向寻找周一至周五。周五加3工作日为下周三；偏移0保留原日期，即使是周末。

**这里的工作日不包含法定节假日和调休规则。** 计算不会改动表达式、ans、变量或历史。修改输入后旧结果失效，需重新计算才能复制或发送。日期差和工作日计数可通过现有数值接力发送精确整数；日期结果在本页复制，尚无独立日期类型接力。
