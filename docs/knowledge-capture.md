# 网页与对话收集

打开“网页与对话收集”，选择一种输入：

1. **粘贴文字**：填写标题，粘贴 Codex、其他 Agent 的对话结果或浏览器中复制的可见正文。来源标签或 URL 可选；如果粘贴的是 HTML 源码，可勾选“提取可见文字”。
2. **本机 HTML**：选择浏览器“另存为”得到的 UTF-8 `.html` / `.htm` 文件。可覆盖提取到的标题，或补充原网页 URL。不会执行脚本。
3. **公开 HTTPS 网页**：输入公开页面地址，明确点击准备预览。抓取只使用 HTTPS 默认端口，不带浏览器 Cookie、账号或认证头，不跟随重定向、不使用系统代理；拒绝本机、局域网、保留地址及常见凭据查询参数。直接联网读取最多 2 MiB HTML，连接最多 5 秒、总请求最多 15 秒。若本机需代理、页面需要登录或由 JavaScript 动态生成，请改用粘贴可见正文或本机 HTML。

每次先点击“准备正文预览”，核对标题、来源、文件名、正文 SHA-256 与前 2500 字，再选择现有**目录型知识源**。也可明确创建/选择 `%USERPROFILE%\.zi-devtools\knowledge-inbox` 作为“Zi 收集箱”。点击“保存到知识源”后，新建 Markdown 文件，包含标题、来源类型、来源、采集时间和正文。正文最多 256 KiB，输出最多 512 KiB；相同来源与正文会提示重复，正文变化会得到不同文件名；不会覆盖已有文件。

保存完成后可点击“扫描整个知识源…”：程序会转到“本地知识源”，选中刚才的目录，并按该来源的排除规则启动一次扫描。扫描读取整个知识源中符合规则的文件（最多 500 个文档、128 MiB），用于发现变化并更新文件清单；它不建立正文索引。也可以稍后在“本地知识源”对目录执行“扫描/刷新”。扫描成功后，点击“下一步：打开增量知识索引…”可直达索引页；仍需手动点击“同步全部已扫描来源”才建立本机正文索引，供关键词检索、带引用问答和 RAG 评测使用。保存时不会自动扫描或索引。

正文只在预览时进入本程序内存，明确保存后写入用户选择的本机目录。抓取的网页内容是不可信文本，程序不会执行网页脚本或页面内指令。正文提取优先选择页面主内容区，跳过常见导航、页脚、侧栏、脚本与样式；复杂站点可能需要人工检查或改用浏览器复制。
