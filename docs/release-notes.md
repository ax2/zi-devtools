# Zi DevTools v0.15.0

新增六个本地工具，现有 26 个轻量工具、5 个开发工作台及本地服务管理，规划清单剩余 24 项。

- JSON 路径查询：字段、索引、通配符，输出匹配结果数组。
- JSON 结构对比：JSON Pointer 差异路径；按索引或忽略数组顺序，保留重复次数。
- 数据质量检查：JSON / CSV / TSV 的缺失值、空白字符串、重复行及类型分布。
- Cron 预览：数字五字段表达式，预览未来 5 年内最多 10 次运行；参考时间支持固定 UTC 偏移。
- 随机数据：系统安全随机字符串，以及独立的可复现种子测试模式。
- Unicode 检查：码点、UTF-8 字节、常见不可见字符及 NFC/NFKC 规范化。

新工具均支持搜索、收藏、托盘直达和独立会话草稿。数据在本机处理。JSONPath 不支持过滤器/递归/切片；JSON 对比暂不支持忽略路径；Cron 不模拟夏令时；种子测试模式不得用于密码或令牌；NFKC 可能改变字符语义。

验证：43 项单元测试、4 项服务生命周期测试、格式化与 Clippy 检查；实际应用明暗主题截图与快捷键导航。安装包生成与安装/卸载验证由 Release 工作流执行。

Windows x64：MSI 安装包、便携 EXE、SHA256SUMS.txt。升级前请从托盘退出旧版本。MIT 开源。
