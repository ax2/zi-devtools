# Zi DevTools v0.16.0

本轮将工具箱升级为可扩展的工具目录，新增声明式插件中心和本机集成发现。

- 八类分类，全部/收藏/最近/常用视图；内置与插件统一搜索，Ctrl K 支持多关键词。
- JSON 插件清单预览、安装、启停、卸载与内容指纹；默认停用，不执行安装脚本或加载动态库。
- 内置操作和后台 HTTP JSON 适配器；3 个示例包、6 项可选工具：本地文本、Ollama、OpenAI 兼容连接器。
- 本机 PATH / 端口只读发现，不启动服务、不读取其他应用私有数据库或凭据。
- 新增 42 项规划，目录共 34 项内置已实现能力、66 项规划；提供 Agent、MCP、RAG 与插件 SDK 的架构、依赖和验收路线。

界面偏好兼容升级，最近/常用仅记录工具 ID 与次数。插件令牌仅保留会话内存；远程接口要求 HTTPS，HTTP 仅支持回环地址；不跟随重定向。V1 不支持 SSE、MCP 会话、完整 RAG、自主 Agent、进程插件或自动更新。连接器通过本地 HTTP 夹具验证，本机 Ollama 未运行，未声称实际模型推理已验证。

Windows x64：MSI、便携 EXE、SHA256SUMS.txt。升级前请从托盘退出旧版本。MIT 开源。

验证：49 项单元测试、4 项 Windows 生命周期集成测试、fmt/Clippy、27 张实际 UI 截图与内置/插件键盘导航；本地 MSI 安装卸载与正式 EXE 启动通过。
