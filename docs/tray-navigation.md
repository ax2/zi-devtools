# 托盘与快捷访问

- 左键恢复主窗口；右键使用 Windows 原生菜单。关闭窗口仍隐藏到托盘，选择“退出”才结束程序。
- 顶部固定打开窗口与搜索；搜索打开现有 Ctrl K 面板，支持名称、用途和多关键词，上下键选择、Enter 打开、Esc 关闭。
- 收藏按添加顺序显示前 8 项；最近按访问时间显示前 8 项；常用按次数显示前 6 项，同次数优先最近访问。各菜单末尾可打开完整视图，会清空旧搜索和分类筛选。
- 收藏和最近均保留工具 ID，原生菜单与首页使用相同记录。插件停用/移除时隐藏不可用入口，但保留其偏好，重新启用后可恢复收藏。
- 全部工具按应用目录分类，包含内置工具和已启用插件。插件名称中的控制字符被清理，过长名称截断；完整名称可在首页/搜索查看。
- 本地服务展示托管、外部占用和状态；只允许停止/重启托管进程。批量按钮在没有适用服务时禁用。
- 收藏、最近、次数和主题保存在本机 ui-preferences.json，不含工具输入/输出。先写入同目录临时文件再替换旧文件；读取损坏数据使用默认值，加载时去重并限制条目数量。

Windows 控制原生菜单的字体、边距和颜色，应用的明暗主题只改变主窗口。未实现自绘悬浮面板或系统全局 Ctrl K 热键；托盘“搜索工具”可在窗口隐藏时恢复窗口并定位搜索。

Stage 19 同时修复搜索列表鼠标滚动被当前选中项拉回的问题，收藏增加操作反馈并与托盘保持一致的顺序。
