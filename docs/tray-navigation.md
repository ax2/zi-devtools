# 托盘、全局启动器与文件导入

## 三种入口

- 左键托盘图标：打开独立快捷面板。主工作台保持原位置、大小和草稿，隐藏时也能使用面板。
- 右键托盘：保留 Windows 原生菜单，提供工作台、面板、搜索、收藏/最近/常用、分类工具、服务和设置。
- 录屏时右键托盘的“屏幕录制”子菜单显示状态，并提供暂停、继续、停止保存；倒计时中可取消，不会自动弹出主窗口。
- 默认全局热键 `Ctrl+Alt+Space`：在其他应用中唤起面板。应用内 `Ctrl K` 仍打开工作台搜索框。

快捷面板支持明暗主题、收藏、最近、全部、关键词搜索、↑↓选择、Enter 打开、Esc 收起。搜索覆盖所有已启用工具，不受当前收藏/最近标签限制。选择工具后恢复工作台；点击工作台按钮可回到原页面。面板失去焦点后收起，后台任务继续运行。

## 热键配置

在“设置 → 全局快捷启动器”修改或关闭热键。支持 Ctrl / Alt / Shift 与 A–Z、F1–F12、Space，至少包含 Ctrl 或 Alt。系统保留组合也可能注册失败，界面会提示。

更换组合先尝试注册新组合，成功后才释放旧组合；失败保留旧绑定。关闭热键或退出程序释放注册。重复实例可能竞争同一组合，不会强行抢占。凭据不参与热键功能。

## 收藏与最近

收藏按添加顺序、最近按访问时间、常用按次数排列，同次数优先最近访问。原生快捷菜单分别显示前 8 / 8 / 6 项，并有完整视图入口；面板列表可滚动。插件停用时从入口隐藏，重新启用后保留收藏记录。

服务只允许停止/重启托管进程。关闭主窗口仍隐藏到托盘；选择“退出”才结束程序。应用主题控制主工作台和自绘面板，原生右键菜单颜色由 Windows 控制。

## 文件导入

将文件拖入主工作台或快捷面板，或打开“文件拖放入口”填写路径。扩展名用于推荐打开方式，由用户最终选择。

| 文件 / 任务 | 支持方式 |
| --- | --- |
| CSV / TSV | 读取并解析表格预览 |
| JSON | JSON 格式化草稿或 JSON 对象数组数据表 |
| UTF-8 日志 / 文本 | Java 异常、Python/Django 异常、线程转储、GC、SQL、Celery |
| 多个文件 / 二进制文件 | 加入文件校验列表，手动启动哈希 |

文本最多 2 MiB，支持 UTF-8 BOM；最多 64 个文件，不递归目录，不执行拖入的程序，不自动上传。日志语言无法仅凭扩展名可靠判断，需选择正确类型。导入会替换所选工具的输入草稿，按钮明确提示；正在运行的目标任务拒绝覆盖。文件校验追加路径，超限时保持原列表。

未增加剪贴板后台监听、系统资源管理器右键扩展或跨应用任意文本抓取；这些不属于本版文件拖放功能。
