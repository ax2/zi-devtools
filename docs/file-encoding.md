# 文件编码检查与转换（Stage 45 / v0.45.0）

从侧栏“文件编码转换”或 Ctrl K 搜索进入。选择一个本机普通文件并读取，界面展示源字节数和编码提示。UTF-8/UTF-16 的 BOM 可确定相应格式；无 BOM 的合法 UTF-8、ASCII 或其他编码只提供推测，**推测不代表确认**。无 BOM 的 UTF-16 也只按 NUL 字节分布给出提示。请选择或调整源编码，查看严格解码的文字后再决定是否转换。

支持源与目标 UTF-8、UTF-16 LE/BE、GB18030（含 GBK）、Big5、Shift_JIS 和 Windows-1252。Unicode 目标可明确选择是否写入 BOM；切换目标时更新建议文件名。点击“生成转换预览”后，展示最多前 4000 字符、目标字节数、前 48 字节十六进制和完整 SHA-256。软件还会按目标编码严格回读，结果与原文不同就拒绝导出。未能解码、含 NUL 或异常控制字符、目标编码无法表示全部字符时会明确报错，不用替换字符或 HTML 实体掩盖问题。

输入文件最多 8 MiB，输出最多 16 MiB；处理完全在本机内存完成。确认文字与字节信息后填写新路径并另存。目标已存在时拒绝覆盖，原始文件不修改。启发式编码识别受文本长度与内容影响，混合编码、二进制、少量短文本可能无法可靠判断；此时应核对来源并手动选择。
