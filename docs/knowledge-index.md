# 增量知识索引

先在“本地知识源”明确添加文件或目录并手动扫描。在“增量知识索引”点击“同步全部已扫描来源”，应用才会解析文件并将分块正文、来源相对路径、位置、SHA-256 保存到 `%USERPROFILE%\.zi-devtools\knowledge-index.sqlite3`。索引不上传网络；该数据库包含文档原文片段，应作为本机用户数据管理。

再次同步时，文件 SHA-256 未变化的内容跳过，变化的文件重新解析，从快照移除的文件或整个知识源会从可搜索索引中删除。没有扫描快照的来源不会加入；其旧索引记录会在同步时清除。同步图片和 PDF 无嵌入文字页面时会使用文档解析页在当前应用会话选择的本机 OCR 语言；未选择时跟随 Windows 用户首选语言。扫描阶段不会识别图片或 PDF；OCR 结果仅在用户明确同步后写入全文索引。OCR 输出会合并相邻汉字之间的空格，保留拉丁字母边界和换行。每份 PDF 最多 OCR 50 个无文本页面，每页渲染长边最多 1200 像素且最多 800 万像素。语言功能不可用、媒体超限或解析失败会回滚整轮事务并保留原索引。取消会在当前文件解析结束后生效；单张图片或 PDF 页面 OCR 运行期间不能中断 Windows OCR 调用。若知识源配置读取失败，应用禁用同步和重建，避免把空配置误当成删除全部来源。

“重建索引”需二次确认，会重新解析当前全部已扫描文件；失败仍保留旧索引。“删除本机索引”需二次确认，会删除 SQLite 数据库及已知日志侧文件，不删除源文件或知识源清单。损坏或未知版本数据库不会自动覆盖；可检查文件后使用删除按钮重新建立。

文档解析页的“导出完整文本…”是独立的显式另存动作，不会写入知识源或索引；只有用户点击同步，识别文本才会进入本机全文数据库。

资源预算：最多 2000 个源文件、128 MiB 输入、100000 个分块、128 MiB 正文，SQLite 数据库约 256 MiB 上限。超限时报错并回滚。可在[本机关键词检索](knowledge-search.md)中查询索引。当前使用 SQLite FTS5 `unicode61` 处理英文词项、中文采用字面包含匹配；[本机向量索引](knowledge-vectors.md)可在用户明确选择模型后从已同步分块另建可选向量库，再由[混合检索工作台](hybrid-search.md)融合关键词与语义结果。

非空同步成功后，索引页提供“下一步：打开本机关键词检索…”入口。它只切换到检索页面，不自动运行查询，也不会把索引内容发送到其他工具。同步失败、空索引或新的同步开始时，此后续入口不可用。
