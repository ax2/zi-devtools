# 增量知识索引

先在“本地知识源”明确添加文件或目录并手动扫描。在“增量知识索引”点击“同步全部已扫描来源”，应用才会解析文件并将分块正文、来源相对路径、位置、SHA-256 保存到 `%USERPROFILE%\.zi-devtools\knowledge-index.sqlite3`。索引不上传网络；该数据库包含文档原文片段，应作为本机用户数据管理。

再次同步时，文件 SHA-256 未变化的内容跳过，变化的文件重新解析，从快照移除的文件或整个知识源会从可搜索索引中删除。没有扫描快照的来源不会加入；其旧索引记录会在同步时清除。若知识源配置读取失败，应用禁用同步和重建，避免把空配置误当成删除全部来源。解析错误、文件版本过期或取消会回滚整轮事务，保留原索引。

“重建索引”需二次确认，会重新解析当前全部已扫描文件；失败仍保留旧索引。“删除本机索引”需二次确认，会删除 SQLite 数据库及已知日志侧文件，不删除源文件或知识源清单。损坏或未知版本数据库不会自动覆盖；可检查文件后使用删除按钮重新建立。

资源预算：最多 2000 个源文件、128 MiB 输入、100000 个分块、128 MiB 正文，SQLite 数据库约 256 MiB 上限。超限时报错并回滚。当前使用 SQLite FTS5 `unicode61` 分词作为全文索引基础；中文自然语言分词、检索排序、可选向量索引和带引用问答仍在规划，不应把本阶段理解为完整 RAG 问答能力。
