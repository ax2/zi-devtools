# 每个工具的桌面与任务栏入口

在「工具库」中找到工具，点击该行的「快捷方式」：

- **创建桌面快捷方式**：直接在 Windows 桌面生成工具入口。
- **创建用于任务栏的快捷方式…**：生成入口并打开所在目录。右键这个快捷方式，在 Windows 菜单中选择「固定到任务栏」；部分系统需先选择「显示更多选项」。固定的是带参数的快捷方式。
- **复制启动参数**：用于自建快捷方式、脚本或其他启动器。

例如：

```text
ZiDevTools.exe --tool json
ZiDevTools.exe --tool services
ZiDevTools.exe --tool django-sql
```

编号来自工具目录 `docs/tools.json` 的 `id`。启用插件的完整编号为 `plugin:<插件编号>/<工具编号>`，可从工具库复制，插件停用或移除后该入口会回到工具库并提示。不存在的工具不会被自动猜测为其他工具。

生成的 Windows `.lnk` 包含当前程序位置、工具编号、当前服务配置的绝对位置、工作目录和程序图标，并保存每个工具独立的任务栏身份。相同名称不会覆盖旧快捷方式，会生成带序号的新入口。无需管理员权限。

工具专用启动直接选择相应工作台及子工具，只打开界面，不自动执行工具，也不自动恢复本地服务；正常不带 `--tool` 的启动沿用原有恢复设置。每次启动目前创建独立程序窗口，尚未向已有窗口转发。[收藏、最近和次数支持协作合并与刷新](shared-preferences.md)。其他用户数据修改前仍应避免多个窗口同时编辑。

程序移动、更换配置位置或便携开发版本目录后，请重新生成快捷方式并重新固定。原地更新且工具编号不变时入口继续使用原位置。任务栏固定由 Windows 操作完成，程序不修改用户的任务栏布局；未验证所有 Windows 版本的实际固定/取消固定交互。

## 从外部程序送入文件

开发版可以使用 `ZiDevTools.exe --open-files "C:\资料 folder\订单.csv"`，或 `ZiDevTools.exe --config "C:\配置\services.yml" --open-files "C:\data\a.json" "C:\data\b.json"`。

`--open-files` 必须放在最后一组选项位置，其后的每个参数都是一个文件路径；参数名形状的文件名也按路径处理。调用者须使用进程参数数组或正确引用每条路径，不要拼接 shell 命令。相对路径按调用者当前目录解析，最多64条。空路径、NUL字符、超量、与工具直达/配置导入/服务夹具混用会拒绝启动。

启动打开已有“从文件开始”确认页，仅排队和推荐打开方式，不读取内容、不导入、不执行文件或工具、不自动恢复服务。用户可改选工具，再主动确认读取；已有2 MiB UTF-8及批量文件校验限制仍适用，目录不递归导入。无效或已消失文件在确认读取时显示错误。

每次目前仍创建独立窗口；本功能是资源管理器入口的文件接收基础，不代表右键菜单已安装。统一经典菜单、按类型适配、单实例转发及EXE/MSI安装/升级/修复/卸载仍待实现与实际Windows验收。

文件入口1.2.0可在`--open-files`之前增加`--file-action`精确预选接收器，例如`ZiDevTools.exe --file-action import:json --open-files "C:\data\a.json"`。共享动作：`import:csv`、`import:tsv`、`import:json-data`、`import:json`、`import:java-trace`、`import:django-trace`、`import:java-threads`、`import:java-gc`、`import:django-sql`、`import:celery`、`import:files`。除文件校验允许1–64文件外，其余每次一个UTF-8文件、最多2 MiB；这些限制与导入页及注册预览共用。必须同时提供文件列表，不可重复动作选项。预选仍不读取内容或自动诊断，用户可改选工具后确认。

设置页“资源管理器右键入口”可展开候选菜单及复制JSON明细。注册计划仅生成明细；“检查当前入口状态”按钮可主动后台只读检查固定本产品入口，均不写入注册表，不生成可导入的.reg文件；当前计划只对文件单选、经典菜单有效，不能当成完整多选、安装生命周期或Windows11现代菜单已交付。模板中程序/配置路径含百分号、引号或控制字符时拒绝生成；此限制只适用于Shell占位符模板，普通文件启动参数保持原有路径范围。
