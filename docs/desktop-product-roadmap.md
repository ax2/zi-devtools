## 共用架构与使用入口

工具库、全局前缀、托盘、资源管理器右键和剪贴板动作共用命令注册表，不各自复制一份工具清单。每个命令包含稳定 ID、所属工具及版本、动作、输入类型、文件扩展名/多选限制、权限、预览入口与是否可撤销。增加工具不自动获得文件写权限，也不默认显示所有右键项。

任务按输入进入独立工作实例；结果携带来源、工具版本和类型，用户可送往备忘、日程、数据处理、图片工具或剪贴板。首次写入、覆盖、联网、注册系统入口或持续采集由用户主动开启；保存后可设置适用范围内的偏好，避免每一步重复询问。任务中心显示进度、取消与结果。录屏/截图合成与音视频写入使用专用后台任务，不阻塞主窗口。

工具数扩大后，固定主导航和搜索/收藏/最近/常用仍作为主入口。按“处理图片”“整理文件”“录制教程”等任务显示相关工具及接力动作，避免继续堆叠侧栏。命令面板允许名称、别名和快捷序列搜索；未实现功能不加入可执行菜单。

## 2. 教程录屏与局部放大

开发版教程录屏0.2.0已接入全景局部放大窗、四角位置与独立聚光灯，以及固定/跟随1–4倍、平滑过渡、鼠标高亮与采样波纹、预览/实时调整/复位。合成源与指针夹具的实际MP4解码验证不等同于真实桌面/物理鼠标验收；后者继续待验，详见[教程录屏](recorder-tutorial.md)。

先提供三个模式：固定区域局部放大、按热键聚焦当前鼠标位置、平滑跟随鼠标。提供 1–4 倍、过渡速度与复位，限制焦点在录制范围内；输出画布和文件分辨率保持不变，放大只是构图变化。可选保留全景加局部放大窗，方便演示软件操作。

教程辅助包括鼠标高亮、点击波纹、按键显示、临时画笔/箭头/聚光灯、步骤编号、提词器、章节标记。文字输入和密码输入不能默认原样显示；按键显示默认仅组合键，可暂停。提供录制前效果预览，明确“写入视频”“仅操作者可见”的区别；捕获后合成避免控制栏递归出现在录屏里。字幕、剪辑和配音可在后续独立工作台接力，不能称当前已具备视频编辑器。

验收：效果确实出现在导出的 MP4，启停/暂停期间状态正确；录制范围边缘、125%/150% DPI、不同屏幕、光标与遮罩位置正确；高帧率下性能与音画同步、取消后的文件封装可用。质量/大小估算继续显示，码率估计不能承诺精确文件大小。

## 3. 更新检查与增量更新

增量更新工具0.1.0增加本机有界差分/完整内容压缩、生成自检及校验重建、后台取消和预览后无覆盖另存；源/压缩内容/目标摘要核验，源不匹配明确拒绝。无签名、网络下载、自动替换/回滚，见[更新包说明](delta-updates.md)。

开发版更新检查0.7.0提供后台匿名GitHub发布检查、稳定/预览频道、SemVer判断、附件大小和有界说明；用户主动开启后每24小时检查，默认关闭。提供用户所选清单/附件的离线摘要校验，提供主动官方附件下载/校验/另存；签名认证/工具差异已接入，首个公开签名Release待验；已接入便携双EXE替换与旧版恢复；已接入MSI安装版认证完整升级；签名增量应用及首次线上升级仍待验收。见[程序更新](program-updates.md)。

先做手动检查，选择后开启定期检查；稳定与预览频道分开。展示程序版本、工具变更、下载大小、兼容条件，离线不影响工作。元数据需受信任签名并记录目标摘要，HTTPS 和 SHA-256 单独使用不能证明发布者身份。

增量包只适用于匹配源版本与源摘要：下载到暂存目录，校验补丁，离线重建目标，校验目标，再等工作保存、录屏结束和程序退出后由独立更新助手替换。保留上一版本，失败回滚；基线不匹配或补丁不可用自动改用完整包，并显示实际下载量。用户数据与索引保持独立；数据库迁移必须定义兼容范围和备份/恢复规则。

便携 EXE 更新完整运行目录；MSI 使用 Windows Installer 的升级/修复/卸载机制，不能绕过它直接替换受管理文件。若以后要减少 MSI 下载量，需单独设计并验证 MSP 补丁或下载层复用；第一阶段允许 MSI 使用完整安装包。更新完成后复核右键入口指向实际版本。

验收：错误源文件、损坏补丁、签名错误、中断下载、磁盘不足、文件被占用、权限不足、更新中断及回滚；按实际完整包/差分包大小报告收益，不预设节约比例。

## 4. 全能计算器

从一个输入框开始：`(128 + 64) * 3`、`5 km -> m`、`0xff & 0x0f`、日期差。提供实时预览、Enter 固定结果、历史复用、变量、可复制表达式与结果，输入错误指出具体位置。不用同时摆出大量按钮；科学、程序员、单位、日期、工作表等模式按需展开。

第一阶段：明确优先级的表达式解析、精确十进制、科学函数与角度单位、整数进制/位宽/符号位、常用单位、日期时间和可选历史保存。第二阶段：大整数、分数、复数、矩阵、方程与函数绘图；公式工作表允许命名变量与依赖重算。金融/统计公式显示假设，汇率若联网则显示来源与更新时间。

验收：`0.1+0.2` 的精确模式、负数幂优先级、弧度/角度、位宽溢出、单位维度错误、零除、极大数字、循环变量、绘图奇点。数值近似与精确结果明确区分；不得使用脚本 eval 执行用户输入。

## 5. 资源管理器统一右键入口

统一入口“Zi DevTools”，文件、文件夹和文件夹背景支持不同子菜单；高频动作置顶，更多动作打开针对当前选择的任务面板。先接入校验、图片转换/压缩、编码检测、目录分析、SQLite 浏览、文档入库等适用现有能力。转换或覆盖先预览输出规则与目标路径，多选给出支持数量和部分失败结果。

EXE 提供用户主动安装/修复/移除入口；MSI 有安装选项并在升级/修复/卸载维护注册。默认当前用户作用域，记录所有权并只移除自己的键。单实例转发结构化路径，不能拼接为 shell 命令；正确处理空格、中文、引号、长路径、多个文件与已不存在的文件。快捷菜单打开只创建草稿，不自动执行耗时/写入动作。

第一阶段做经典级联菜单，Windows 11 若仅能在“显示更多选项”出现就明确说明。现代菜单涉及 IExplorerCommand、打包身份和 shell 扩展部署，应单独原型与验证，不宣称注册表级联菜单等同于现代菜单。Shell 侧只转发任务，不加载主程序或模型执行，以保护资源管理器响应速度。

验收：便携目录移动后可修复；EXE/MSI 共存及升级时不误删对方入口；安装失败清理、卸载后无残留、入口显示权限正确，实际 Explorer 新旧菜单与多选验证。

## 6. 全功能时钟

开发版时钟0.4.0已接入五个工作视图、主动保存/预览确认恢复、声音/音量/静音/定时免打扰，以及世界时钟/秒表/每个计时器/番茄钟独立原生小窗（最多8窗，置顶/全屏/Esc、同步操作与重置确认）。小窗布局仍仅会话；完整日程共享调度、真实跨屏/睡眠/改时/完全退出等及退出后任务继续推进，不能视为全功能时钟验收完成。

大字数字/模拟时钟、世界时钟与跨时区会议对照、秒表与分段、多个独立倒计时、命名预设、闹钟/重复/稍后提醒、番茄钟、置顶迷你窗与全屏时钟。拖动或输入设置时长，键盘暂停/继续/重置；声音试听、静音与全屏勿扰可配置。

与日程共享提醒数据和调度层，避免两套提醒争用。持续时间用单调时钟，日历闹钟用明确时区；睡眠恢复后的补提醒可配置。隐藏到托盘继续提醒，彻底退出则停止；若用户要退出后提醒，主动安装系统任务或常驻助手并提供禁用/卸载入口。

验收：睡眠恢复、手工调整系统时间、跨日、夏令时重复/缺失时间、重启恢复、多计时器并行、不重复响铃、音频不可用降级，分别验证托盘隐藏与退出行为。

## 7. 截图、自由轮廓与透明 PNG

捕获当前桌面后进入选择层，支持全屏、窗口、矩形、自由手绘闭合轮廓、多边形。鼠标拖出不规则边界，松开自动闭合，预览轮廓、内部内容与棋盘格透明背景；可撤销、移动点和羽化。按选区最小包围框裁出图像，对轮廓外像素写 alpha=0，边缘抗锯齿；默认输出透明 PNG，不以白色替代透明。

增加光标附近放大镜、颜色/坐标提示、标注/箭头/文字、打码、置顶截图、复制与无覆盖另存；不破坏原始捕获。长截图需要滚动捕获和拼接专门验收；OCR、图片转格式和教程录屏可接力。截图保存透明 PNG 与落地网站配图使用 WebP 是两项不同要求，网站仍遵守 WebP 流量预算。

验收：凹多边形、边界外拖动、自交规则、过小/未闭合选区、抗锯齿边缘、透明像素、混合 DPI/多屏负坐标；输出 PNG 重新读取核验 alpha，图片编辑器实际显示透明。

## 8. 统一前缀快捷键

建议可配置前缀 `Ctrl+Alt+Space`，按下后显示操作提示并释放修饰键，再按 `R S` 开始录屏、`R P` 暂停/继续、`R E` 结束、`S F` 自由截图、`C` 计算器、`T` 时钟、`V` 剪贴板、`K` 搜索。dev.5 已接入现有可配置全局前缀与 R S/P/E、C、K 等默认序列，并提供全工具附加键草稿编辑和保存；T 已接入时钟工作台；S C 已直接启动截图，S F 已打开截图工作台，V 已接入开发中的文本剪贴板工作台。真实物理跨应用冲突验收尚未完成。支持一个或多个附加键，不要求用户记住所有序列。

序列只在面板激活期间接收输入；支持超时、Esc、失焦取消，输入法组合期间不误触。可用工具的附加键已经可搜索、修改；K 保留搜索，空序列解除绑定，重复或前缀重叠禁止保存，保存失败保留旧配置。导入先查看合并/替换变化再放入草稿，导出只含自定义序列；系统注册冲突仍保留旧前缀。现有 Ctrl K 和录屏热键作为迁移兼容，提供重复绑定提示；保留一个直接“停止录屏”紧急键，不让用户只能完成多键序列才能结束录制。录屏启动仍需明确区域和输出设置。

验收：任意应用唤起、中文 IME、远程桌面、键被占用、失焦、超时、重复序列、长按、防连击、程序退出后释放注册，不长期全局拦截普通输入。

## 9. 超级剪贴板

dev24接入0.1.0文本会话历史闭环：Windows通知/主动开启、暂停/关闭、搜索置顶、去重与容量边界、组合预览复制、现有接力入口。持久化和其他格式仍待开发，见[当前实现与边界](clipboard.md)。

先做可选历史采集与便捷多项操作，再增加跨工具能力。支持文本、HTML/RTF、图片、文件引用，按内容类型搜索与预览，置顶/收藏/标签、保留期、容量、暂停、排除应用与一键清空。首次开启明确是否保存到本机以及保存范围；持久内容保护使用 Windows 保护能力，仍不能假定对已登录用户进程绝对保密。

差异化方向：连续复制生成表格/JSON；多片段有顺序拼装与模板变量；来自不同应用的片段组成备忘/日程草稿；图片→OCR→字段提取→CSV 的预览流程；剪贴板条目携带来源和变换链，结果可回到原任务。多项粘贴可选择逐项、合并或编号列表；目标应用能接收的格式需说明，先复制结果作为可靠降级。

默认不读取密码管理器等排除应用，支持快捷“私密暂停”。不能保证自动识别所有秘密，用户须可控制来源与保留范围；远程模型处理必须明确发送内容。同步、共享和自动上传不作为默认行为。引用文件需验证存在性与变化，不能在后台无界复制大文件。

验收：连续复制/重复事件、复制自身输出不形成循环、文本/图片大小上限、容量淘汰、暂停恢复、来源不可获取、重启/清空、错误格式、文件失效、敏感内容排除、模拟粘贴失败。
