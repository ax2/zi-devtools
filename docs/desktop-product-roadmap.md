## 共用架构与使用入口

工具库、全局前缀、托盘、资源管理器右键和剪贴板动作共用命令注册表，不各自复制一份工具清单。每个命令包含稳定 ID、所属工具及版本、动作、输入类型、文件扩展名/多选限制、权限、预览入口与是否可撤销。增加工具不自动获得文件写权限，也不默认显示所有右键项。

任务按输入进入独立工作实例；结果携带来源、工具版本和类型，用户可送往备忘、日程、数据处理、图片工具或剪贴板。首次写入、覆盖、联网、注册系统入口或持续采集由用户主动开启；保存后可设置适用范围内的偏好，避免每一步重复询问。任务中心显示进度、取消与结果。录屏/截图合成与音视频写入使用专用后台任务，不阻塞主窗口。

统一任务运行时 `task-runtime 0.5.0` 已开始落地：每个 Job owner 使用 UUID，和工具 ID、实例 ID 与 generation 组成 `RunId`；任务中心去重/清理、打开结果及单项/批量取消传递共用该身份，避免相同工具槽位和 generation 的并发任务冲突。UUID 不跨 Job 生命周期，不支持崩溃恢复或跨重启。取消能力与实际处理器在同一注册表中；缺少必需实例的任务不显示取消入口。用户可显式开启跨重启任务历史，最多保存 1,000 条终态元数据，默认关闭并可停止记录或清空；不保存任务实例名、摘要、路径、输入和输出。持久化作业恢复、跨页/关页隔离、统一暂停以及统一提交/结果接力仍待实现。

工具数扩大后，固定主导航和搜索/收藏/最近/常用仍作为主入口。全局启动器 `1.6.8` 已对内置工具 ID、显示名称和别名加入跨路由冲突门禁，并对内置工具与已启用插件的精确名称/别名重名提供多入口提示，保留各自名称、分类和插件标识供选择；托盘“全部工具”、收藏、最近和常用菜单也会给规范化后重复的标题附加分类，分类仍冲突时再附加稳定 ID，长标题在保留省略的同时显示末尾分类或 ID。动态插件的搜索元数据缓存到其包清单摘要或启用状态改变时才重建；结果匹配与偏好排序保持实时。按“处理图片”“整理文件”“录制教程”等任务显示相关工具及接力动作，避免继续堆叠侧栏。命令面板允许名称、别名和快捷序列搜索；未实现功能不加入可执行菜单。

## 7. 截图、自由轮廓与透明 PNG

增加光标附近放大镜、颜色/坐标提示、截图内直接箭头/文字和置顶截图；复制与无覆盖另存不破坏原始捕获。截图选区现在支持在透明 PNG 预览上直接放置本机字体文字（红色深描边，支持单行输入和字号预览）、拖出黑色遮挡、可调块大小的像素化矩形、可调半径的局部模糊、横向/纵向/对角线三色渐变遮挡和红色白描边箭头，并可撤销/重做；像素化、模糊、渐变和箭头遵守选区alpha，文字不涂出透明轮廓，每次标注修改都会从捕获源重算。渐变使用不透明色阶替换选区内可见像素，不留下底层原色；颜色暂为固定预设。也可经明确确认的内存接力打开图片编辑器，使用已有箭头、文字、黑色遮挡和可调像素化遮挡。截图页原生文字、模糊、渐变遮挡和置顶截图均已实现；置顶快照使用独立AlwaysOnTop窗口，更新快照或关闭即可控制窗口生命周期。长截图需要滚动捕获和拼接专门验收；OCR、图片转格式和教程录屏可接力。截图保存透明 PNG 与落地网站配图使用 WebP 是两项不同要求，网站仍遵守 WebP 流量预算。

验收：凹多边形、边界外拖动、自交规则、过小/未闭合选区、抗锯齿边缘、透明像素、混合 DPI/多屏负坐标；输出 PNG 重新读取核验 alpha，图片编辑器实际显示透明。

## 8. 统一前缀快捷键

建议可配置前缀 `Ctrl+Alt+Space`，按下后显示操作提示并释放修饰键，再按 `R S` 开始录屏、`R P` 暂停/继续、`R E` 结束、`S F` 自由截图、`C` 计算器、`T` 时钟、`V` 剪贴板、`K` 搜索。dev.5 已接入现有可配置全局前缀与 R S/P/E、C、K 等默认序列，并提供全工具附加键草稿编辑和保存；T 已接入时钟工作台；S C 已直接启动截图，S F 已打开截图工作台，V 已接入开发中的文本剪贴板工作台。真实物理跨应用冲突验收尚未完成。支持一个或多个附加键，不要求用户记住所有序列。

序列只在面板激活期间接收输入；支持超时、Esc、失焦取消，输入法组合期间不误触。可用工具的附加键已经可搜索、修改；K 保留搜索，空序列解除绑定，重复或前缀重叠禁止保存，保存失败保留旧配置。导入先查看合并/替换变化再放入草稿，导出只含自定义序列；系统注册冲突仍保留旧前缀。现有 Ctrl K 和录屏热键作为迁移兼容，提供重复绑定提示；保留一个直接“停止录屏”紧急键，不让用户只能完成多键序列才能结束录制。录屏启动仍需明确区域和输出设置。

验收：任意应用唤起、中文 IME、远程桌面、键被占用、失焦、超时、重复序列、长按、防连击、程序退出后释放注册，不长期全局拦截普通输入。

## 9. 超级剪贴板

超级剪贴板0.17.0新增显式启动的 Windows 本机图片 OCR，后台识别当前图片预览，最多1 MiB；结果默认不写历史或磁盘，用户选为接力来源后才可通过顶部统一接力栏发送，来源图片变化会使结果失效。默认整图识别，0.19.0增加在预览图上拖拽局部区域并映射原图裁剪；更改区域清除旧识别结果和接力选择。语言仍跟随 Windows 用户首选语言；语言切换、识别文本持久化、OCR 到 Agent 的自动字段提取仍待规划。0.16.0 的 RTF 功能保持：独立默认关闭、限制2 MiB并原样保存字节，不解析或渲染；保护快照schema7可读取旧schema1–6。Windows隔离窗口站夹具包含 RTF 关闭/开启、来源排除和回流抑制检查；本机创建窗口站仍可能受当前令牌权限限制。通用工具文本结果到Agent草稿的有界交接已实现，Agent工作台1.4.0支持逐条管理及批量导入有界 UTF-8 资料。

先做可选历史采集与便捷多项操作，再增加跨工具能力。支持文本、HTML/RTF、图片、文件引用，按内容类型搜索与预览，置顶/收藏/标签、保留期、容量、暂停、排除应用与一键清空。首次开启明确是否保存到本机以及保存范围；持久内容保护使用 Windows 保护能力，仍不能假定对已登录用户进程绝对保密。

差异化方向：连续复制生成表格/JSON；来自不同应用的片段组成备忘/日程草稿；将已有整图 OCR 扩展为 OCR→字段提取→CSV 的可预览流程；剪贴板条目携带来源和变换链，结果可回到原任务。多项粘贴可选择逐项、合并或编号列表；目标应用能接收的格式需说明，先复制结果作为可靠降级。

默认不读取密码管理器等排除应用，支持快捷“私密暂停”。不能保证自动识别所有秘密，用户须可控制来源与保留范围；远程模型处理必须明确发送内容。同步、共享和自动上传不作为默认行为。引用文件需验证存在性与变化，不能在后台无界复制大文件。

验收：连续复制/重复事件、复制自身输出不形成循环、文本/图片大小上限、容量淘汰、暂停恢复、来源不可获取、重启/清空、错误格式、文件失效、敏感内容排除、模拟粘贴失败。

## 实施顺序与发布门槛

| 阶段 | 主任务 | 可交付闭环 |
| --- | --- | --- |
| A（本次开始） | 工具版本与需求建档 | 全目录版本、工具库显示、插件兼容、生成校验；不新增虚假的可用入口 |
| B | 命令注册与前缀面板、计算器基础 | 共用命令输入/动作、统一键序列、能日常使用的计算器 |

| E | 右键安装生命周期、更新检查 | EXE/MSI 分别安装/修复/升级/卸载与真实 Explorer 验证 |

阶段可交错推进，但系统入口写入与更新必须先完成失败恢复设计。每次只把真实验收的能力改为已实现；公开发布还要验证安装包、下载摘要及网站同步。所有验收日志与截图保存在长期项目档案，不上传用户内容或凭据。

系统集成设计依据：[Microsoft Explorer 菜单接入文档](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer)说明现代菜单的 IExplorerCommand 与应用身份；[Microsoft 补丁包文档](https://learn.microsoft.com/en-us/windows/win32/msi/patch-packages)说明 MSP 补丁结构及目标安装版本关系。本文在此基础上提出分阶段方案，仍需本项目的实际安装验证。
