# 时区工作台

工具版本：`0.1.2`。从工具库搜索“时区转换”或“夏令时检查”进入。输入一条来源本地时间和 IANA 时区，再把它转换到最多 8 个目的时区；结果包含当地日期时间、UTC 偏移、时区缩写和对应 UTC。目的时区可逐个添加或移除，并可复制转换结果。

时间格式为 `YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD HH:MM:SS`。时区使用 IANA 名称，例如 `America/New_York`、`Asia/Shanghai`、`Europe/London`。程序使用随应用打包的 `chrono-tz` IANA 时区数据库，不联网查询，页面会显示其数据库版本；数据库只会随应用更新，不保证覆盖应用发布后的政策变更。

夏令时结束时，一个当地时间可能对应两个真实时刻。工作台会显示两个候选偏移，要求选择较早或较晚的时刻后再转换。夏令时开始时，某些当地时间不存在；工作台拒绝猜测，并显示前后最近的有效分钟。也覆盖像 Apia 在 2011 年跳过整日的民用时间变更。

输入仅保留在当前界面会话，不写入文件、不发起网络请求。当前版本面向“一个来源时间到多个目标时区”的转换；尚未包含长期行程、批量文件导入、日历邀请生成或团队共享。
