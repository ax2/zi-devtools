# SQL 格式化（开发中）

工具版本：0.3.1。可在通用工具目录中选择通用 SQL、PostgreSQL、MySQL、SQLite 或 SQL Server / T-SQL 方言，再格式化输入。缩进可选 2 空格、4 空格或 Tab，关键字大小写可选大写、小写或保留输入。宽窗口下输入与结果并排，窄窗口纵向排列；切换离开工具再回来时会保留方言和排版设置。它只在本机处理文本，不连接数据库，也不执行 SQL。

排版基于 Rust `sqlformat` 库，默认使用 4 空格缩进和关键字大写，并对常见 CTE、JOIN、CASE、窗口函数、注释及表达式进行布局。MySQL 与 SQLite 选项目前使用库的通用词法模式；PostgreSQL 和 SQL Server 使用各自的特殊字符模式。额外保护 PostgreSQL dollar-quoted 字符串和 SQLite 方括号标识符；参数占位符原样保留，不执行参数插值。缩进和关键字大小写仅控制格式化输出，不会重写字符串字面量或参数值。

该库用于格式化 SQL 空白和布局，不提供完整 AST 或语义验证。格式化结果不能证明语句有效；不支持的语法仍可能产生不理想排版。工具不会连接数据库或修改源文本，结果需由使用者检查后再执行。
