# 本地服务管理 1.3.1

从侧栏“本地服务”、工具库搜索、托盘“服务”或全局快捷面板进入。

## 服务定义

新增服务填写固定标识、显示名称、工作目录和启动命令；端口、健康检查、描述可选。高级选项支持 YAML 的 stop_command、stop_timeout_ms、tags、config_files、env，展开前提示其中包含环境变量值。保存仅更新本机配置，不执行命令；服务标识保存后不可改名。

可以按名称、标识、标签、端口搜索，并筛选托管运行、外部占用或已停止。每项显示 PID、端口、健康检查、日志路径与配置摘要。启动/停止/重启在后台执行，单服务显示操作中状态并防止重复点击。

运行中的托管服务须先停止才能编辑或删除。外部端口占用不会被启动覆盖或强制结束。删除需确认，只删除服务定义与自动恢复意图，不删除工作目录、配置文件或历史日志；删除最后一个服务后空配置仍有效。

保存检查原始定义与最新磁盘配置，拒绝覆盖已变化的配置；同目录临时文件同步后原子替换。保留未识别的 YAML 设置及服务扩展字段，但 YAML 格式、注释可能被重新序列化。跨程序在最后一次校验之后的极短竞争窗口没有协作文件锁；出现外部并发修改时建议先刷新。磁盘失败保持编辑器供重试。

## 日志

日志窗口默认每 2 秒后台刷新，支持暂停自动刷新、跟随末尾、大小写不敏感行筛选、复制以及打开完整日志。预览最多 5000 行/4 MiB，不截断原始文件。清空需二次确认；请根据自身需要保留重要日志。日志可能包含业务数据或敏感信息，分享前自行检查。

## 托盘

右键为独立可搜索轻量菜单，跟随 Windows 传入的系统主题；主窗口手动亮暗主题独立。支持收藏、最近、常用、全部、服务标签；服务显示状态/PID/端口，可启停重启并打开桌面日志。工作台、设置、退出按钮常驻；退出沿用未保存任务检查。按 Esc 或点击外部收起，面板无任务栏按钮，不替代桌面完整管理页。

本阶段不增加服务依赖编排、任务计划启动或日志轮转。每轮状态刷新最多使用 8 个工作线程并发检查，单 HTTP 请求超时 500ms；列表保持配置标识顺序。普通定时刷新不重叠；服务操作或配置更新后取消旧轮次的新任务分配，忽略过期结果。已发出的旧请求允许按超时结束，启动前单项检查独立执行。100 个全部超时的服务仍需多轮批次完成，当前功能不等于生产服务管理平台。

## 退出与健康反馈

服务卡片显示本次会话最近的进程退出时间和退出码，非零退出标为异常退出；下一次启动清除旧摘要。摘要只来自本次程序会话启动的子进程，不跨程序重启保存；恢复的旧进程不能补取其历史退出码。完整日志仍保留，成功的用户停止与删除定义会清除摘要。正常结束与启动后立即结束都可以查看退出码。运行进程的健康检查失败在卡片直接显示，HTTP 仅 2xx 视为通过，404/503 不视为健康。此状态是最新轮询结果，不代表启动失败、自动重启或生产告警。

健康失败不等于没有服务监听。HTTP 端点有响应（包括 404/503）时仍标为外部响应，禁止重复启动；不会结束该外部进程。外部响应的健康失败也直接显示在卡片上。

## 重载与读取限制

配置文件在外部修改或切换时，仍在托管的服务必须保留原定义和状态目录，否则拒绝重载并提示先停止；原管理状态保留。增加或修改未运行服务不受该保护影响。PID 记录恢复出的运行服务同样检查。

配置文件预览最多读取 80,001 字节（80,000 字节正文加一个截断探测字节）；日志按打开时长度快照最多读取末尾 4 MiB，之后追加的内容留给下一轮刷新。末尾行收集最多 5001 行用于截断探测；极长单行显示有界末尾片段。未创建日志显示空内容，其他读取错误显示失败，不修改原文件。
