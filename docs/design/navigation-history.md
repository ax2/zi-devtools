# 跨工具后退与前进：接入设计

日期：2026-10-18；状态：设计已落实，本轮固定源码验证完成；未公开发布。实机兼容性边界见下文。

## 用户体验

侧栏固定区域提供后退/前进按钮，悬停显示目标工具和实例名；支持Alt+Left/Alt+Right，存在审核弹窗或输入法组合时不接管。返回工具库保留此前查询、分类、集合和滚动上下文。工具间接力成功后，可返回原工作实例继续查看来源，再前进到接收实例。按钮只导航，不运行工具、不读取文件、不恢复关闭实例、不保存或覆盖数据。

## 当前代码事实

- src/app.rs有open_entry、navigate、navigate_with_visit及各工作台直接切页路径；仅在open_entry追加历史无法覆盖接力、后台任务返回和工作实例切换。
- src/app/navigation.rs以实际图片/数据/录屏子工具ID识别当前入口；Java/Django与插件也需要保留具体工具身份。
- src/workbench/sessions.rs已有Workspace::active_id/select，select在实例不存在时返回错误；modal_open与operation_pending提供审核/保存状态。调用select前仍需统一导航审核门禁。
- src/image_tools/workflow/workspace.rs已有独立实例ID与后台任务所有权；图片流程实例和其它五种图片视图不应混为同一位置。实例选择及审核状态需要受控的上层接口。
- 当前托盘按entry.*导航；旧tool.data分支没有找到现有菜单发送点，不据此声明线上可触发缺陷。

## 拟定模型

History最多保留64个本次运行位置，重启不自动恢复。位置包含稳定路由ID、适用时的数据/图片流程实例ID；工具库另保留筛选和查询快照。不复制输入、结果、数据库连接、文档正文或文件内容。普通重绘及输入编辑不生成历史；同一位置更新展示上下文。后退后打开新位置截断前进分支。

采用统一的当前导航位置描述，供侧栏标题和历史共用。评估在完成本帧导航后观察位置变化，覆盖直接切页路径；如采用观察法，须在导航前保存原位置上下文，防止覆盖旧工具库筛选。历史恢复先验证完整目标，再改变页面/实例，不允许半成功切换。恢复历史的动作不再次创建历史节点。

不可用目标（已关闭实例、停用/移除插件）在历史中跳过并给出简短反馈，不重新创建草稿或启用插件。运行中的后台任务仍可查看，不取消任务；审核、接力确认、退出确认及实例保存/恢复过程禁止切换。历史位置不替代收藏、最近访问或工作实例快照。

## 开发与验收

1. 提取可测试的有界历史状态机：去重、容量淘汰、前进分支截断、失效目标、失败恢复不改变当前位置。
2. 完成当前路由/实例描述及无副作用恢复，覆盖数据七视图、图片六视图、Java/Django、录屏入口、内置小工具、插件、工具库/设置/任务等主要页面。不能以少量页面冒充全局导航。
3. 接入固定可见按钮、准确目标提示与键盘门禁。验证支持的最小窗口尺寸，鼠标和键盘结果一致。
4. 用临时配置和原生窗口验证“数据实例A→图片→数据实例B→后退A/前进B”、关闭目标实例、停用插件、接力确认窗口、后台任务、空历史与新分支；所有来源草稿及结果保持不变。
5. 更新独立工具版本、目录、使用说明与档案，执行完整检查。物理键盘、多屏和真实插件部署仍按实际证据单独列明。

## 实施结论与验收边界

以上设计已落实到src/app/history.rs及其model模块。插件恢复使用既有选择规则（包括清除临时凭据），停用目标跳过；录屏导航仅切换入口，原生回归确认用户选择的音频模式保持。工具库每次访问保存查询、筛选和滚动，恢复使用其独立滚动区域。页面首尾与显式导航入口共同记录位置，覆盖直接切页、实际接力和后台任务返回。
