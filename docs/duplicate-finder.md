# 重复文件检查

在工具目录搜索“重复”或从“文件与系统”进入。明确选择本机目录后，点击“开始检查”；界面显示扫描与读取进度，可随时取消。结果按理论重复逻辑大小排序，展开文件组可查看路径与 SHA-256，并主动复制路径供人工核对。

程序先遍历文件元数据，只读取大小相同的候选文件内容，并按 64 KiB 流式计算 SHA-256。默认最多检查 100,000 个目录条目、24 层深度、20,000 个候选文件、2 GiB 候选内容，整个过程软上限 30 秒；达到预算会跳过整组并标记部分结果。链接、Windows 重解析点、不可读和检查中变化的文件也计入部分结果。取消后已完成的文件组仍可查看。

检查只读，不修改或删除文件。“理论重复逻辑大小”按同一摘要组中保留一份计算，仅用于估算；硬链接可能共享实际存储，文件之后也可能变化。做清理前应先确认路径用途、备份需求和当前内容。
