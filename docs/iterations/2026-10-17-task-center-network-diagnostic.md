# 网络诊断进入任务中心（network 1.1.0，task-center 1.13.0）

日期：2026-10-17\
程序版本：`0.82.0-dev.105`（未更改、未发布）

## 目标与实现

DNS 查询和 TCP 连通测试原先在网络诊断页后台执行，但离开页面后没有统一状态入口。本轮将其纳入任务中心，并支持从任务记录回到网络诊断工作台。

任务行只使用固定标题、固定诊断类型（DNS 解析/TCP 连通性）和通用成功/失败耗时摘要。主机、端口、解析地址、诊断输出与错误原文继续仅保留在对应工作台的内存状态中，不进入任务中心记录。任务使用请求编号保持当前异步操作关联，过期响应不会覆盖较新的诊断状态。

网络诊断工具版本由 1.0.0 更新为 1.1.0；后台任务中心由 1.12.0 更新为 1.13.0。程序开发版本保持不变。

## 边界

网络诊断任务目前不可取消；用户离开页面不会停止后台 DNS/TCP 操作。任务中心只记录最近运行期间的有限任务，不持久化诊断内容。任务行中的类型是发起任务时的快照，后续切换 DNS/TCP 页面不会改变历史类型；已分别验证 DNS 与 TCP 的任务卡片返回路由。
