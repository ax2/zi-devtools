## 目标与行为

第三方日历常用 `RRULE;COUNT=n` 表示有限重复，而本机日程数据用包含截止日期表示重复范围。此次为双方可精确表达的日/周/月/年规则增加有界换算：依本机现有的缺日跳过或月底替代语义，计算第 N 次实际发生日期，并保存为重复截止日；`COUNT=1` 保存为单次日程。

导入预览提示 COUNT 会转成本机截止日期。再次导出使用语义等价的 `UNTIL`，不保留原始 COUNT 语法。`COUNT` 与 `UNTIL` 并存、非正整数、超出 1901–2099 日期范围或不支持的复杂重复条件会拒绝整份导入；没有任何部分写入。原本的 UID 去重、预览确认和事务复核保持不变。

重复计算受日历上界约束：日/周用有检查的日期偏移，月/年只扫描本机可表示的日期范围；没有按输入 COUNT 值执行无界循环。

## 边界

TZID/VTIMEZONE、例外日期、复杂 BYDAY、间隔大于 1、UTC 重复以及原始规则语法保留仍未支持。该换算只覆盖本机模型明确支持的简单规则，不宣称完整 RFC 5545 或第三方日历客户端兼容。应用版本未变，未打包或发布。
