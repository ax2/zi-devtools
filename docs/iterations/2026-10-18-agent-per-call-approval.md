# Agent MCP 工具逐次确认

日期：2026-10-18\
工具：Agent 任务工作台 `1.10.0`\
程序版本：`0.82.0-dev.105`（未发布）

## 目标

让 Agent 在保留原有低影响只读直调规则的同时，允许用户在审阅确切工具与参数后，决定是否发送其他已列入本次白名单的 MCP 调用；拒绝时必须在调用发出前停止。

## 实现

- 检查阶段保留没有被显式禁止的工具。具备完整低影响只读声明且获得直接许可的工具标为直调；其他工具标为逐次确认。
- 计划获批后，模型提出每次调用时 UI 显示工具名和完整 JSON 参数，用户可以“仅批准这次调用”或“拒绝并停止任务”。计划批准本身不预先批准后续工具参数。
- 发送前重新读取当前权限文件、检查服务范围及工具定义。拒绝、取消、界面关闭或显式禁止时不会发送待确认调用。
- 在确认区说明 MCP 服务不是进程沙箱，工具参数不能限制服务的其他副作用，已执行的外部操作可能无法撤销。
- 保留原 `execute` API 的失败关闭行为；只有明确提供审批回调的执行入口能执行逐次确认工具。

## 边界与遗留

- 逐次确认只授权一次具体 MCP 调用，不构成沙箱、字段级/路径级数据范围控制或回滚机制。只能对可信服务使用。
- 这是允许更多用户授权数据操作的第一步；统一本机文件写入动作、范围授权管理、撤销语义和审计策略仍需单独设计与验收。
- 未运行真实 Ollama 服务验收；合成截图不证明特定桌面缩放/DPI 下的人工操作体验。目录同步检查通过；未发布程序或安装包。
