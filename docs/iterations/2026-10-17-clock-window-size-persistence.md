# 时钟小窗尺寸跨重启保存

日期：2026-10-17\
工具版本：全功能时钟 0.7.0\
程序版本：0.82.0-dev.105（未发布）

## 目标

让用户在启用时钟本机保存并确认恢复后，重新打开独立小窗时沿用相同目标上次调整的尺寸；避免在数量较多的小窗目标间重复调整。

## 实现

- 把最多48个小窗目标的逻辑宽高写入时钟快照，尺寸取整数逻辑点并受窗口最小/最大尺寸约束。
- 使用稳定目标键区分世界时区、秒表、计时器ID和专注计时器；校验未知目标、重复目标、越界尺寸、无效ID和数量上限。
- 仅在用户确认恢复后载入尺寸；原快照读取仍只显示预览，不自动改动当前会话。
- schema 1/2 旧快照仍可恢复；升级会在同目录以原始字节备份对应旧 schema。旧快照没有小窗尺寸时仍采用默认尺寸。
- 小窗打开状态、屏幕位置、显示器信息不保存，恢复也不会自动创建原小窗。
