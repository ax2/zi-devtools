# 图片缩放插件 0.2.0 输入契约修订

## 目标与发现

继续独立 DevTools 向 Studio 提供可检索、可组合的工具候选。图片插件仅提供单张已授权图片的缩放，不把独立版完整图片工作流标为完成。

最初 0.1.2 的字符串 pattern/not 通过了标准 JSON Schema 和 profile 静态检查，但只读审查当前 Studio 安装声明校验发现输入 schema 不支持这两个关键字。0.1.2-candidate-01 与目录9bb54349d84c0e48只保留为失败的中间证据，不作为安装候选。不修改冻结目录。

输入和输出校验器是分离的：输出支持 oneOf，因此 URL 0.1.1 成功/失败分支不受本问题影响。该结论来自源码检查，不是实机安装结果。

## 修改

0.2.0 清单使用整数宽度1–4096、JPEG质量35–95，默认1600/82，明确PNG/WebP无损。新Rust适配器接受整数，并保留旧字符串读取兼容；Host清单只允许整数。增加media分类、中英文别名、PNG/JPEG/WebP资源过滤。权限、路由和成功输出schema保持不变。

增加输入关键字子集回归，防止标准schema检查掩盖Host声明不兼容。新运行证据覆盖9种格式、9项旧字符串参数一致性、4项参数拒绝和1项坏图零输出；补充9项当前原生/WASI字节比较。

## 边界

使用本项目共享核心和现有缓存，不导入Studio私有代码、配置、数据库或运行其EXE。Studio只读源码和公开检查脚本仅用于兼容性审核。无签名、无安装、无发布，Host完整接受仍为0。小样本不证明16MP性能、生产10秒生命周期、并发、取消、权限、资源登记和跨工具接力。
