# 接力目标方向键导航

## 目标与交互

百个工具的选择不应依赖逐项Tab。搜索框聚焦时，↑↓按实际显示顺序选择目标；首次↓从第一项开始，首次↑从末项开始，边界停留。推荐目标和普通目标共用顺序，已过滤或材料不兼容的项不能进入导航。

方向键只改变本次选择，并让对应行滚动到可见位置，不接收、不写文件、不运行目标。选择后Tab直接聚焦底部确认按钮，仍需明确按Space/Enter或鼠标点击按钮接收。没有经过目标选择时保留标准Tab顺序；搜索框Enter不新增自动接收行为。

改变查询/分类/范围会重置键盘位置，但保留已选目标与源快照。空结果时方向键不改变选择。分类菜单打开、其他控件聚焦或输入法组合期间，不消费其方向键/Tab。IME组合结束的当帧也不导航。

纯导航测试覆盖显示顺序去重、过滤、不回绕边界、空/变化结果、焦点与IME事件守卫。原生明暗夹具覆盖预编辑期间方向键无效、取消预编辑后的正常推荐顺序、搜索保留原选择、过滤为空、从末项开始并自动滚动、Tab到确认和Space接收一次。
