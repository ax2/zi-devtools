# 类型化资料库回收站与恢复（artifact-hub 0.9.0）

日期：2026-10-17\
程序版本：`0.82.0-dev.105`（未更改、未发布）

## 实现

类型化资料库的删除操作现在先把条目标记到独立回收站表，保留资料行与所有不可变版本。普通列表和回收站使用独立查询；回收站可以按名称或当前版本正文搜索，内容只读。恢复时按当前版本号复核，成功后返回正常资料列表；草稿未保存时拒绝恢复或切换列表。移入回收站后，旧窗口即使尝试按原版本号写入新版本也会被拒绝。永久删除只能从回收站再次发起并明确确认，操作按版本复核后级联删除资料及历史版本，不触碰来源文件。

为兼容已有本机资料库，回收站表在首次用户删除时才创建，不更改原 SQLite schema 版本。新数据库和已有 v1 数据库都沿用原资料读取路径。配额按库内所有版本统计，移入回收站不会立即释放资料库配额；永久删除后才移除对应数据。

资料库工具版本从 0.8.0 提升到 0.9.0。程序开发版本仍为 `0.82.0-dev.105`。

## 验证

- eframe 合成鼠标点击“恢复到资料列表”通过；证明条目从回收站消失、回到普通资料列表且原记录仍存在。截图与机器证明：`screenshots/artifact-hub-trash-20261017/`。

## 边界

恢复只撤销回收站标记，不恢复已经永久删除的资料。回收站仍占用资料条目和版本容量；本轮未实现自动清空期限、批量恢复或按库空间自动清理。永久删除是明确不可恢复的用户操作。
