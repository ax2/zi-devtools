# 类型化资料库历史版本差异比较（artifact-hub 0.10.0）

日期：2026-10-17\
程序版本：`0.82.0-dev.105`（未更改、未发布）

## 实现

资料库打开历史版本后，可选择“与当前版比较”。系统在单个 SQLite 读事务中读取所选历史版和最新版本，校验两版 SHA-256，再生成只读逐行差异；新增行以绿色显示，删除行以红色显示，相同行作为上下文。差异独立折叠显示，不替换编辑器中的历史版内容，也不写入资料库。

为了保证界面响应，比较输入两版合计最多 2 MiB；超过时明确提示仍可查看原版本，不生成差异。输出硬限制为 64 KiB，超出时按 UTF-8 字符边界截断并标记。相同内容显示“两个版本内容相同”。

资料库工具版本从 0.9.0 更新为 0.10.0。程序开发版本仍为 `0.82.0-dev.105`。

## 验证

- 专项测试覆盖新增/删除行、读取期间不改变版本、相同版本、输入超限拒绝、64 KiB输出截断。
- `capture_ui` 合成鼠标点击“与当前版比较”，验证 v1→v2 结果和只读状态；深色界面截图见 `screenshots/artifact-hub-version-diff-20261017/`。
- `cargo test --offline --locked --features ui-preview --quiet`：947 项通过、27 项忽略、0 失败；集成测试50项通过、9项忽略。
- `cargo clippy --offline --locked --all-targets --features ui-preview -- -D warnings`、`cargo fmt --check`、工具目录/Studio插件映射生成与 `--check`、`git diff --check` 通过。

## 边界

这是 UTF-8 文本的逐行差异，不做 JSON/CSV 语义合并、二进制比较、冲突解决或历史版本恢复。超过输入上限仍可从版本选择器手动查看历史内容。
