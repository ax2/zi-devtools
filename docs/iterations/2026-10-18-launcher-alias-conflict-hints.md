# 启动器精确词重名提示（2026-10-18）

## 目标

保持插件可扩展，同时避免动态插件与内置工具共用精确名称/别名时，搜索界面看不出同词存在多个入口。

## 实现

- 目录排序先识别精确名称、稳定 ID 与别名命中；仅当多个入口同时精确命中时，为这些条目标记同词入口数。
- 工具库与全局启动器在匹配原因处显示“同词还有 N 个入口”；工具库的悬停说明也包含完整提示。
- 不隐藏插件、不修改评分或自动选择；结果名称、分类和“插件”标记继续供用户比较。
- 全局快捷启动器工具版本升级到 `1.6.3`，程序版本保持不变。

## 验证

已添加注册表回归测试，用合成插件与内置 JSON 工具共用精确别名，断言两条结果都显示冲突数量；本轮尚未执行 Cargo 测试。内置目录独立审计覆盖 ID、名称和别名，确认 112 个已路由工具之间没有完全相同的精确词。`cargo fmt --check`、目录生成与 `--check`、内置别名审计和 `git diff --check` 均通过。E: 可用空间不足 180 MB，保留现有缓存并跳过 Cargo 测试。
