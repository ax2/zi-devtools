# 内置搜索精确词目录门禁（2026-10-18）

## 目标

阻止内置工具的稳定 ID、显示名称或别名在规范化后指向多个已接入路由；动态插件仍可扩展，发生重名时由启动器显式提示。

## 修改

- `scripts/sync_tools.py` 将已接入工具 ID、显示名称和搜索别名纳入同一跨路由精确词唯一性门禁；同一工具自身名称与别名重叠允许通过。
- 精确词规范化与冲突校验拆到 `scripts/catalog_validation.py`，新增 4 个 Python 单测覆盖 NFKC/空白/大小写冲突、同工具重复词、未路由规划项，以及与 Rust runtime 小写规则一致而不做 casefold 扩展，并接入 CI。
- 注册表回归测试覆盖插件别名与内置别名冲突，以及插件精确名称与内置别名冲突，确保所有精确匹配条目显示替代入口数。
- 新增全目录注册表回归测试，逐项断言所有已接入工具的 ID、显示名称和别名搜索结果首位均为该工具；本轮未能执行该 Cargo 测试。
- 全局快捷启动器工具版本升至 `1.6.4`；程序版本保持不变。

## 验证

运行完整 `scripts/tests`（23项通过）、目录生成与 `--check`、内置 ID/名称/别名独立审计、`cargo fmt --check` 与 `git diff --check`。Cargo 测试未运行：E: 空间仍不足以安全编译，且项目约定保持现有本地 target/cache。
