# 计算器非线性方程区间求根（0.14.0）

日期：2026-10-17\
程序版本：`0.82.0-dev.105`（保持不变，未发布）\
独立工具版本：全能计算器 `0.14.0`

## 目标与实现

落实全能计算器路线图中尚未实现的非线性方程能力。新增独立区间二分工作区，用户提供实数公式 `f(x)`、递增端点、区间宽度容差和最多 200 次迭代，再主动启动计算。算法复用已有受限表达式解析器，不执行脚本或访问网络/文件；可读当前变量及 RAD/DEG 设置。求解变量 `x` 仅在本次计算快照中覆盖同名变量，不修改计算器变量。

只有端点为零或函数值异号时才接受区间。结果显示 f64 近似根、残差及迭代数。收敛结果可复制或通过既有数值接力发送为 1×1 f64；任何公式、区间、容差、迭代数、变量或角度变化都会使结果过期，过期与未收敛结果均不能接力。根不会改写 `ans`、表达式历史或矩阵。

工作表升至 schema 8，保存求根工作区与输入草稿，旧 schema 1–7 保持可读；恢复后不保存或自动重放派生根。工具目录登记独立版本及能力边界，程序开发版本不变。

## 限制与风险

只搜索用户给出的单个区间，要求变号；偶重根可能漏检。算法不证明函数连续，间断点会导致变号但不是真根；残差供用户判断，不构成误差证明。非收敛结果只显示状态，不允许复制/接力。当前不提供多根扫描、牛顿法、复数根或符号 CAS。
