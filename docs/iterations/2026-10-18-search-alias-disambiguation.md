# 搜索别名去歧义（2026-10-18）

## 目标

消除工具目录中完全相同的跨工具搜索别名，让明确的精确词只对应一个可见路由，并防止后续重新引入冲突。

## 发现与修改

- “表格流程”同时指向可组合数据管线与文本 / 表格流程；数据管线别名改为“数据转换管线”。
- “闹钟”同时指向全功能时钟与万年历日程；日程工具别名改为“事件提醒”，时钟保留“闹钟”。
- `scripts/sync_tools.py` 在 Unicode NFKC、空白折叠和大小写规范化后检查所有已接入路由间的别名唯一性。
- Rust 注册表回归测试再次检查运行时目录的规范化别名唯一，并断言四个专属词各自只有一个精确别名命中。
- 全局快捷启动器工具版本升级至 `1.6.2`；程序版本保持不变。

## 验证

运行目录生成与 `--check`、独立别名冲突审计、`cargo fmt --check` 及 `git diff --check`。Cargo 测试未运行：E: 仅剩约 180 MB，可用空间不足以安全编译；保留现有缓存，不做清理。
