# 截图工作台局部模糊遮挡（2026-10-17）

## 目标

在截图选区上提供比像素化更柔和的局部处理，并维持透明套索、羽化、原图重算和独立撤销/重做行为。

## 实现

- 新增“模糊”矩形标注，默认半径12px，可调范围4–32px；至少拖出2×2输出像素，拖动时显示范围，松开后后台生成实际预览。
- 对选区矩形使用水平、垂直两次滑动窗口盒式均值模糊，按alpha加权颜色；仅写入非透明像素RGB，保持原alpha以及矩形外的全部像素。
- 工作缓冲按选区大小惰性分配，上限不超过输出图像面积；使用可失败的容量预留，内存不足时交给现有失败恢复逻辑保留上一有效预览。
- 与文字、箭头、像素化和黑色遮挡共用100项撤销/重做历史；所有修改仍从捕获源、选区和羽化重新渲染。
- 独立截图工具版本升至0.13.0；程序开发版本保持0.82.0-dev.105。路线图仍保留渐变遮挡、置顶截图和多屏等事项。

## 遗留与边界

- 当前是边界裁剪的双向盒式模糊，矩形边缘保持明确；未实现羽化模糊边界或渐变覆盖。
- 模糊只能弱化细节，不保证无法反向辨认；处理敏感信息应使用不透明黑色遮挡并检查输出。
- 盒式模糊缓冲惰性申请且不超过选区像素数，但编解码器、GPU和截图工作台其他内存仍不计入单一总进程预算。
