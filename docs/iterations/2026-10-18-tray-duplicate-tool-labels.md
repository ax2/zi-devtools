# 托盘重复工具标题消歧（2026-10-18）

## 目标

让托盘的“全部工具”、收藏、最近和常用入口在标题重复时仍可区分，尤其是内置工具与动态插件同名的情况。

## 修改

- `Navigation::new` 检查托盘工具标题；重复标题附加工具分类。
- 如果附加分类后仍有相同标题，再附加稳定工具 ID。
- 原生菜单标题超过 36 字符时省略中间部分，保留前缀和末尾分类/ID，避免长度限制再次隐藏区分信息。
- 标题冲突检测与启动器搜索一致，使用 NFKC、大小写和空白规范化。
- 所有托盘快捷列表复用同一份展示标题，不改变工具 ID、排序、收藏或打开行为。
- 全局快捷启动器版本提升至 `1.6.7`；程序版本不变。
