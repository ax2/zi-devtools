# 目录工作台自适应布局 — 下一轮实施计划

日期：2026-10-18；状态：已核对截图与源码，尚未修改产品布局。

## 已观察的问题

本轮最终原生深色截图 progress-dark/progress-2.png（1500×1125 像素，逻辑窗口1200×900）中，第三张汇总卡片超出右侧可视区域。源码使用固定540点来源输入、420点目标输入和不换行的横向工具栏；长路径、文件名与结果文字可能扩张滚动区域内容宽度。根因仍须通过布局几何和对比截图确认，不能只假定是三列卡片本身。

## 实施边界

保留比较、预览、明确执行、无覆盖提交和任务取消语义。根据当前可用宽度分配路径输入；窄窗口将路径和操作分行，汇总卡片可堆叠。长路径保留完整悬停提示和可编辑内容，文件行不得把操作挤出可视区域。不修改复制权限、上限或发布版本。

## 验证要求

采用真实原生渲染，分别检查1200与900逻辑宽度、浅色与深色、长中文/英文路径；记录控件完整矩形与裁剪矩形，避免仅检查中心点掩盖部分裁切。实际点击预览/返回/取消，并回归现有复制与重试流程。截图检查文字可读性、布局层级及操作可达性。受控输入不能替代物理多屏DPI验收。
