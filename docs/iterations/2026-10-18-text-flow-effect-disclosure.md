# 文本流程动作影响提示

日期：2026-10-18\
程序版本：`0.82.0-dev.105`（未更改、未发布）\
工具版本：`text-flow 1.13.0`

## 目标

用户希望程序支持更多本地数据操作，同时在执行前知道具体影响。流程动作原先主要用说明文字描述行为，搜索结果、已添加步骤和运行入口没有统一的影响分类。

## 修改

- 动作目录增加影响类型：纯转换、读取所选文件、处理本次内存图片。
- 搜索结果和步骤清单显示影响类型，悬停可查看具体边界。
- 运行按钮汇总当前流程会产生的影响，并提示不会自动保存或联网；另存完整结果继续使用独立确认，只创建新文件。
- 测试保证所有动作都有影响声明，文件读取只出现在 `file.sha256`，图片信息只处理内存图片。
- 更新 `text-flow` 工具版本至 1.13.0、使用说明和目录清单。
