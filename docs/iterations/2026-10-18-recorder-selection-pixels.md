# 2026-10-18 录屏框选物理像素与交互修复

程序保持 `0.82.0-dev.105`。屏幕录制 `1.1.1`、显示器选择录屏 `0.1.2`、教程辅助 `0.11.2`。

## 发现与实现

- 原尺寸标签直接显示 egui 界面点数，缩放后与录制像素不同。`Region::selection_bounds` 统一预览/提交的坐标换算、裁边、舍入和偶数宽高规则，并拒绝非有限坐标或无效尺寸。
- egui 超过拖动阈值后才报告 drag_started，旧代码把此时的位置当作起点。现在保留 pointer.press_origin，恢复鼠标真正按下的起点。
- 原显示器验证错误被 `.ok()` 丢弃，再误报选区过小。现在有效候选提交时保留错误原因，关闭浮层、请求恢复主窗且不覆盖旧选区。
- 浮层绘制提取到 `src/recorder_ui/selection.rs`，生产入口与合成原生验收夹具共用。错误提示当帧显示、重试清除，提示宽度由实际排版决定，窄窗口缩小字号并换行；像素尺寸标签带独立深色底板。
