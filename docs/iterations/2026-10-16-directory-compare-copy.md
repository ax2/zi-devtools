# 目录内容对比：受控复制（1.1.0）

日期：2026-10-16\
程序版本：0.82.0-dev.105（保持不变）

## 目标与实现

将“完整目录比较结果中的文件差异”接入明确授权的本机写入流程，同时保留比较本身的只读行为。用户勾选差异文件、指定来源侧和目标目录后，工具在后台构建复制计划，预览源大小、SHA-256 和目标冲突，再由用户点击“执行复制”。

计划只接受完整比较报告里已判定的普通文件差异；拒绝部分报告、无关选择、重复路径、链接/重解析路径、目标位于源目录中、无效相对路径以及超过 1,000 个文件或 2 GiB 的计划。源文件在计划生成时流式求摘要，执行时重新读取并比较预览摘要及文件元数据。每个文件通过同目录临时文件和原子无覆盖发布提交。冲突、来源变化、失败与取消逐项汇报；取消会保留已经提交的文件。

本轮未加入覆盖、同步、移动、删除或自动撤销；文件系统写入已完成的部分不会因后续失败而回滚。工具版本从 1.0.0 提升到 1.1.0，程序开发版本不变。

## 遗留与边界

物理鼠标/触屏设备尚未验收。自动化 eframe 界面流程已覆盖勾选、预览、执行和来源保留；API 单测覆盖冲突、变化、取消和不覆盖。目标父目录创建后若后续复制失败，空目录可能保留。单文件发布具有原子无覆盖保证；多文件批次是逐项提交，不是整体事务。
