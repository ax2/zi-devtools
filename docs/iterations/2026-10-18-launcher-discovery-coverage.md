# 工具检索元数据覆盖

日期：2026-10-18\
程序版本：0.82.0-dev.105（未变更）

## 发现

审核 `docs/tools.json` 的 92 个已实现工具时发现，55 个条目没有任何用途别名，38 个条目没有搜索关键词。工具仍可按名称或稳定 ID 搜索，但跨语言和按任务描述查找的覆盖不均，随着工具数量增长会让用户更依赖精确名称。

## 修改

- 为原本缺少别名的 55 个已实现工具补充中文和英文用途别名，并加入中英文关键词；为另外 5 个已有别名、但缺少关键词的工具补齐关键词。
- `scripts/sync_tools.py` 新增目录质量门禁：已实现工具至少有两个 NFKC 规范化后不重复的别名，并提供非空关键词。以后将工具标为已实现时若未补齐发现信息，目录同步会失败。
- 全局快捷启动器从 `1.5.2` 升至 `1.6.0`；程序版本仍为 `0.82.0-dev.105`。已重生成工具清单、README、路线图目录计数及插件迁移快照。
- 更新 `docs/navigation.md` 与 `docs/tool-versions.md`，说明搜索元数据门禁和工作区集合 `0.3.0` 的真实范围。

## 验证

- 逐项检查当前 92 个已实现工具：每项至少两个唯一别名且关键词非空；重复项为 0。
- `python -B scripts/sync_tools.py` 与 `python -B scripts/sync_tools.py --check` 均通过，报告 92 项已实现、62 项规划或开发中。
- `git diff --check` 通过。此次未改 Rust 搜索算法；E 盘余量低，未运行 Cargo 构建。原生检索排序与别名评分沿用既有测试覆盖，本轮校验关注清单元数据和未来同步门禁。

## 后续补充：覆盖所有已接入路由

进一步按 Rust 工具与页面注册表审计发现，112 个实际可见路由中有 92 个已实现、20 个开发中；唯一残留缺口是“显示器选择录屏”没有别名。已为它补充“多显示器录屏 / multi-monitor recording”，并将目录质量门禁扩展到所有已接入路由。全量复核 112 个入口后，别名/关键词缺口为 0；全局快捷启动器版本升至 1.6.1。
