# 2026-10-16 工具版本历史入口

状态：开发中功能的版本追踪 UI 已接入并通过全量代码验证；程序版本保持 `0.82.0-dev.105`，不改动任何工具的独立版本。

## 目标与实现

工具库已显示每个工具的独立版本，但内置工具的 `version_history` 原先没有进入运行时目录，也没有统一的查看入口。本轮将内置目录与插件清单的历史记录映射到同一工具条目，并在工具库每行增加紧凑“版本”菜单，显示当前版本/开发状态，以及按时间倒序排列的日期和变更摘要。菜单以“当前版本”标签区分当前状态与历史首条记录；长历史使用可滚动菜单；旧插件没有历史时明确显示“此工具尚未声明版本历史”，不从插件包版本推断。

历史记录在目录项克隆间使用共享 `Arc`，避免搜索排序时重复复制记录。维护规则、路线图与导航说明同步更新；没有更改工具目录版本或程序版本。
