# 动态插件搜索目录项缓存（2026-10-18）

## 目标

快捷面板和工具库在 UI 重绘期间会多次调用 `entries(query)`。内置目录已用 `OnceLock` 预建，但每次仍会从所有启用插件重新构造 `ToolEntry`，重复规范化名称、说明、别名及版本历史。

## 修改

- Store 加载插件目录时预建精确失效键：已加载包的 ID、清单 SHA-256 和启用状态；每帧只比较借用切片，避免重新分配键集合。
- `DevToolsApp` 缓存插件对应的 `ToolEntry`；包新增/移除、内容摘要改变或启停时重建。
- 每次搜索仍按当前查询词和收藏/最近/频次偏好评分与排序，插件冲突提示仍按本次结果计算。
- 新增插件目录键回归断言，覆盖安装、启用、重新加载与清单摘要变化，并将全局快捷启动器版本提升至 `1.6.8`；程序版本不变。

## 验证与限制

- `cargo fmt --check`、工具目录同步检查、23 项 Python 测试和 `git diff --check` 通过。
- Rust 测试因 E: 可用空间仅约 170 MiB 而未运行。插件回归断言及运行时缓存行为仍需 Cargo 测试验证。
- 本改动只缓存插件目录项的构造，不缓存查询评分/排序，也不是针对数百插件的性能基准；重绘负载改善程度仍待测量。
