# 截图工作台原生文字标注（2026-10-17）

## 目标

让用户在透明截图预览上直接添加教程步骤文字，减少截图与图片编辑器之间的切换，同时保留原图重算、撤销/重做与透明选区。

## 实现

- 新增文字模式：输入一行1–80个非控制字符，设置12–96px字号；移动鼠标时显示红色文字预览，点击透明 PNG 预览确定位置。
- 使用图片编辑器共用的 Windows 本机字体加载和字形栅格化；实际文字为红色、带深色抗锯齿描边。缺少字体或字形时，后台渲染报错并恢复上一次有效标注状态。
- 字形只写入当前已有非透明像素，不会把套索外部或羽化为零的像素涂成不透明；文本内容与字号随标注进入100项撤销/重做历史，并在重新选择、羽化和选区历史中保留/重算。
- 独立截图工具版本升至0.12.0；程序开发版本保持0.82.0-dev.105。同步截图工作台说明、工具版本页、产品路线图、工具目录和来源证明版本映射。

## 遗留与边界

- 多行文字、字体/颜色选择、文字位置拖动编辑和文字对象选中/删除仍未实现；本轮通过点击添加并以撤销移除。
- 不支持系统缺失的字体字形；遇到缺字时可通过图片编辑器接力并选择其他字体。
- 模糊/渐变遮挡、置顶截图、真实多屏和混合 DPI 验收继续保留在路线图中。
