# 目录复制预览状态与批量选择（目录内容对比 1.2.0）

日期：2026-10-16\
程序版本：0.82.0-dev.105（保持不变）

## 目标与修改

复查 1.1.0 目录复制交互后发现，预览生成后仍可编辑目标路径和来源侧，用户可能看到已改变的设置却执行旧计划。现在任何来源侧、目标路径或文件选择变化都会清除旧预览和上次结果；预览生成/执行过程中锁定比较路径、来源、目标和选择，避免后台计划与可见设置脱节。预览区明确显示实际目标目录，完整路径可悬停查看；完成结果展示相对路径以控制长路径占位。

为减少大量差异逐项勾选的成本，筛选当前最多 100 条可见差异可批量加入选择，也可清空；界面显示已选数量、估算字节和 2 GiB 超限提示。选择仍受 1,000 项限制，且批量操作不包括目录、未校验内容或当前筛选不可见的行。

目录内容对比工具版本升至 1.2.0，程序版本保持不变。

## 遗留

自动化 eframe 使用合成指针事件；物理鼠标、触屏、多显示缩放尚未验收。批量选择仅作用于当前筛选下实际显示的最多 100 行；更大集合需要缩小筛选范围后分批操作。多文件复制仍为逐项提交，不是整体事务。
