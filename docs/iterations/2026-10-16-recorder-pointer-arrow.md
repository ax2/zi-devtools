# 教程录屏方向箭头与当前位置聚焦（0.5.0）

日期：2026-10-16\
程序版本：`0.82.0-dev.105`（未更改、未发布）\
工具版本：教程录屏辅助 `0.5.0`（开发中）

## 目标与实现

教程录屏新增一个默认关闭的方向箭头指针，用于在讲解中指示鼠标指向的位置。箭头采用白色填充和深色描边，按输出画面大小缩放；固定/跟随放大模式使用现有坐标映射，边缘自动裁切。指针在缩放裁剪范围外时不绘制。合成发生在鼠标提示之后、步骤编号之前，预览与导出视频复用同一路径。

UI 提供“方向箭头指针”开关，设置沿用已有实时更新逻辑。示例预览默认展示该效果；关闭全部效果会复位为默认关闭。功能只绘制鼠标方向箭头，不采集或显示键盘内容。

此外新增默认序列 `R F`“聚焦放大到当前鼠标位置”。它读取一次 Windows 物理指针坐标，减去显示器桌面原点和用户选区偏移，转换成录制区域内的归一化焦点并切换到固定放大。鼠标位于选区外时保持原设置并显示原因；该动作不修改录制区域或鼠标位置。`R Z`仍用于切换连续跟随放大，用户可在快捷键设置中调整序列。
