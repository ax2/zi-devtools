## 目标

消除实现约束文档中与当前 MSI 模板冲突的过期陈述，同时保留历史版本记录的时间语境。

## 对照证据

- `packaging/windows.wxs` include `explorer.wxi` 和 `explorer-ui.wxi`；共享模板定义 perUser 安装菜单选项及安装器事务自定义动作。

- 既有 Hosted Windows 历史证据证明指定版本的文件/文件夹/背景菜单可见及公开旧版升级流程，但不证明当前未提交版本安装验收、现代菜单、多选或工具内容导入。

## 修改

更新文档状态摘要及“基础/缺口”段落，明确区分 MSI 生命周期动作与便携设置页能力。将旧版本章节内容保留为当时验证记录，不把历史缺口改写成当前事实。没有修改程序代码、应用版本或工具版本。
