# 结构化数值表接力到计算器

日期：2026-10-17\
程序版本：`0.82.0-dev.105`（未更改、未发布）

## 修改

统一“发送结果到工具”面板现在为结构化表格提供计算器推荐目标。只有完整表格符合1–8行、1–8列且每格能转换成现有计算器数值类型时，该目标才可选。确认界面说明矩阵尺寸和当前列顺序；列名不会送入矩阵。用户仍需选择A/B，并按原计算器规则明确许可替换未保存的目标矩阵；接收不计算、不回写表格。

转换复用数据工作台的精确数值解析：整数、精确分数/类型对象保留原值，JSON小数保留为近似值；空值、布尔、普通文本以及超出尺寸的表格不提供计算器目标。更大的表格仍可在数据工作台选取行列范围。若用户在接力面板把目标从计算器切回资料库/数据工作台，原始结构化表格载荷会恢复，避免把矩阵JSON误存为表格。

同步工具版本：`pipeline` 0.21.0、`text-flow` 1.11.0、`artifact-hub` 0.8.0、`advanced-calculator` 0.13.0。程序开发版本不变。

## 边界

直接送入矩阵时必须使用完整数值矩形，不支持在接力弹窗中挑选子行/列；此时请先在数据工作台使用现有范围选择器。目标仅表示填入矩阵，不自动运行运算。接收仍受计算器后台I/O和未保存内容保护约束。
