# 目录内容对比

从“文件与系统”或工具搜索打开，分别选择两个本机普通目录，点击“开始对比”。工具按**原样大小写的相对路径**配对文件和目录；空目录、单侧路径和文件/目录类型冲突也会列出。两侧同路径文件先比较逻辑大小；大小相同才流式读取双方内容并计算 SHA-256。结果可按路径或差异类型筛选，点击“导出差异 CSV”后才在用户选定位置保存，不覆盖已有文件。CSV 记录相对路径、两侧类型/大小、已计算摘要与本次覆盖状态；危险的电子表格公式前缀会在路径字段前加单引号。

默认每侧最多扫描 50,000 个条目、24 层，整个任务的软时间上限为 45 秒；最多尝试 10,000 个同大小文件对，实际读取内容总预算为 2 GiB。后台进度可见，可随时取消。链接及 Windows 重解析点、不可读项、深度或条目上限都会造成部分结果；摘要预算不足或检查中发生变化的文件保持“未校验”或相应错误状态。

**只有两侧目录均完整枚举时，才会断言“仅左侧/仅右侧”。**任何一侧不完整时，单侧可见项计入“未判定单侧项”，不会当作缺失导出。同大小且 SHA-256 相同只说明本次读取时一致，文件之后可能变化；相对路径仅按原样大小写配对，大小写不同的名称可能显示为两条。

需要复制时，只能从完整比较报告中选择已判定差异里的普通文件，并选择左侧或右侧作为来源。可以将筛选结果中当前页显示的最多 100 项批量加入选择，或清空选择；界面显示已选文件数和估算字节数。生成预览会在后台重新读取源文件，记录大小和 SHA-256，并检查目标冲突；目标目录不能位于来源目录内。计划最多 1,000 个文件、2 GiB。预览明确显示来源侧、目标目录和每个相对路径；如果目标缺少子目录，也会去重并逐条列出执行时要新建的目录。来源侧或目标目录发生变化时，旧预览立即作废，后台生成/执行期间相关输入会锁定。用户查看预览后再点击“执行复制”，每个文件会以 64 KiB 缓冲流式复制，复制中重新校验摘要与文件状态，并通过同目录暂存和原子无覆盖提交发布。执行时会再次校验来源与目标目录的文件系统身份；任一目录即使被另一个普通目录替换到相同路径也会逐项拒绝写入。目标在计划后出现、来源或目标变化、路径无效或读取失败会逐项报告。已有目标会跳过。取消后已成功发布的文件保留，不会回滚或删除；关闭程序时会取消尚未完成的复制任务，已提交文件保留。工具不覆盖、同步、移动或删除文件；只有用户明确执行复制后，才会向选定目标写入新文件。

每份预览只允许执行一次。执行完成或取消后，若需要重试未完成项，先重新生成预览；这样会刷新目标冲突状态，并防止重复提交旧计划。

复制完成或取消后，点击“仅选择未复制项”会排除已成功的文件，选中冲突、失败、路径不可用和未处理的项目。上次结果保持可见，该操作不会写入文件。按需更换目标目录，再生成新预览并明确执行；冲突不会自动覆盖，新的预览会重新读取来源并计算摘要。

目录扫描、生成复制预览和执行复制会显示在后台任务中心。切换工具后仍可查看状态、取消并返回当前目录工作台；取消后已复制的文件保留。预览取消不写目标。出现冲突、失败或扫描覆盖不完整时不会显示为全部成功。正在扫描、预览或复制时会阻止升级重启。

执行复制时，目录页与任务中心同步显示已处理/总项目、成功/冲突/失败数、已提交字节，以及当前文件暂存字节。进度条是处理进度，并非成功率；暂存文件完成校验和原子提交后才计入成功。取消后当前暂存文件清除，已提交文件保留。

目录页会根据窗口可用宽度调整路径输入与操作行；窄区域的汇总卡片改为单列，长文件名独立换行显示。输入框仍支持编辑完整路径及悬停查看，不因缩窄窗口而改变实际复制路径。

差异列表、待复制文件预览和待建目录预览各自分页，每页100项，支持前后翻页及页码跳转。跨页和筛选保留已选项目；筛选变化返回结果首页，新比较/新预览重置对应页码。批量选择只加入本页，生成复制预览时仍包含全部已选文件。最多选择1,000项，达到上限仍可取消已有选择。翻页或筛选不会写入目标，也不会改变已生成计划的实际文件范围。

复制结束后，旧执行计划默认收起，仍可展开查看。执行结果显示总数、成功数与未复制数，可按全部、未复制、成功、冲突、失败、未完成分类，或筛选路径和错误内容；结果每页100项。存在未复制项时默认突出这些项目。取消时尚未收到成功/冲突/失败结果的文件标为未完成，可能包含已经开始暂存但未提交的当前文件。首次查看结果或改变分类/筛选/页码时定位结果标题，普通浏览不强制回到顶部。审阅不会改变计划、文件选择或自动重试；需要重试时仍先重新预览，再明确执行。

目录差异和复制结果均可点击“发送筛选…到数据工作台”，将当前分类/查询的全部匹配行跨分页传递。确认窗口显示冻结快照范围、行列数、覆盖/取消状态及前三行预览；确认后创建独立CSV/JSON实例，保留原实例，默认折叠原始输入并展示结果表。文件大小保持数字，缺失值保持NULL；表内保留来源/目标根目录和部分扫描或取消信息。不会重新扫描、读取或复制文件，新实例不自动保存；可以在工作台继续筛选、排序、保存或导出。超过10,000行或JSON表示2MiB、路径无法准确转为Unicode时明确拒绝，不静默截断；实例容量不足等导入失败保留审核快照供重试。
