# 程序更新检查 0.1.0（开发中）

从设置的“程序更新”进入，或在工具库搜索“更新检查”；支持共用收藏、最近和托盘入口。

点击“立即检查”后，后台匿名读取 `ax2/zi-devtools` 的公开 GitHub Release。稳定频道读取 latest；预览频道比较最近20个公开发布中的稳定与预览版本，使用 SemVer 优先级选择最高版本，不按发布日期或字符串排序。构建元数据不影响优先级；较新的开发构建不会被建议降级。未发布的 Git 标签不算可下载版本。

“每24小时自动检查”默认关闭，开启状态与上次请求时间保存于独立的界面偏好文件。启动后等待至少5秒、界面刷新时检查到期状态；隐藏到托盘也可处理，完全退出后不运行。失败也记录本次请求时间，避免离线时持续重试；仍可主动立即检查。检查期间禁止重复请求和切换频道。关闭自动检查不取消已经发出的请求。

联网只读取发布元数据，不发送工作内容、文件路径、账号或认证令牌。请求15秒超时，不跟随重定向；响应最多2 MiB、20个版本、每版32个附件，说明截取前16000字符。只接受官方仓库标签页和符合固定命名的 Windows x64 EXE/MSI/MCP EXE及摘要文件。失败、限流或格式异常明确显示，不能当成“已是最新版”。系统时间倒退时自动检查暂缓，可手动刷新时间。

显示的附件大小来自发布服务。查看发布页由用户点击触发。本页不下载、不安装，也没有验证附件摘要或发布签名；不会修改程序目录和Windows Installer状态。即使看见某版本，附件可能缺失，需在发布页核对。既有发布流程尚未验证预览版MSI打包，本页支持频道查询不代表预览包已经发布。

## 后续验收

更新清单的最低系统要求、按独立工具版本显示差异、发布签名及摘要验证、完整包下载和安装状态尚未实现。增量更新需准确源版本/摘要、补丁校验、重建目标校验、退出后替换与失败回滚；便携EXE和MSI升级使用不同所有权路径。[更新包生成与重建](delta-updates.md)0.1.0已提供本机差分/完整内容生成及校验重建，但没有签名或安装能力，不能视为完整增量更新已完成。
