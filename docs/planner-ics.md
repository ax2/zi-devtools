# ICS 日历文件互通

v0.79.0-dev.2 开发版提供基础 ICS 导入、导出。它用于主动交换日程文件，不连接在线账号、不自动订阅或同步，也不处理会议邀请。正式安装版本仍为 v0.78.0。

## 导入

在万年历页选择“导入 ICS 日历…”，读取 `.ics` 文件后先展示预览。展开条目可核对文件里的标题、详情、日期和重复设置；同一标识已有记录时可比较本机内容。取消不会写入或改变原文件。

默认只添加新日程。同一 UID、同样的安排视为无变化；同一 UID 但内容不同默认保留本机内容。需要更新时勾选“更新同 UID 日程”，再明确确认更新条数，最后点击“确认导入到本机”。同标题但不同 UID 的记录分别保留，重复导入相同文件不会创建副本。

新增和更新条目的提醒关闭，不采用文件中的 VALARM，也不执行附件或链接。更新保留本机置顶、完成和回收站状态，清除该条目的已知晓 / 延后状态；未变化、跳过或不在文件中的记录完全保留。文件中的地点和 URL 附加为详情纯文本；语言标签、替代表示及其他附加属性不保留，预览会说明。

提交在一个事务内重新核对预览时的所有已保存记录；新增、编辑或删除等任何并发变化均取消整次导入，不会部分提交。错误后重新读取文件并预览。导入完成后可打开日程、选择日期视图，按需开启提醒并保存。

## 当前支持范围

| 内容 | 处理方式 |
| --- | --- |
| 文件 | UTF-8，可带 BOM；CRLF 或 LF；单个 iCalendar 2.0 公历 VCALENDAR；最多 16 MiB、100000 物理行、2000 个日程 |
| 标识和标题 | VEVENT 必须有 UID、SUMMARY、DTSTART；UID 原文保留并稳定匹配；标题遵守现有 120 字符限制 |
| 日期 | VALUE=DATE 全天事件；无 DTEND 时为一天；DTEND 不包含该日期，界面显示包含的最后一天 |
| 时间 | 不附时区的浮动本地时间，或单次 UTC（Z）时间转本机钟表时间；精度为分钟，非零秒拒绝 |
| 结束 | 可选 DTEND，需与 DTSTART 使用相同类型；遵守既有范围与重复时长校验；暂不支持 DURATION |
| 重复 | DAILY / WEEKLY / MONTHLY / YEARLY，INTERVAL 省略或等于 1；支持与起点一致的单个周几、月日、月份及本软件导出的月底替代规则 |
| 截止 | 支持本软件导出的 2099 年末截止；COUNT 或其他 UNTIL 尚不能准确保留，会拒绝导入，不改成更长的重复 |
| 详情 | TEXT 反斜杠、逗号、分号、换行及 UTF-8 折行；保留折行边界和正文末尾空格；不执行富文本 |

TZID、VTIMEZONE、X-WR-TIMEZONE 时区提示、UTC 重复日程、EXDATE / RDATE / RECURRENCE-ID、每周多日、复杂 BYDAY、会议 REQUEST / CANCEL、取消或暂定日程、VTODO 等暂不支持。出现这些内容、重复 UID、无效时间、重复必要属性或超容量时，整份文件不写入；需在原日历整理或选择支持的导出方式。UTC 重复不会被直接改成本机重复，以免夏令时后产生不同安排。

这些限制是当前本机数据模型的范围，不代表 ICS 格式本身的能力。不能把可解析属性误当作完整兼容第三方日历。

## 导出

先保存或放弃当前编辑，再选择“导出日程 ICS…”。打开日程时默认导出当前记录；也可选择全部日程，不受日期或搜索筛选影响。默认排除已完成和回收站，可主动包含已完成记录，回收站需先恢复。

导出预览展示实际条数和文件大小，可展开核对内容。提醒默认不随文件导出；勾选后，仅为未完成且开启提醒的条目生成 DISPLAY 提醒。目标软件是否支持及是否弹出由目标日历控制。全天提醒以开始日的提醒钟点再减去提前量，多日安排只生成开始日提醒。

文件保留标题、详情、起止时间、全天及重复规则。已有日历 UID 原样保留，本机新日程使用稳定的生成 UID。普通日程以浮动时间输出，导入其他时区的日历时按其当地钟表解释，不是跨时区会议迁移。月 / 年缺日跳过或月底替代按标准 RRULE 输出；重复的最后起点不晚于 2099 年末，结束可能延续到下一年。

点击导出后选择新路径，已有文件不覆盖。UTF-8 编码、CRLF 换行，按最多 75 字节折行且不切断多字节字符。失败时目标可能留下部分新文件，界面会提示，检查后用新文件名重试。预览后的导出使用这份快照，不重新读取变化中的数据库。

完成、置顶、回收站、已知晓和延后等本机状态不写入 ICS；已完成记录导入其他日历后可能成为普通安排。需要完整保留状态，请使用 JSON 完整备份。ICS 导入的原 UID 随本机数据库与 JSON 备份保存，旧版（包括 dev.1）不认识此字段；试用前保留旧版备份。

## 实现与验证依据

格式规则参考 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545)，属性解析使用固定版本 [ical 0.11.0](https://docs.rs/ical/0.11.0/ical/)。应用额外验证组件、属性类型、时间和当前可表示的重复范围；不是完整 RFC 实现。

验证包括保存前预览、取消、确认更新、事务冲突、UID 重复导入、旧数据、Unicode / 空格与折行、全天结束、UTC 和不支持规则的拒绝。独立 Python icalendar 6.3.2 与 dateutil 2.9.0.post0 对本软件生成的七个合成事件进行解析和六种重复规则的 2200 天范围比对；还读取了独立生成器导出的 UTC 单次会议和全天月重复事件，核对原 UID、文本转义、结束边界与默认关闭提醒。这不等于 Outlook、Apple Calendar、Google Calendar 等真实客户端均已验收。
