# 本地知识源管理

从侧栏“本地知识源”或工具搜索进入。明确选择一个受支持文件或一个目录，填写名称和可选排除规则后点击“添加”；此时只保存路径，不读取目录内容。点击“扫描/刷新”才在后台读取文件、建立版本快照。源列表可选择、调整排除规则、重新扫描或移除；移除不会删除原文件。

支持 `.md`、`.markdown`、`.txt`、`.html`、`.htm`、`.pdf`、`.docx`。知识源扫描只做文件版本检查，不提取正文；需要阅读内容时在[文档解析与分块](document-ingestion.md)手动选择单份文件。每个快照保存相对路径、字节数、修改时间和 SHA-256；刷新时显示新增、变化、移除数量。配置和快照仅写入本机 `%USERPROFILE%\.zi-devtools\knowledge-sources.json`，不保存文档内容，也不上传网络。

默认跳过 `.git/`、`node_modules/`、`target/`、`.venv/`、`__pycache__/`。排除规则用逗号分隔：`drafts/` 排除同名目录，`notes/drafts/` 排除指定相对目录，`*.log` 排除扩展名，`private/file.md` 排除指定相对路径。修改规则会使旧快照失效，需要重新扫描。

最多 32 个知识源；每次扫描最多 500 个受支持文档、5000 个条目、8 层目录、单文件 16 MiB、总计 128 MiB。不会自动扫描整盘，不跟随符号链接或指向目录外的路径。超过限制或扫描中发生变化会明确报错，不把部分结果当成完整版本。可随后在[增量知识索引](knowledge-index.md)手动同步；检索和问答仍在规划中。
