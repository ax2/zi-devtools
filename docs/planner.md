# 备忘录、万年历与日程

Stage 78 源码开发版新增，尚未发布到 v0.77.0 安装包。从工具库的“时间与生成”分类打开，或用 Ctrl K 搜索“备忘”“日历”“提醒”。两个入口可加入收藏，托盘的最近、常用和全部工具也可访问。

## 备忘录

新建后输入标题和正文，点击“保存到本机”。支持按标题/正文搜索、置顶、复制全文、移入回收站和恢复。切换工具保留当前编辑草稿；打开另一条记录前需要保存或放弃。完全退出时有未保存内容会提示，写入过程中不能确认退出。

“转为日程”把已保存备忘的标题和正文复制为日程草稿，原备忘保留。设置日期、时间与提醒，再保存才会启用提醒。正文是纯文本，不执行脚本或 Markdown。

## 与其他工具互通

在已有结果接力的工具（JSON/编码小工具、数据工作台、文本对比、网络诊断、Java/Django 诊断和 HTTP 响应）点击“发送结果到工具…”，选择“备忘录 · 新建草稿”。先预览完整快照的开头，再创建草稿；内容不自动保存，点击备忘里的“保存到本机”才持久保留。正文最多 128 KiB，超限不截断；已有未保存备忘或日程、正在加载/保存时拒绝覆盖并保留原结果。

备忘和日程编辑区也提供“发送正文到工具…”；发送当前正文（包括未保存的编辑），不附带标题、日期或提醒设置。可以继续进行 Base64 编码、JSON 格式化、文本对比等；仍需在目标工具主动执行。来源保留，目标输入的替换规则在接力对话框中展示。回收站条目不提供正文接力。

## 万年历与日程

- 公历月视图支持 1901–2099 年、前后月、回到今天及日期跳转；显示农历、闰月、节气与节日。长节日名称在格内缩写，悬停可查看完整信息。
- 点击日期查看当日日程；输入关键词会跨所有日期搜索标题与正文。日程支持标题、详情、置顶、一次性/每天/每周重复、完成或结束整个重复日程。
- 使用电脑当前本地时区，以当地钟表时间安排；修改系统时区后会跟随本地时区，不是跨时区会议系统。新建/修改时拒绝夏令时不存在或有歧义的时间；既有重复日程遇到不存在的时刻跳过，重复时刻取第一次。
- “弹出提醒”需要显式勾选后保存，可提前 0–10080 分钟；0 表示准时，重复日程的提前量必须小于重复周期。提醒会恢复主窗口，在任何工具页面显示；支持“已知晓”和“10 分钟后提醒”，处理结果持久保存。“已知晓”处理当次提醒，不结束重复日程。
- 程序运行、缩到托盘、任务栏最小化时均可提醒；完全退出不提醒，也不会唤醒休眠电脑。重新打开/恢复运行后补显示未处理提醒。多次错过的重复提醒合并为最新一次，避免大量补弹。
- 关闭提醒窗口不会自动知晓；通过页面右上角“待处理提醒”可再打开。“打开日程”定位该次日期与对应记录，不会标记已知晓；其他未保存编辑会阻止跳转，同一日程正在编辑时保留编辑内容。回收站中或已完成的日程不提醒，恢复后未处理的过期提醒可能立即出现。

日历算法使用固定版本 [lunar_rust 1.0.1（MIT）](https://github.com/flameoftheforest/lunar_rust)，完全本机计算。春节、闰月和清明日期的测试样例参考香港天文台 [2023 公农历对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2023e.pdf)、[2024 公农历对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2024e.pdf)。这些是抽样校验，未逐日与官方历表核对整个范围。节日名称不代表官方放假/调休安排，不显示推测的补班日。

## Markdown / 文本文件互通

点击“导入 Markdown / 文本…”选择一份 `.md`、`.markdown` 或 `.txt` 文件。仅支持 UTF-8（可带 BOM），正文最多 128 KiB；其他编码先使用文件编码工具转换。标题取文件名，正文保留 Markdown、空行和原始换行，不剥离 front matter 或标题、不解析执行脚本和链接。目录、符号链接、空字节及超限内容拒绝导入；空文件可形成有标题的空草稿。

导入在后台完成，原文件不变。已有未保存编辑需先保存或放弃；成功后打开新备忘草稿，明确点击“保存到本机”才写入数据库。读取失败保留当前记录。操作过程中阻止新的读写和确认退出。

备忘 / 日程的“导出正文…”先展示当前正文快照，包括未保存编辑；确认后选择新文件名，以 UTF-8 写出，不添加 BOM、不转换换行、不插入标题。标题只用于建议文件名；日程日期、重复和提醒设置不写入文件，因此这不是完整备份。可以选 `.md`、`.markdown` 或 `.txt`，已有文件拒绝覆盖，取消预览或文件选择不写入。

导出不改变当前草稿是否已保存。回收站记录需先恢复再导出。文件写入失败会提示；磁盘错误时新目标文件可能包含部分正文，应检查并选择新文件名重试。当前仅支持单文件，未实现目录同步、多文件批量交换或 Markdown 渲染编辑器。

## 清理回收站

回收站内可对当前记录选择“永久删除这条记录…”，或选择“清空回收站…”。清空范围包含所有备忘与日程，不受搜索、日期或类型筛选影响；确认窗口会列出实际删除的标题和条数。取消或按 Esc 保留记录，只有点击“确认永久删除”才提交，之后无法恢复。

有未保存编辑时需先保存或放弃；后台清理期间禁止继续写入和确认退出。提交前在同一事务内逐条复核确认时的记录版本及回收站状态：任何一条已修改、恢复或删除，整批回滚，重新加载后再确认。确认窗口打开之后新移入回收站的记录不会顺带删除。

清理释放 2000 条 / 32 MiB 的记录容量。SQLite 会复用空闲页，数据库文件不保证立即缩小；这也不是安全擦除，外部备份不受影响。

## 本地数据与边界

内容仅在明确保存时写入偏好文件旁的 `planner.sqlite3`，设置页和工具内可查看实际位置。保存、加载在后台线程执行，SQLite 事务和记录版本阻止旧窗口覆盖新修改。保存失败保留当前编辑。其他进程的改动需要主动重新加载，多开可能分别提醒，建议一个实例管理日程。

标题最多 120 字符、正文 128 KiB，共 2000 条及 32 MiB 内容（包含回收站）。内容没有加密，不自动上传、同步、读取剪贴板或扫描其他应用。备份时完全退出程序再复制数据库；未知数据库版本拒绝写入。

月/年重复、农历生日重复、日程结束时间、全天事件、周视图、ICS 导入导出、系统通知中心、程序退出后的系统定时任务均属于后续规划，不是当前能力。

## 验证

包含保存/恢复/冲突/回收站、无效和超限输入、保存失败草稿、提前/延后/知晓/重启补提醒、重复合并、跨年/闰日、夏令时和农历抽样测试。原生 UI 夹具支持明暗主题截图，以及独立观察线程验证实际计时到点后从托盘隐藏或任务栏最小化恢复。后者使用合成内存日程，持久存储与重启恢复另由自动测试验证。
