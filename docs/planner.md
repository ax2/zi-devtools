## 与其他工具互通

v0.80.0-dev.3 的结果接力增加“万年历 / 日程 · 新建草稿”。支持接力的工具结果可直接成为日程正文，完整快照最多128 KiB，超限拒绝且不截断。确认区显示当前日历所选日期的09:00、本机时区、不重复和提醒关闭；创建后可调整日期时间并主动开启提醒，再点击保存。原工具结果和已有记录保留，不自动写入。已有未保存备忘/日程，或正在读写、文件/删除预览时拒绝接收；接力窗口保留结果和错误提示。备忘草稿接收也遵守同一预览保护。

在已有结果接力的工具（JSON/编码小工具、数据工作台、文本对比、网络诊断、Java/Django 诊断和 HTTP 响应）点击“发送结果到工具…”，选择“备忘录 · 新建草稿”。先预览完整快照的开头，再创建草稿；内容不自动保存，点击备忘里的“保存到本机”才持久保留。正文最多 128 KiB，超限不截断；已有未保存备忘或日程、正在加载/保存时拒绝覆盖并保留原结果。

备忘和日程编辑区也提供“发送正文到工具…”；发送当前正文（包括未保存的编辑），不附带标题、日期或提醒设置。可以继续进行 Base64 编码、JSON 格式化、文本对比等；仍需在目标工具主动执行。来源保留，目标输入的替换规则在接力对话框中展示。回收站条目不提供正文接力。

## 万年历与日程

v0.80.0-dev.2 在有编辑记录时的固定底部增加“返回日程视图”和“查看当前编辑”。小窗口月历和周视图可直接往返浏览区与编辑区；宽窗口也可定位当前编辑。只移动页面，不关闭草稿、不改变搜索、日期、重复或提醒，不自动保存。正文中的 Ctrl Home 仍按原有文本编辑方式使用。

- 周视图按周一至周日排列，支持前后周、今天、日期跳转、本周关键词与已完成筛选。全天优先，跨天事件显示在每个覆盖日，午夜结束不额外占用一天；窄窗口横向滚动，各列可上下滚动。点击卡片保留所点日期并打开原日程，修改重复日程会影响整个系列；其他未保存草稿会阻止跳转，当前同一日程草稿保留。仅查看、筛选和切周不写入记录，也不改变提醒状态。
- 公历月视图支持 1901–2099 年、前后月、回到今天及日期跳转；显示农历、闰月、节气与节日。长节日名称在格内缩写，悬停可查看完整信息。
- 点击日期查看当日日程；输入关键词会跨所有日期搜索标题与正文。日程支持标题、详情、置顶、一次性/每天/每周/每月/每年重复、完成或结束整个重复日程。
- **Stage 79**：普通日程可勾选“设置结束时间”，支持跨天；不勾选仍是单个时间点。结束必须晚于开始，结束边界不包含：10 月 2 日 21:00 至 10 月 3 日 00:00 只占用 2 日。月历标记与单日列表显示覆盖当天的日程，同一重复系列当天只列一条。
- **Stage 79**：“全天事件”支持单日或连续多日，界面的结束日期包含当天。例如 2 日至 4 日包含 2、3、4 日。启用弹出提醒后可填写独立提醒钟点，再减去提前分钟；多日事件只在开始日安排一次提醒。切换全天会沿用当前开始钟点作为提醒钟点，保存前可修改。
- **Stage 79**：重复事件保持原始的本地钟表时长，不保持绝对秒数（跨夏令时可能不同）；为避免同一系列重叠，每天 / 每周 / 每月 / 每年时长最多 1 / 7 / 28 / 365 天。一次性事件的结束不超过 2099 年末；视图不展示 2099 年后的日期。未来重复仍沿用完整时长，最后一次可能延续到 2100 年，但不会产生新的 2100 年起点。
- **Stage 79**：7 / 30 天列表包含范围开始前已开始、仍未结束的事件，每次安排只列一次，不按覆盖天数重复。点击这类安排会定位其开始日。只修改结束时间不会重新弹出已知晓提醒；改变开始、全天模式、提醒钟点或重复规则会重置处理状态。
- 切换“7 天日程 / 30 天日程”，以所选日期为起点（包含当天）按计划时间查看多日安排；可点击“今天起”或输入起点日期。每天 / 每周 / 每月 / 每年重复逐次展开，条数表示出现次数，不是记录数量；默认隐藏已完成，可勾选包含。此视图的关键词仅筛选当前日期范围，回收站仍单独查看。
- 多日列表点击某次安排，进入对应日期并打开原日程；不会改写系列起点或标记提醒已知晓。编辑、完成影响整个重复系列，不支持仅修改某一次。其他未保存编辑会阻止打开，当前同一日程的草稿保留。列表按本机计划钟表时间展示，不是实际送达提醒日志。
- 多日视图最多展开 30 天，超过 2099 年末的日期不展示。结果按保存版本缓存，滚动仅绘制可见行；重新加载或保存后刷新。月历 / 单日模式仍支持跨所有日期的关键词搜索。
- 每月按起始日号、每年按起始月日重复，均为公历规则。缺少对应日期默认跳过：31 日跳过短月，2 月 29 日仅在闰年出现。可勾选“没有对应日期时，改用当月最后一天”，例如 1 月 31 日 → 2 月末 → 3 月 31 日，闰日遇平年改为 2 月 28 日；不会把后续起点永久改为 28 日。
- **v0.79.0-dev.3**：重复日程可勾选“设置重复截止日期”，填写 YYYY-MM-DD，保存后生效。截止日期包含当天开始的安排；不能早于起点，不超过 2099 年。最后一次跨天 / 全天事件仍保留完整时长，月历与 7 / 30 天列表会继续展示至实际结束。未勾选保持原规则。
- 截止后不产生新安排；最后一次未处理的提醒仍会在重新打开时补显示，已知晓不再提示，稍后提醒继续生效。仅修改截止日期不重置这些状态；缩短后不再包含的提醒不会作为未来新次数出现。截止不等于“结束整个重复日程”，后者会停止该系列全部提醒。切换“不重复”后保存会移除截止。
- 更改重复规则或月底替代选项，需要保存后生效，并重置该系列已知晓 / 延后状态；旧的未处理提醒可能因此重新出现。月历、多日列表和提醒使用同一规则；不产生 2099 年之后的新重复次数。
- 使用电脑当前本地时区，以当地钟表时间安排；修改系统时区后会跟随本地时区，不是跨时区会议系统。新建/修改时拒绝夏令时不存在或有歧义的时间；既有重复日程遇到不存在的时刻跳过，重复时刻取第一次。
- “弹出提醒”需要显式勾选后保存，可提前 0–10080 分钟；0 表示准时，重复日程的提前量必须小于重复周期。提醒会恢复主窗口，在任何工具页面显示；支持“已知晓”和“稍后提醒”，处理结果持久保存。Stage 79 v0.79.0-dev.5 可选择 5 / 10 / 30 分钟、1 / 2 小时或 1 天（默认 10 分钟），从点击时刻延后；选择本身不写入，点击“稍后提醒”才保存。延后仅针对当次安排，新的重复次数仍按原规则提醒，即使延后时间更长；不改动日程的开始时间。“已知晓”处理当次提醒，不结束重复日程。
- 程序运行、缩到托盘、任务栏最小化时均可提醒；完全退出不提醒，也不会唤醒休眠电脑。重新打开/恢复运行后补显示未处理提醒。多次错过的重复提醒合并为最新一次，避免大量补弹。
- 关闭提醒窗口不会自动知晓；通过页面右上角“待处理提醒”可再打开。“打开日程”定位该次日期与对应记录，不会标记已知晓；其他未保存编辑会阻止跳转，同一日程正在编辑时保留编辑内容。回收站中或已完成的日程不提醒，恢复后未处理的过期提醒可能立即出现。

日历算法使用固定版本 [lunar_rust 1.0.1（MIT）](https://github.com/flameoftheforest/lunar_rust)，完全本机计算。春节、闰月和清明日期的测试样例参考香港天文台 [2023 公农历对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2023e.pdf)、[2024 公农历对照表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2024e.pdf)。这些是抽样校验，未逐日与官方历表核对整个范围。节日名称不代表官方放假/调休安排，不显示推测的补班日。

## Markdown / 文本文件互通

在备忘录页点击“导入 Markdown / 文本…”选择一份 `.md`、`.markdown` 或 `.txt` 文件。仅支持 UTF-8（可带 BOM），正文最多 128 KiB；其他编码先使用文件编码工具转换。标题取文件名，正文保留 Markdown、空行和原始换行，不剥离 front matter 或标题、不解析执行脚本和链接。目录、符号链接、空字节及超限内容拒绝导入；空文件可形成有标题的空草稿。

导入在后台完成，原文件不变。已有未保存编辑需先保存或放弃；成功后打开新备忘草稿，明确点击“保存到本机”才写入数据库。读取失败保留当前记录。操作过程中阻止新的读写和确认退出。

备忘 / 日程的“导出正文…”先展示当前正文快照，包括未保存编辑；确认后选择新文件名，以 UTF-8 写出，不添加 BOM、不转换换行、不插入标题。标题只用于建议文件名；日程日期、重复和提醒设置不写入文件，因此这不是完整备份。可以选 `.md`、`.markdown` 或 `.txt`，已有文件拒绝覆盖，取消预览或文件选择不写入。

导出不改变当前草稿是否已保存。回收站记录需先恢复再导出。文件写入失败会提示；磁盘错误时新目标文件可能包含部分正文，应检查并选择新文件名重试。当前仅支持单文件，未实现目录同步、多文件批量交换或 Markdown 渲染编辑器。

## 完整备份与恢复

“完整备份…”在后台读取数据库的一致性快照，预览全部已保存备忘与日程（包括回收站）。JSON 备份保存正文、标题、置顶、更新时间、重复规则、提醒开关、已知晓和稍后提醒状态；不包含未保存草稿、软件配置或其他工具数据。可以展开记录核对正文和日程。选择新文件名后才写入，已有文件不覆盖；内容为明文，需要自行保管。使用内置备份时无需退出软件。

“恢复备份…”先校验格式版本与内容，再读取当前已保存记录，预览三种恢复方式：

- 合并并保留现有：相同记录标识保留本机内容，只添加新记录。同名但不同标识的记录分别保留。
- 合并并使用备份：相同记录使用备份内容，本机独有记录保留。
- 替换全部：最终仅保留备份中的记录；本机独有记录移除。空备份在此模式下可清空全部记录，必须明确确认。

预览展示新增、覆盖、移除和保留条数；展开影响记录可比较恢复前后。覆盖或移除必须额外勾选确认，无法撤销。提交前在同一事务内复核全部当前记录，任何并发修改、删除或新增均取消整次恢复，数据库写入失败也整批回滚；需重新读取备份并确认。操作中的退出保护保持有效，有未保存编辑时不能开始备份或恢复。

新增 / 覆盖日程的提醒默认关闭；需要保留备份提醒状态时明确勾选“同时恢复…提醒设置”，到期提醒可能立即弹出。保留的本机记录不受此开关影响。备份没有独立时区标识，日程时间按本机时区解释，不能当作跨时区会议迁移。其他日程数据、回收站、已知晓及稍后提醒状态保留。

格式版本为 1，最大文件 40 MiB，最多 2000 条；恢复后的序列化记录仍受 32 MiB 总容量和每条 128 KiB 正文限制。重复标识、未知版本 / 字段、无效时间或超限内容拒绝恢复。恢复的新写入记录保留原标识并分配新的版本标识，防止旧窗口沿用备份中的旧版本保存；未变化的现有记录保留版本。重复恢复按标识匹配，不增加重复副本。

备份写入遇到磁盘错误可能留下不完整目标文件，错误会明确提示，需检查并用新文件名重试。当前没有加密、定时备份或自动保存恢复前备份；替换前可以取消操作，先建立完整备份。

## 清理回收站

回收站内可对当前记录选择“永久删除这条记录…”，或选择“清空回收站…”。清空范围包含所有备忘与日程，不受搜索、日期或类型筛选影响；确认窗口会列出实际删除的标题和条数。取消或按 Esc 保留记录，只有点击“确认永久删除”才提交，之后无法恢复。

有未保存编辑时需先保存或放弃；后台清理期间禁止继续写入和确认退出。提交前在同一事务内逐条复核确认时的记录版本及回收站状态：任何一条已修改、恢复或删除，整批回滚，重新加载后再确认。确认窗口打开之后新移入回收站的记录不会顺带删除。

清理释放 2000 条 / 32 MiB 的记录容量。SQLite 会复用空闲页，数据库文件不保证立即缩小；这也不是安全擦除，外部备份不受影响。

## 周视图（v0.79.0-dev.10 开发版）

日历页选择“周视图”，按所选日期所在周的周一至周日排列。可切上周/下周、回到本周/今天，或输入 YYYY-MM-DD 跳转。1901 年初和 2099 年末那一周仍显示完整星期，但范围外的日期不可选择；导航不会停在全周超出范围的位置。

关键词和“包含已完成”仅筛选本周，回收站不进入周视图。全天在每列优先，其余按出现的开始时间顺序；跨天安排在覆盖的每天显示，午夜结束边界不包含下一日。范围前已开始但本周尚未结束的安排也显示。标题截短，悬停查看完整标题、范围和重复规则。顶部总数按出现次数计算，每天计数按覆盖该日的安排，跨天显示不代表新增记录。

点击日期只更改所选日期，可以在顶部新建日程。点击卡片打开原记录并选中所点的日期，保留周视图及关键词；即使安排在前一周开始，也不跳走到上一周。编辑区在周视图下方，打开时滚动到编辑区；重复日程仍编辑整个系列。其他未保存草稿会阻止打开，同一系列已有未保存输入会保留。只查看、选择日期或切周不改写记录，不标记提醒已知晓。

周视图使用全宽七列，小窗口横向滚动，每列内部可上下滚动，仅绘制可见行；切周、筛选或数据更新时从列首开始显示。缓存条件和记录索引，加载/保存/导入/恢复后的数据替换清除缓存。查询首次展开仍有扫描开销。没有按小时定位、拖动改变时间、单次重复编辑或独立的周提醒状态；提醒沿用保存记录的规则。

## 本地数据与边界

内容仅在明确保存时写入偏好文件旁的 `planner.sqlite3`，设置页和工具内可查看实际位置。保存、加载在后台线程执行，SQLite 事务和记录版本阻止旧窗口覆盖新修改。保存失败保留当前编辑。其他进程的改动需要主动重新加载，多开可能分别提醒，建议一个实例管理日程。

标题最多 120 字符、正文 128 KiB，共 2000 条及 32 MiB 内容（包含回收站）。内容没有加密，不自动上传、同步、读取剪贴板或扫描其他应用。内置完整备份无需退出；手工复制数据库时需完全退出程序；未知数据库版本拒绝写入。

旧备忘和一次性 / 每天 / 每周记录可直接读取，未选择月底替代时不新增该 JSON 字段。使用每月 / 每年规则后，旧开发版不能识别新重复类型，无法读取包含这些记录的数据库或备份；升级前可用旧版本保留完整备份，不应指望新备份能导入旧开发版。数据库结构及完整备份容器版本仍为 1，新记录规则由当前版本解析。

Stage 79 新字段包含可选结束时间、全天标识和全天提醒钟点，保存和完整 JSON 备份会保留。旧记录直接读取，未使用新能力的记录不写这些字段。v0.78.0 及更早版本不能读取含新字段的数据库或备份；使用开发版前先保留旧版完整备份，不能把新数据直接交给旧版。数据库结构及备份容器版本仍为 1，未知字段严格拒绝，避免静默丢失设置。

通过 ICS 导入的记录会保存原始日历 UID，用于后续去重和导出；v0.79.0-dev.1 也不能读取含此字段的数据。未使用 ICS 导入的旧记录不新增 UID 字段。试用前先保留旧版完整备份。

v0.79.0-dev.3 的可选重复截止字段随数据库 / JSON 备份保存；未设置时不新增字段，旧数据直接可读。dev.2 及更早版本不能读取包含该字段的数据；试用前保留旧版完整备份。

农历生日重复、周视图、ICS 的时区 / COUNT 次数 / 例外扩展、系统通知中心、程序退出后的系统定时任务均属于后续规划，不是当前能力。
