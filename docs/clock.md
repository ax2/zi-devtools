# 时钟工作台（开发中）

程序0.82.0-dev.8，工具独立版本0.2.0。前缀松开后按T，或在工具库搜索“时钟/秒表/计时器/番茄钟”。

世界时钟使用本机时间，支持多时区数字时钟、模拟表盘、中文常用城市与IANA名称搜索；最多12个显示时区。会议对照可查看距现在-12到+24小时的不同当地时间，不设置闹钟或改变系统时间。按[chrono-tz官方资料](https://docs.rs/crate/chrono-tz/0.10.4)接入IANA时区规则；UI展示内置数据库版本，时区政策变更需要随软件升级，不承诺实时最新或联网校时。

秒表支持开始/暂停/继续、总累计及分段，最多1024段；重置会清空分段。多计时器最多32个，各自命名、开始/暂停/重置与移除，可用1/5/25分钟和1小时预设。运行时使用单调时间，不按日历系统时钟计算时长。结束仅发一次应用内提醒，知晓或稍后5分钟。

闹钟使用指定日期时间及所选时区，可一次或每天当地同一时间；最多64项。夏令时跳过的时间拒绝创建，每日规则跳过该日；重复时间可选择第一次/第二次。恢复或系统时间前跳后补一次提醒并推进至未来，不集中重播所有错过日期。稍后5分钟保留后续每日规则。

番茄专注支持自定义专注/短休息/长休息分钟数、开始/暂停、完成计数；每4次完成专注用长休息。当前结束后等待用户进入下一阶段并主动开始，不自动连续计时。

页首可直接“启用本机保存”，更多选项在“保存设置 / 读取与恢复预览”中。操作后后台写入，运行计时每30秒保存检查点；故障退出最多丢失最近30秒。文件在界面显示的用户配置目录clock.json，不在软件release目录；未开启时只保留运行会话。停止自动保存保留已有文件，下次启动仍可查看并选择恢复。

重启读取只生成预览，不自动恢复或写回。确认后替换当前时钟会话并启用保存：默认按保存的剩余时间暂停恢复；也可选择包含退出期间按原到期时间继续。继续模式使用保存UTC与本机UTC差值，系统时间回拨不增加剩余时长，手工改时可能改变离线持续时长判断。秒表始终暂停并保留累计/分段；闹钟按日历规则补一次，已确认的提醒不重播。若保留当前会话替换保存内容，先勾选明确的覆盖确认。

立即保存/重试可以更新最新检查点；后台写入中正常退出按钮暂不可用。文件512KiB上限，条数/时长/ID/时区/schema/提醒来源均校验；原子替换前不删除旧文件，协作进程排他写锁与摘要复核拒绝过期覆盖。损坏或未来版本文件拒绝写入，重新读取不会清空当前会话；需在程序外备份并处理原文件后重读，不能以空默认值覆盖。所有保存内容是用户数据，不纳入公开日志。

隐藏到托盘继续处理；完全退出后不弹提醒，未保存修改会丢失。当前应用内提醒无声音。声音试听/静音、独立置顶/全屏小窗、与日程共享完整提醒调度、真实睡眠/时钟修改/实体退出验收及退出后可选系统任务仍待实现或验证。
