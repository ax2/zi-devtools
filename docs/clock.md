# 时钟工作台（开发中）

程序0.82.0-dev.7，工具独立版本0.1.0。前缀松开后按T，或在工具库搜索“时钟/秒表/计时器/番茄钟”。

世界时钟使用本机时间，支持多时区数字时钟、模拟表盘、中文常用城市与IANA名称搜索；最多12个显示时区。会议对照可查看距现在-12到+24小时的不同当地时间，不设置闹钟或改变系统时间。按[chrono-tz官方资料](https://docs.rs/crate/chrono-tz/0.10.4)接入IANA时区规则；UI展示内置数据库版本，时区政策变更需要随软件升级，不承诺实时最新或联网校时。

秒表支持开始/暂停/继续、总累计及分段，最多1024段；重置会清空分段。多计时器最多32个，各自命名、开始/暂停/重置与移除，可用1/5/25分钟和1小时预设。运行时使用单调时间，不按日历系统时钟计算时长。结束仅发一次应用内提醒，知晓或稍后5分钟。

闹钟使用指定日期时间及所选时区，可一次或每天当地同一时间；最多64项。夏令时跳过的时间拒绝创建，每日规则跳过该日；重复时间可选择第一次/第二次。恢复或系统时间前跳后补一次提醒并推进至未来，不集中重播所有错过日期。稍后5分钟保留后续每日规则。

番茄专注支持自定义专注/短休息/长休息分钟数、开始/暂停、完成计数；每4次完成专注用长休息。当前结束后等待用户进入下一阶段并主动开始，不自动连续计时。

当前数据仅保存在运行会话，隐藏到托盘继续处理；完全退出会清空计时器、闹钟、分段和专注记录，退出保护会提示。当前应用内提醒无声音。持久保存/重启恢复、声音试听/静音、独立置顶/全屏小窗、与日程共享完整提醒调度、真实睡眠/时钟修改验收及退出后可选系统任务仍待实现或验证。
