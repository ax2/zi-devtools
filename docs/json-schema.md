# JSON Schema 校验（开发中）

工具版本：`0.2.0`（开发中）。在“编码工具”中输入待校验 JSON，并在 Schema 编辑框粘贴 JSON Schema，或选择本机根 Schema 文件。校验覆盖 Draft 4、Draft 6、Draft 7、2019-09 和 2020-12，按 `$schema` 自动识别；未声明时按库默认版本处理。Schema 会先通过对应元模式校验，再验证输入。失败结果包括数据实例 JSON Pointer 和脱敏错误摘要。

所有操作只使用本机数据。Schema 上限 64 KiB，实例 JSON 上限 1 MiB，最多显示 100 条错误。未选择文件时，仅允许当前文档的 `#` URI 引用。用户明确选择本机根 Schema 文件后，可读取该文件所在目录内的引用文件：最多 32 个，累计 1 MiB，每个文件最多 64 KiB；根文件及引用必须是普通 JSON 文件。目录外路径、网络 URI、带查询参数的引用均在读取/编译前拒绝，引用路径会解析规范化并检查是否仍在所选目录内。正则匹配使用线性时间 regex 引擎；文件与 HTTP resolver 仍关闭，校验器只使用预先审核并放入内存注册表的本机 Schema。

如果 Schema 声明 `$id`，相对引用按照其 URI 基址解释；本工具不会猜测如何将远端 `$id` 映射回本机目录，所以这种情况下相对外部引用会拒绝。请使用明确的 `file://` URI，并确保目标仍在所选根目录内。当前只读取被 Schema 显式引用的文件，不递归扫描整个目录。

真实窗口中的键盘、粘贴和窄屏交互仍待验收。WASI 共享核心、Studio 插件交付、自动修复和更多结果导航未实现。
