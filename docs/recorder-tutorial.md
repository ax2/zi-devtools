# 教程录屏辅助（0.2.0，开发中）

更新：2026-10-06，程序0.82.0-dev.23。搜索“教程录屏”“录屏放大”或在录屏页展开“教程辅助”。完整教程工具还在开发，这份说明只覆盖当前实现。

先选择屏幕、录制区域、输出MP4与质量，再选择原始画面、固定焦点放大、跟随鼠标放大或全景加鼠标放大窗。放大1–4倍，固定焦点用横/纵比例调整；焦点限制在选区，输出宽高不变。可开启约180ms平滑过渡、鼠标高亮和左右键点击波纹，默认全部关闭。复位画面只关闭放大；关闭所有效果同时关闭鼠标提示。

录制中可调整。统一前缀后R T打开设置、R Z开关鼠标聚焦放大、R X关闭全部效果；附加序列可修改，实际配置以本机设置为准。开始/暂停/结束仍用R S/R P/R E或原直接热键。倒计时期间不接受效果调整；暂停不推进视频时间并清除瞬态波纹，恢复不重放暂停期间的点击。

预览共用编码输出的像素转换。默认合成网格，可在预览上移动和点击试用。主动点击“预览所选区域当前画面”读取静态快照，仅存于当前工作台内存，不上传或自动写盘；切换区域会丢弃旧预览，可手动恢复示例/清除快照。缩略预览不是最终质量验收，快照不会实时刷新，可能包含工作台。

## 实现与边界

裁剪后、行翻转与H.264编码前进行BGRA合成。静止桌面也从保留的原始帧重新合成，不重复放大上一张输出；末尾补帧使用已合成画面。鼠标用显示器物理起点和选区转换坐标；离开选区不绘制高亮，跟随焦点保留最后位置。放大使用最近源像素，缩放边缘可能有锯齿。黄色波纹为左键，蓝色为右键，最多8个、约500ms淡出。

点击以状态变化采样，极快点击可能遗漏，不是完整事件记录。效果区域最多1600万像素，超限拒绝启用。效果与预览均是会话设置，不自动保存或采集键盘文字。主窗口是否被录入仍取决于选区与最小化设置；建议缩小选区或使用前缀操作。快捷面板也可能被录入，原生控制层捕获排除尚待实现。

## 验证与后续

测试覆盖边界/行方向、字节级复位、源内容不变、平滑跟随、暂停/点击衰减和无效设置拒绝。实际Windows采集回调用测试专用合成源和指针，导出MP4后解码检查固定焦点、跟随、高亮、波纹、复位及暂停时长；注入只存在于ui-preview特性，不进入普通发布程序。这证明编码路径与合成输出，不等同于真实桌面、物理鼠标或混合DPI验收。本机测试窗口的桌面合成颜色未通过实际采样，失败证据保留，真实屏幕内容与物理输入仍待验证。

热键聚焦当前位置、按键组合显示、画笔/箭头、步骤编号、提词器、章节标记，以及高分辨率性能、不同屏幕/DPI与音画同步仍逐项推进。普通录屏边界见[屏幕录制](recorder.md)，完整九项路线见[桌面效率扩展](desktop-product-roadmap.md)。

## dev23全景放大窗与聚光灯

“全景＋鼠标放大窗”保留完整录制区域，在四角之一叠加约36%画面宽高的局部放大窗；1–4倍、跟随鼠标、支持平滑，鼠标离开后保持最后焦点。放大窗边框帮助区分局部与全景，选择不遮挡教程内容的位置。

聚光灯独立于放大模式，半径为画面短边的3–45%、外围压暗0–90%，圆周带柔和过渡；鼠标离开选区时取消压暗，放大窗保持明亮。先合成全景压暗，再叠加局部窗及鼠标提示；关闭全部效果恢复原始像素。聚光灯不是隐私遮挡，敏感内容仍可能在视频中出现。效果可在录制中调整，共用现有前缀关闭效果命令；按键显示/画笔/箭头/提词器/章节等仍待开发，高分辨率性能与真实物理输入另验收。

本轮增加放大窗四角、聚光灯越界、固定放大时指针不在可见裁剪画面、无效参数拒绝等回归测试。合成源经实际 Windows 编码导出 640×360、30fps 的 MP4，解码后 9 项像素及时长检查通过；亮暗两种主题的设置和预览均已截图检查。测试专用窗口仍注入合成画面和指针，不能代替真实桌面、多屏、高 DPI 和性能验收。
