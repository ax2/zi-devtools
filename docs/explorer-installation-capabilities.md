# 逐安装菜单能力0.26.0候选

新便携登记从同一受写删锁保护的EXE读取菜单声明，和程序SHA256一起保存。预览和确认使用该安装的动作集合；应用前再次比较实际声明、摘要、路径、登记和菜单状态。相同应用版本不代表相同能力，登记代次继续独立跟踪。

## 兼容规则

新写安装账本为协议4，读取协议1–4。协议1–3不能携带能力快照，未知字段/协议或损坏声明继续拒绝。旧无快照登记保留历史11动作布局，使用冻结清单而非维护程序未来的Target::ALL。这是沿用用户已有登记，不是推测任意未知程序支持新功能。没有声明的程序不能新增便携登记。

旧维护程序不认识协议4会拒绝读写；没有承诺旧维护程序能够编辑新账本。既有菜单调用不需要账本解码。新代码继续读取旧恢复记录和Undo1/2；快照随Installation进入联合事务和逆操作，回滚恢复原动作集合，并保留后来便携登记/用户选择。没有通过简单放宽未知字段来绕过兼容问题。

## 当前范围

手动便携登记、修复、切换、移除和恢复菜单图像已接入快照。界面显示登记工具数量和旧布局来源，确认页显示将提供多少工具。

MSI准备阶段目前仅有包摘要和目标位置，尚未从实际包内载荷传入声明。其无快照候选仍使用冻结11动作布局；不能据此新增目录、图片等动作。下一步必须携带与包载荷摘要绑定的声明，并在InstallFiles后比较实际文件，再完成真实不同能力发行版的两种移除顺序/升级失败回滚及实际菜单调用。

## 验证边界

新增纯模型测试覆盖快照保存/反序列化、子集计划、MSI逆操作回到便携子集、旧协议迁移和快照/摘要不一致拒绝；文件核验测试覆盖同摘要但错误快照的拒绝、新登记缺少声明拒绝及写删锁。新增原生KTM夹具检查账本和实际菜单树由子集变全量、事务中止保持全量、回滚同时恢复子集。夹具中的记录或合成PE不是两个真实可运行发行版的验收。

深浅主题确认页用纯合成、禁止应用的受控模型捕获，不读取或登记截图程序；明确显示未验证/登记。应用版本保持0.82.0-dev.105，不发布安装包。
