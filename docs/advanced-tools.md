# Stage 15 工具用法

六个工具均在本机处理。通过 Ctrl K 搜索工具名称，填入示例后点击操作按钮；Ctrl Enter 执行第一个操作。输入和结果只保留在当前应用会话的独立草稿中，不写入磁盘。

## JSON 路径查询

输入 `{"items":[{"name":"Rust"},{"name":"Python"}]}`，路径 `$.items[*].name`，结果为 `["Rust","Python"]`。

支持 `$`、`.字段`、`["特殊字段名"]`、非负数组索引及 `[*]`（数组元素或对象字段值）。未匹配返回 `[]`。不支持递归、过滤器、负数索引、切片。路径最多 4096 字节、128 层，匹配最多 10000 项。

## JSON 结构对比

分别粘贴左侧与右侧 JSON。对象字段顺序不影响结果。“按数组索引对比”逐项比较；“忽略数组顺序”在所有层级将数组作为多重集比较，保留元素重复次数。例如 `[1,2]` 与 `[2,1]` 相等，但 `[1,1,2]` 与 `[1,2,2]` 不相等。

结果列出 added、removed、changed，路径使用 JSON Pointer（根为 `""`，`/` 转义为 `~1`，`~` 转义为 `~0`）。无序模式下不同数组整体报告。最多 10000 项差异，暂不支持忽略路径。数字遵循 serde_json 的数值表示，不保证 `1` 与 `1.0` 被视为相同值。

## 数据质量检查

选择与输入相符的 JSON、CSV 或 TSV 按钮。JSON 需要对象数组；CSV/TSV 需要非空且不重复的表头。报告包含总行数、完整重复行数（不含第一次）、每列类型计数、混合非空类型、缺失或 null 数量、空白字符串数量。

缺失字段与显式 null 合计；CSV/TSV 始终保留字符串，不猜测日期或数字。最多 10000 行、128 列。本工具不执行 JSON Schema 规则验证。

## Cron 预览

五个字段按“分 时 日 月 周”排列，支持数字、`*`、逗号列表、升序范围和正整数步长。例如 `*/15 9-18 * * 1-5` 表示工作日 9 点至 18 点期间每 15 分钟。星期 0 与 7 都表示周日。

参考时间填写 `2026-09-26T09:00:00+08:00`，留空用当前 UTC；输出严格晚于参考时间的最多 10 次运行，搜索未来 5 年。仅使用参考时间的固定 UTC 偏移，不处理地区时区和夏令时。日和周都不以 `*` 开头时采用 OR，否则采用 AND。日期不可能匹配时显示错误。不支持秒/年、英文月份/星期、L、W、#。

## 随机数据生成

输入 JSON 参数，例如 `{"length":24,"count":5,"seed":42}`；省略字段使用默认值。

- length：每个字符串的码点数，1–256，默认 24。
- count：结果数量，1–100，默认 5。
- alphabet：可选自定义字符集，去重后 2–256 个非空白、非控制字符。默认大小写字母、数字、`-` 和 `_`，不保证每类字符都出现。
- seed：无符号 64 位整数，仅用于种子测试模式，默认 42。

“安全随机字符串”使用操作系统随机源和拒绝采样，不使用 seed；源失败即报错。“种子测试数据”使用固定算法，同参数可复现，不能用作密码、令牌或密钥。返回 JSON 中的 values 可直接复制提取。

## Unicode 检查

报告每个码点的 UTF-8 字节偏移、字符、U+ 编号、十六进制字节以及 attention 标记，并给出 NFC/NFKC 结果。attention 仅提示常见空白、控制和格式字符，不是完整安全检测。

按码点而非可见字形计数；组合字符和 emoji 可能由多个码点组成。NFC 合并规范等价字符，NFKC 还会折叠全角、圈号等兼容字符，可能改变语义。转换结果与原输入分离，最多 10000 码点。

通用边界：工具入口输入最多 1 MiB；结构化报告最多 8 MiB。复制结果由用户主动操作。
