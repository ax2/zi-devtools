# 多个工具窗口的收藏与访问记录

从多个工具快捷方式打开窗口时，收藏、最近工具和常用次数仍共享同一配置目录下的 `ui-preferences.json`。

Windows 保存时在协作文件锁内读取最新文件，只合并本窗口相对读取基线的修改，再原子替换文件：

- 工具访问次数累加，多窗口访问同一工具不会相互覆盖；重复保存不会重复计数。
- 收藏合并本窗口的新增和删除，保留其他窗口对不同工具的修改。
- 最近工具将本窗口的访问合入最新记录，去重并保留最多 20 项。
- 不改动的设置保留其他窗口的新值；不同快捷指令的绑定按键分别合并。

活动窗口约每 2 秒刷新收藏、最近和次数，工具库、开始页和托盘使用同一偏好。刷新不强制切换正在运行窗口的主题、热键或录屏状态，也不覆盖本窗口尚未保存的发现操作。

锁竞争通常等待当前保存结束；等待约 500 毫秒仍不可用时报告失败并保留待保存修改，后续成功保存继续合并。磁盘写入、进程内等待和取消完成仍可能增加实际耗时，并非零阻塞后台保存。损坏、非对象、字段无效或超出 8 MiB 的最新文件会拒绝覆盖；自动只读刷新失败时保留当前显示，不自动重置文件。

每份偏好旁保留一个零字节 `.json.lock` 文件，句柄结束释放锁，无需清理；不要在软件运行时删除它。只有本机制的协作窗口共享事务，直接编辑 JSON 的其他程序没有事务保证。此跨进程锁验收限 Windows，本轮不扩张为备忘录、日程、工作实例或服务配置的跨进程编辑保护。

旧开发版没有使用此协议，升级后请退出旧版本再共享配置；同时运行旧版窗口仍可能覆盖新记录。
