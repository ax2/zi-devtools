# 本机关键词检索

先在“本地知识源”添加文件或目录并扫描，再在“增量知识索引”手动同步。打开“本机关键词检索”，输入关键词，可筛选来源并选择最多 10、25 或 50 条结果。查询在后台只读执行，正文仅来自本机 SQLite 索引，不上传网络。

英文词项用 FTS5 的字面转义 AND 查询，按 BM25 相关度排序；含中文的查询在有界索引中做完整片段字面包含匹配，按相对路径和片段顺序排列。中文当前没有自然语言分词或语义召回，复杂中文问句可能找不到相关文档。特殊输入不会拼接成 SQL。

结果显示来源、相对路径、页/段落位置、片段和 SHA-256。可复制来源引用，或将片段和引用一并复制到其他应用。点击“打开原文件”前，应用会确认来源仍在清单、文件仍在当前扫描快照，重新校验规范路径、大小与文件 SHA-256；文件发生变化、来源被移除或链接替换时拒绝打开。结果是执行查询时的索引快照，源文件变化后需要重新扫描并同步，或再次检索。

本功能不含向量语义检索、混合重排或自动问答；这些能力在工具路线图中单独规划。
