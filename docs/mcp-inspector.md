# MCP 协议调试台

从工具首页搜索“MCP”或左侧“MCP 协议调试台”进入。填写本机 MCP stdio 服务的绝对 EXE 路径；参数为 JSON 字符串数组，例如 `["C:\\path\\server.js"]`，可把脚本路径作为 Node/Python EXE 参数传入。不通过 shell 执行命令。点击“检查服务能力”建立短会话，初始化并校验协议版本，再按服务声明的能力分页读取 tools/resources/prompts 列表。检查操作不会读取资源正文、获取提示词消息或调用工具。

能力结果按“工具”“资源”“提示词”切换。工具页显示服务对只读行为的声明与选中工具的 `inputSchema`。默认输入 JSON 对象后逐次准备并确认调用；未声明只读的工具需要再输入完整工具名。也可为当前服务和工具设“禁止调用”，或在其同时声明 `readOnlyHint=true`、`destructiveHint=false`、`openWorldHint=false` 时明确允许从按钮直接调用。这里的“直接”仍需要用户主动点击，只省去第二次确认；服务端注解只是声明，不能证明程序安全。每次调用都会重新初始化和列举工具，并核对当前完整工具定义与确认时一致；名称、描述、schema 或注解变化时拒绝执行，要求重新检查。

权限规则保存在用户配置目录的 `mcp-permissions.json`，只存摘要与规则，不存原始调用参数或响应。服务身份绑定规范化 EXE 路径、程序内容、参数以及参数中直接引用的文件内容；更换程序或工具定义不会继承旧的直接调用许可。发送 `tools/call` 前还会重新读取权限文件；权限文件损坏时拒绝调用并保留原文件。选“每次确认”可撤销当前规则；若该工具正在调用，将取消当前短会话。已经发送到服务的动作无法保证撤销。规则约束 Zi DevTools 调试台与[本机 Agent 工作台](agent-workbench.md)发起的调用，不能限制服务本身或其他客户端；持久连接和跨客户端权限仍未覆盖。

身份核对为每个程序或直接文件参数设置 256 MiB 上限；超出时仍可检查服务能力、资源和提示词，但不会调用工具或保存授权。通过解释器间接加载的其他文件不一定能纳入身份摘要，因此应只连接可信的本机服务。

资源页明确选择清单中的 URI 后点击“读取选中资源”，显示 `resources/read` 返回的有界 JSON。提示词页选择名称，填写字符串值的 JSON 对象，再点击“获取选中提示词”，显示 `prompts/get` 返回的消息。每次操作都会重新初始化并枚举当前服务；目标已不在新列表中时拒绝发送请求。资源内容可能含敏感信息，请只连接可信服务。

连接目标、输入参数和结果仅在当前应用进程中使用，不写入配置或长期历史。子进程只继承必要的系统路径环境，不继承应用环境中的 API key 等自定义变量；依赖这些变量的服务器暂需后续显式环境配置。服务进程本身是用户选定的代码，本功能不提供沙箱。

检查总时长 15 秒，调用/读取/获取总时长 30 秒；单条消息最多 1 MiB、单个请求最多 256 KiB、每类列表最多 128 项与 8 页。点击“停止并退出进程”可取消当前操作；Windows 使用 kill-on-close Job Object 清理启动的进程树。服务 stderr 不显示，避免把日志中的敏感数据带入界面。当前只支持本机 stdio 的行分隔 JSON-RPC；尚无持久连接、Streamable HTTP、参数表单或通用协议日志。已授权的只读工具可在本机 Agent 工作台使用；独立夹具覆盖协议交互，真实第三方服务兼容性仍待验证。
