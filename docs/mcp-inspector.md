# MCP 协议调试台

从工具首页搜索“MCP”或左侧入口打开。输入本机 MCP stdio 服务的绝对 EXE 路径，参数使用 JSON 字符串数组；例如以 Node 或 Python EXE 启动脚本。不通过 shell 执行命令。点击“检查服务能力”运行一次短会话；点击“连接并保持”则启动同一服务进程供连续操作使用。持续连接闲置 2 分钟自动退出，也可随时点击“断开并退出进程”。路径、参数和结果仅在当前应用进程中使用，不写入配置或历史。

检查会初始化并校验协议版本，按服务声明分页读取 tools/resources/prompts 列表，不读取资源正文或执行工具。工具页展示 `inputSchema` 与服务的只读声明。调用前输入 JSON 对象；默认需要逐次确认，未声明只读的工具还须输入工具名。可为当前服务和工具设“禁止调用”，或在同时声明 `readOnlyHint=true`、`destructiveHint=false`、`openWorldHint=false` 时允许点击后直接调用。“直接”只省去第二次确认，仍需主动点击。服务端声明不能证明服务程序安全。

短会话每次重新初始化；持续连接只初始化一次，但每次操作重新枚举能力。调用会复核当前完整工具定义与用户所见版本相同，发送前重新读取磁盘权限并核对服务身份。工具名称、描述、schema 或注解变化时拒绝调用。资源和提示词也必须先出现在本轮列表中。任意操作、协议或权限错误会结束持续连接，避免把迟到响应误认为新请求。

规则保存在用户配置目录的 `mcp-permissions.json`，只存摘要与规则，不存原始参数或响应。服务身份绑定规范化 EXE 路径、程序内容、参数以及参数中直接引用的文件内容；更换程序或工具定义不会继承旧许可。权限文件损坏时拒绝调用并保留原文件。身份核对对每个程序或直接文件参数设 256 MiB 上限；超出时仍可检查能力、资源和提示词，但不可调用工具或保存授权。规则约束 Zi DevTools 调试台与[本机 Agent 工作台](agent-workbench.md)，不能限制服务本身或其他客户端。已发出的动作无法保证撤销。

每次操作总时长：检查 15 秒，调用、读取或获取提示词 30 秒；持续连接按操作重置限额。单条消息最多 1 MiB、单个请求最多 256 KiB、每次操作接收最多 4 MiB，每类列表最多 128 项及 8 页。Windows 使用 kill-on-close Job Object 清理启动的进程树。服务 stderr 不显示，以免把日志中的敏感信息带入界面。子进程只继承必要的系统路径环境，不继承应用环境中的 API key 等自定义变量。用户选择的服务本身是可执行代码，本功能不提供沙箱。

## Streamable HTTP（Stage 77）

在连接目标选择 Streamable HTTP，填写完整端点，再点击“连接并保持”。当前实现针对 2025-06-18 / 2025-03-26 版协议：支持初始化、JSON 或 SSE 请求响应、会话 ID 和版本头、工具/资源/提示词枚举，以及断开时的 DELETE。连接闲置 2 分钟退出，每次操作沿用上述时长、消息与总输出限制。停止挂起操作会尝试发送取消通知，随后结束连接；这不能保证服务端已执行的动作被撤销。

接受 HTTPS，或主机精确为 127.0.0.1 / ::1 的本机 HTTP 地址；不跟随重定向、不使用环境代理。地址不能包含账号、密码、查询参数或片段。Stage 78 开发分支的 Bearer 和公共客户端 OAuth 入口见下文，尚未发布。HTTP 工具每次调用必须人工确认，不继承 stdio 的持久直接调用规则；实际调用前再次枚举并比较完整工具定义。

会话返回 404 时用不带旧会话 ID 的初始化请求建立新会话，最多等待 15 秒。原操作仍报错，不自动重放；界面清空旧能力清单，需再次点击“检查服务能力”后手动操作。重新连接失败或取消则退出。初始化已经取得会话 ID 但后续校验或通知失败时，也会尝试 DELETE 清理。服务端发起的交互式请求、独立 GET 通知流、心跳、参数表单和通用协议日志暂不支持。2026-07-28 版无会话协议仍需独立适配。一次性本机 HTTP 夹具已覆盖 JSON/SSE、复用、确认、取消通知、消息超限、重定向、定义变化、失效恢复且不重放、恢复失败与初始化失败清理；真实第三方服务兼容性待验证。

## 临时 Bearer（Stage 78 开发中，未发布）

临时认证默认无认证。需要时勾选“本次连接使用 Bearer 令牌”，只输入为当前端点签发的令牌，再连接；密码输入框会清空，断开后须重新输入。切换地址或传输方式也会清空输入。令牌不加入配置、历史或报告，不会读取其他应用的凭据。

同一连接的初始化、后续请求、取消通知和断开 DELETE 使用该认证；会话失效后重新初始化仍使用本次令牌，但不会重放原操作。401 提示重新提供有效令牌，403 提示检查权限，不自动登录、刷新或重试。禁止跟随重定向。

解析后的 JSON/SSE 字符串和对象键中完整令牌回显会在进入界面前隐藏；工具定义若包含令牌则拒绝，以免隐藏过程掩盖定义变化。资源 URI 和提示词名称包含令牌也拒绝，避免改变调用目标。此处理不是通用敏感信息识别，不能识别被编码、拆分、数字化或只回显部分的令牌。

这是临时认证入口；完整 OAuth 登录和自动刷新尚未实现。完整质量检查和界面验收仍在进行。


### 主动保存端点令牌（Stage 78 开发中，未发布）

Windows 下可输入令牌后点击“保存输入令牌”，保存到 Windows 凭据管理器，输入随后清空。保存会替换此端点已有令牌。勾选“连接时使用此端点的已保存令牌”后，只有主动连接时才读取；令牌不回填编辑框。点击“删除此端点已保存令牌”可以撤销保存。

目标按规范化的完整端点绑定，包含主机、路径和端口，与插件凭据使用不同命名空间。更换地址会取消已保存令牌选择；找不到对应凭据就明确失败，不会改用其他端点或临时输入。不会自动枚举或导入其他应用的凭据。断开只释放本次连接，已保存凭据需主动删除。

### OAuth 授权信息预览（Stage 78 开发中，未发布）

展开“OAuth 登录准备 · 查看授权信息”，检查当前目标资源与资源配置地址。默认地址保留 MCP 的路径，也可按服务说明修改。点击读取后，选择该资源声明的授权服务器，再检查将读取的地址，点击读取服务器信息。可预览登录/令牌地址及 PKCE S256、授权码支持声明。

读取仅接受 HTTPS，不带令牌或 Cookie、不使用环境代理、不跟随重定向；单次最长 10 秒、64 KiB。资源标识与当前规范 MCP 地址不一致，或 issuer 与所选服务器不一致时拒绝。更改目标会丢弃旧预览；已启动读取最多继续到超时，不会自动跳转或读取下一个地址。

这是 OAuth 登录的配置前置步骤；当前开发中的公共客户端浏览器登录、PKCE 回调及令牌交换入口见下文，开放注册和主动开启的自动续期入口见后续章节；受保护注册/软件声明及完整互操作仍未完成。

点击“查找服务授权配置地址”时，仅对当前 HTTPS 服务发送不带令牌的 GET。若 401 返回 Bearer resource_metadata 提示，解析并显示该地址；缺少提示或 GET 不支持时生成保留服务路径的默认地址。不会自动跟随提示去读取配置或登录，仍需检查地址并点击下一步。拒绝重定向、多个配置地址、畸形引号以及非 HTTPS 地址；当前不支持 DPoP 地址提示。该操作不初始化 MCP 会话、不调用工具，最长 10 秒。

### PKCE 与本机回调基础（Stage 78 开发中，未接入登录 UI）

新增 S256 PKCE 登录事务，使用独立随机 state/verifier，并冻结资源、客户端、授权服务器和回调地址。验证回调 state、声明的 issuer、重复字段与无效编码；授权码只接受一次。授权服务错误描述不进入界面。

本机回调接收器先绑定 127.0.0.1 随机端口与固定应用路径，再等待回调；仅接受匹配 Host 的 GET 请求，不接收请求体。请求头最多 12 KiB，每个连接读取最多 1 秒，整体等待最多 5 分钟；取消或成功后关闭监听。返回浏览器的文字固定且禁止缓存，不回显授权码或 state。

已通过合成 TCP 回调测试，包括错误 Host/方法/路径/state、重复 Host、请求体、取消、超时和端口释放。这些是回调基础的分项验证；当前浏览器打开、令牌交换和登录 UI 已在下文开发增量中接入，开放注册和主动开启的自动续期入口见后续章节；受保护注册/软件声明及完整互操作仍未完成，不构成完整 OAuth 验收。实现参考 RFC 7636 和 RFC 8252。

### 令牌交换基础（Stage 78 开发中，未接入登录 UI）

授权码经本次回调验证后，以表单发送到绑定的 HTTPS 令牌端点，包含 PKCE verifier、client_id、相同 redirect_uri 和 resource。授权码被消费，不自动重试；明确禁用网络库的重试、重定向和环境代理，不附加已有服务令牌或 Cookie。

响应最多 64 KiB，连接最多 5 秒、整体最多 15 秒，支持取消；仅接受 JSON Bearer 响应，拒绝重复关键字段、成功/错误混合、权限扩大、无效或已过期令牌。访问令牌绑定服务地址；期限缺失显示为未知，不虚构有效期。刷新令牌只在内存保留，主动刷新入口见下文，自动刷新尚未接入。TokenSet 没有 Debug/Serialize，不写入历史、配置或系统凭据；HTTP/JSON 库内部副本不保证全部擦除。

合成 HTTP 夹具验证参数、状态/媒体类型/响应限制、取消与错误隐藏；测试用私有入口允许 loopback HTTP，公开交换入口仍只接受 HTTPS。本轮不是实际授权服务验收，浏览器登录 UI 接入见下一节；开放注册、自动续期已在后续增量接入；受保护注册/软件声明与完整授权互操作仍需完成。

### 浏览器登录入口（Stage 78 开发中，未发布）

读取资源和所选授权服务器信息后，填写服务预注册的公共客户端 ID（token_endpoint_auth_method=none），主动选择权限并点击“在浏览器登录”。使用系统浏览器；后台先绑定本机回调，再验证回调、交换令牌；界面显示等待/交换/完成并提供取消和清除。回调路径固定为 /oauth/callback/zi-devtools，仅端口动态选择，服务必须支持原生客户端 loopback 动态端口；固定路径便于预注册。随机 state 与 PKCE 防止接受其他登录回调。

登录完成后主动“连接并保持”，认证方式与手工 Bearer 互斥；当前端点、客户端、issuer、有效期再次核对。切换端点或认证方式、断开、清除授权会释放 UI 持有的令牌；登录请求被取消后旧结果不能进入新登录状态。已知过期时间到达时由界面轮询发起连接取消，不承诺网络级零延迟终止。系统/网络库内部副本不保证全部擦除。

已验证 21 项 OAuth 专项测试及真实 eframe 明暗界面截图。尚未完成真实授权服务或官方 SDK OAuth 全流程验证、受保护注册/软件声明、完整授权互操作；不是完整 OAuth 验收，未发布 Stage 78。

### 主动刷新授权（Stage 78 开发中，未发布）

服务提供 refresh_token 后，可在尚未连接时点击“刷新本次授权”；已连接且没有操作运行时，点击“断开并刷新授权”。后者主动断开当前会话再刷新，成功后由用户重新连接，不重放原工具调用。普通断开/清除仍清除授权。

刷新表单只包含 refresh_token、client_id、resource 和 grant_type，发送到原绑定 HTTPS 令牌端点，沿用 15 秒整体/64 KiB 响应限制及取消；不自动重试、跟随重定向或发送原访问令牌。新响应可以收窄原权限，不可扩大。返回新刷新令牌时替换旧值；未返回则保留原值。旧 TokenSet 在刷新开始时移出界面，失败或取消后丢弃，避免重用结果不明的轮换令牌；需要重新登录。

24 项 OAuth 专项测试通过，包含参数绑定、过期访问令牌的主动刷新、刷新令牌轮换/未返回时保留、缺失刷新令牌、取消标记、权限扩大、状态错误与重定向拒绝。开放注册和自动续期入口见后续章节；受保护注册/软件声明、完整授权互操作和真实服务完整验证仍待完成，本轮不是完整 OAuth 完成。

### 持续连接凭据更新基础（Stage 78 开发中，未发布）

HTTP worker 新增端点绑定、带确认响应的凭据更新通道，只在操作之间替换认证客户端；保留会话 ID 和协议状态。收到 404 后使用最新凭据重新初始化，不重放失败操作。更换目标或无效 Bearer 更新会拒绝并关闭原会话。

当前连接内保留最多 32 个完整已知令牌用于响应屏蔽，包含旧令牌；会话重建前继承屏蔽集合，连接结束释放。达到上限停止连接，需重新连接，不无限积累。仍不承诺识别编码、拆分或部分令牌。新增两个合成 TCP 测试验证轮换、恢复、旧值屏蔽和无效更新拒绝；HTTP 专项共 13 项通过。该通道现已连接下一节的自动续期界面和调度器，尚未完成真实服务互操作。

### 连接期间自动续期（Stage 78 开发中，未发布）

登录后可主动勾选“连接期间自动续期授权”，默认关闭，仅适用于当前目标。服务必须返回刷新令牌及超过 30 秒的明确有效期；提前量为有效期五分之一且限制在 20–60 秒。未知或极短有效期不安排自动刷新，过期后断开。授权仍不持久保存。

空闲时启动续期，正在执行的操作先完成，不重放操作；续期及连接确认期间暂停新操作。新令牌经端点绑定通道交给连接，确认最多等待 3 秒，成功后保留会话继续使用。刷新失败/取消、确认拒绝/丢失/超时或期限到达都会断开并要求重新登录，不回退旧凭据。切换到其他工具页面也继续后台轮询。

新增期限调度及 5 项连接状态测试，验证确认前阻止操作、确认后恢复、失败/丢失/超时、忙操作延后和待刷新时过期。实际 eframe 合成状态明暗界面可预览开关；这些分项测试不证明真实授权服务或官方 SDK 的完整自动续期互操作。受保护注册/软件声明、完整授权互操作与 Stage 78 发版仍待完成。

应用级轮询已覆盖切换工具页面；托盘隐藏和系统休眠恢复时的调度仍需实际验证，不把当前页面状态测试当作完整后台生命周期验收。

### 开放客户端注册（Stage 78 开发中，未发布）

服务声明 HTTPS registration_endpoint、公共认证 none、授权码和 PKCE S256 时，可主动点击“注册并登录”。按 [RFC 7591](https://www.rfc-editor.org/rfc/rfc7591) 发送公共客户端元数据，使用本次回调的实际动态端口；收到验证通过的注册结果后，保持同一个本机 listener 并打开浏览器登录。

只支持无需初始访问令牌的开放注册，不发送 Authorization/Cookie，受保护注册或软件声明仍不支持，可改用预注册客户端。响应必须是 201 JSON，不跟随重定向、不自动重试；64 KiB 响应上限、5 秒连接/15 秒整体时限及在途取消。拒绝密钥、混合错误、重复关键字段、回调/认证方式改变和权限扩大；服务器缩小权限时同步缩小登录申请。

动态 ID 只用于这次回调，清除时丢弃，不能换端口当作手工预注册 ID 重用；再次注册并登录会创建新客户端。服务端记录可能保留，失败或取消不会自动删除，界面在操作前说明。注册 ID/响应不持久保存；底层网络/JSON 副本不承诺全部擦除。

32 项 OAuth 分项测试通过，新增合成 POST、响应限制/异常、在途取消、HTTPS 入口与注册结果状态验证；不是实际服务或完整 SDK OAuth 验收，公共客户端撤销见下一节，完整互操作仍待完成。

### 主动撤销授权（Stage 78 开发中，未发布）

根据 [RFC 7009](https://www.rfc-editor.org/rfc/rfc7009)，服务明确声明 HTTPS revocation_endpoint 和认证方式 none 时，可以点击“撤销服务端授权”，连接期间则是“撤销授权并断开”。撤销地址在登录时冻结并随刷新保留，界面显示实际目标。先结束本机授权/自动续期/连接，再分别发送刷新令牌和访问令牌；无刷新令牌只发送访问令牌，已过期的令牌也可主动撤销。

每个令牌仅发一次，表单只有 token、token_type_hint、client_id；不附 Authorization/Cookie、不跟随重定向、不使用代理或自动重试。连接上限 5 秒，整个撤销任务最多 15 秒并可取消；响应正文不读取/保留/显示。仅把 HTTP 200 视为接受请求；未知令牌也可能被接受，不宣称具体 grant 全部失效。失败、取消或超时只报告未确认/未知，本机不恢复旧凭据。

普通清除和断开只移除本机授权，不联系服务端；撤销不会删除动态注册的服务端客户端记录。服务未声明公共撤销时仅提供本机清除。新增合成 TCP 表单/两类令牌/过期/拒绝/重定向/取消/整体期限、端点冻结和 UI 不恢复测试；实际服务或官方 SDK 的完整撤销互操作仍需验收。
