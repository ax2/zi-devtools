# 图片工作台（Stage 40 / v0.40.0）

从侧栏“图片工作台”或搜索进入。选择 PNG、JPEG 或 WebP 图片后，可查看像素尺寸与原文件大小；调整输出宽度会保持宽高比，只允许缩小。选择 PNG、JPEG 或 WebP 输出，JPEG 可调质量。点击“生成编码预览”后展示从最终编码字节重新解码的预览图与实际字节数，确认另存路径后才会写入新文件。

所有处理在本机完成，不上传文件。单个输入文件不超过 32 MiB，解码像素不超过 1600 万；读取与编码在后台运行。另存要求扩展名与格式一致，目标已存在时拒绝覆盖；原图不修改。WebP 输出目前为无损编码，JPEG 对透明图层的表现需在预览中检查。批处理、可视化裁剪/标注与 EXIF 清理仍在规划清单中。
