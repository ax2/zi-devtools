# 图片工作台（Stage 43 / v0.43.0）

从侧栏“图片工作台”或搜索进入。选择 PNG、JPEG 或 WebP 图片后，可查看像素尺寸与原文件大小；调整输出宽度会保持宽高比，只允许缩小。选择 PNG、JPEG 或 WebP 输出，JPEG 可调质量。点击“生成编码预览”后展示从最终编码字节重新解码的预览图与实际字节数，确认另存路径后才会写入新文件。

切换“批量处理”后，可一次选择 1–100 张图片，选择已有输出目录、统一最大宽度、格式和 JPEG 质量。先点击“检查并预览输出清单”：页面展示每张原图尺寸、大小、生成的 `-batch` 文件名，并检查已有目标及批次内重名；存在冲突时不能开始。确认后逐张处理，页面显示进度、每项成功或失败及实际文件大小。“取消余下任务”会在开始下一张、分块写入或最终发布前停止；图像编码本身不能中断，编码结束后再检查取消。已发布的文件保留；再次运行前需重新预检。

切换“元数据检查”后，选择静态 PNG/JPEG/WebP，可查看常见 EXIF、GPS 目录、ICC、XMP、文本与 IPTC 块数量；不展示坐标或其他元数据原值。点击“生成清理预览并复检”会按 EXIF 方向处理像素、重新编码同格式文件，检查输出不含已识别的源元数据块，并显示实际预览。确认后另存 `-cleaned` 副本。动画 PNG/WebP 拒绝处理，避免丢帧。ICC 色彩配置移除与 JPEG 重压缩可能改变显示效果；复检只覆盖已识别的常见标准块，不承诺清除所有私有格式数据。

切换“裁剪与标注”后，选择静态图片。在原图预览上选择“裁剪”“黑色遮挡”或“箭头”并拖动；选“文字”后输入内容并点击画布定位。可撤销上一步或清空操作；再次裁剪以最后的裁剪范围为准。画布坐标映射到原图像素，导出时先裁剪，再按添加顺序绘制遮挡、箭头和文字。中文文字使用本机字体，必要时可指定 TTF/TTC/OTF；字体缺字会明确报错。点击“生成输出预览”后展示从最终编码字节重新解码的画面、像素尺寸和实际文件大小，再确认另存路径。JPEG 会把透明区域铺白；遮挡会写入像素，但仍需检查画面中的其他敏感信息。编辑过程不修改原图。

所有处理在本机完成，不上传文件。单个输入文件不超过 32 MiB，解码像素不超过 1600 万；读取与编码在后台运行。单张另存要求扩展名与格式一致，批量输出目录必须已存在；目标已存在时拒绝覆盖，原图不修改。WebP 输出目前为无损编码。裁剪与标注读取时会处理 EXIF 方向并拒绝动画，以免导出首帧造成误解。

dev85起，单图转换、裁剪标注、元数据清理和批量输出统一先写入同目录随机暂存文件，完整写入并同步后再无覆盖发布到最终路径。其他工具不会在最终路径读到正在写入的半成品；若目标在发布前出现，保留目标并报告失败。失败只清理暂存，预览和原图保留。单图保存没有新增取消按钮。普通相对输出路径仍可使用；Windows设备名和数据流等特殊名称拒绝。
