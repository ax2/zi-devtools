# Embedding 工作台

从工具搜索或左侧“Embedding 工作台”进入。确认本机 Ollama 已运行并有支持嵌入的模型；接口默认为 `http://127.0.0.1:11434/api/embed`。可点击“获取本机模型列表”，但列表也可能包含不支持嵌入的聊天模型，需要自行选择。填写模型与两段文本后点击“生成并比较向量”。

工作台展示模型、维度、两向量范数、余弦相似度、欧氏距离和各向量前 8 个元素；可复制完整向量 JSON 或简短指标。两段文本各限制 4000 字符和 16 KiB；只接受 `127.0.0.1` 或 `::1` 回环地址的 `/api/embed`，不使用代理、重定向或 URL 凭据。连接最长 5 秒、请求总时长最长 120 秒、响应不超过 4 MiB、向量维度不超过 8192。取消会停止等待并关闭客户端请求；模型服务已启动的计算可能继续到服务端自行结束。

请求和结果只保存在当前应用内存，应用不写入配置或日志。文本会送到你选择的本机 Ollama，服务端是否记录由其设置决定。相似度是当前模型的数值结果，不证明文本事实相同。此工具不修改知识索引，也不提供向量检索或混合重排；后续阶段会分别设计版本、增量同步、资源预算和评测。
