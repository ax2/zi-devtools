# 目录空间分析

从“文件与系统”或工具搜索打开“目录空间分析”，选择本机目录后点击“开始分析”。工具在后台读取目录项和文件元数据，按文件逻辑长度显示已统计总量、最大的直属子目录和最多 20 个大文件；不打开文件正文，不删除或移动任何内容。路径及结果只保留在当前窗口内。

扫描最多检查 250,000 个条目、深入 24 层，约 20 秒时停止继续枚举，可随时取消；单次文件系统调用若阻塞，无法保证严格在 20 秒内结束。符号链接和 Windows 重解析点不会递归；无法读取的目录、链接、深度与时间/条目上限都会使结果标为“部分结果”，所示大小只代表已统计内容。扫描过程中目录发生变化也可能影响结果。

文件逻辑长度不等于实际磁盘分配空间。稀疏文件、压缩、硬链接以及文件系统元数据都可能造成差异；硬链接会按路径重复计数。该工具帮助定位空间占用，不判断文件是否可安全删除。项目本身的定期构建缓存清理仍由 [磁盘维护脚本](maintenance.md)单独负责。
