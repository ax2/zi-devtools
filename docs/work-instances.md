# 数据工作实例（v0.78.0）

数据工作台、列转换和表格合并现在共享命名工作实例。每个实例拥有自己的输入、解析后表格、筛选、导出结果、合并右表、待应用预览和一步撤销状态。工具入口仍共享同一组数据实例，避免误认为每次搜索打开都会新建一份。

## 使用

1. 打开数据工作台，点“新实例”，输入名称。实例选择框可在多份材料之间切换；后台解析和合并继续收取结果。
2. 文件导入到 CSV/TSV/JSON 表时自动新建实例。结果接力到数据表默认也新建，可以明确选择替换当前实例。
3. 点“保存快照”，查看保存内容和本机位置后确认。点“另存副本”可保留原保存项。也可为当前实例单独启用自动保存；会先显示保存位置、明文存储和配额说明并要求确认。
4. 重启后从开始页或工作台打开“已保存实例”，搜索名称并打开。打开保存项会创建独立实例；如果已打开同一个保存项，则回到原实例并保留当前修改。
5. 关闭实例需确认放弃未保存修改。已经保存的快照保留；在实例库中删除保存项需另行确认，不删除原始文件，已打开实例也保留。

手动保存的是点击时的内容。启用自动保存后，当前实例在编辑停止 3 秒后保存；解析、转换、合并或流程任务运行时会等任务结束再保存。自动保存按实例控制，只在本次程序运行期间有效，重启后默认关闭。保存中可继续编辑，保存完成提示只对应当时捕获的快照；后续编辑会在下一次空闲后再次保存。内容与最近保存的 SHA-256 摘要一致时会跳过写入，避免无意义地增加版本。

自动保存同样写入本机未加密的 `workspace.sqlite3`，可能包含输入、表格内容和路径。启用前需要在确认框同意；随时可暂停，暂停不会删除已保存快照。自动保存不是退出保证：程序关闭或系统强制结束前若 3 秒计时、后台任务或写入尚未完成，最后修改仍可能未保存。需要确认保留时，请查看实例显示的保存版本，或使用手动“保存快照”。

## 保存范围和恢复

原始输入、文件路径、当前表格、当前筛选/排序、导出结果、合并参数及预览、转换参数/预览/一步撤销会保存到配置目录旁的 `workspace.sqlite3`。这是本机明文数据库，可能包含用户输入的敏感内容；确认框显示具体保存位置。凭据管理方式没有改变。

创建或使用临时实例不会创建保存库；打开不存在的保存库返回空列表。自动保存通过写时复制捕获表格行，在后台完成编码、校验和写入；快照捕获仍需复制有界文本字段。若用户正好在后台保存期间修改表格，首次修改可能复制整份表格行，实际大表延迟仍需在运行环境中测量。

恢复只读取已经保存的内容，不读取原始文件、不重新解析、不运行命令或网络请求。运行中的任务不能保存或关闭；当前不支持程序退出后恢复未完成的执行。退出程序会提醒保留数据工作，系统强制结束进程无法保证提示。

任务中心为数据解析和合并记录实例标识及名称，取消与打开关联正确实例。已经关闭的实例无法从旧任务记录直接复活，可从保存库主动恢复。其他工具继续使用原有任务机制；不是全平台统一运行管理器。

## 限额和一致性

- 同时最多 16 个数据实例；最多保存 256 项，快照内容总计 128 MiB，单项 64 MiB。SQLite 元数据和事务临时文件另占空间，不将内容配额等同于总磁盘占用。
- 保存和删除检查之前读取的版本；版本冲突不会覆盖或删除较新的保存项。可另存副本，或关闭后重新打开最新保存项。
- 保存使用 SQLite 事务；内容通过恢复校验后才写入。格式版本未知、列索引错误、行宽不一致或内容超限会拒绝加载，已打开的实例不受影响。
- 删除保存项不可撤销；库启用自动页回收。没有后台自动删除用户保存项。

这一轮接入数据实例的会话级自动保存。跨工具项目空间、保存历史、完整运行恢复、图片/文档实例、通用类型化结果和插件/Agent 写操作仍按路线继续推进。后续格式变化必须维护旧版读取或显式迁移，不得静默覆盖不支持的版本。

## 从全局搜索返回当前实例

按Ctrl K，选择“工作实例”（Ctrl 5），输入实例名称即可返回本次程序运行中已打开的数据工作。全局快捷面板也提供同名页签，并可同时查找图片流程实例。搜索结果显示当前视图和运行/待确认状态；同类同名实例用短标识区分。切换保留原工作与后台任务，支持Alt+左右方向键返回。这里不加载未打开的保存项；恢复快照仍使用“已保存实例”。
