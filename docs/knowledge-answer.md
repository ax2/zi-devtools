# 带引用的本机知识问答

先在“本地知识源”添加并扫描文档，再在“增量知识索引”手动同步。打开“带引用的知识问答”，选择默认的“关键词”或“关键词 + 向量”证据模式。混合模式还需先在“本机向量索引”使用 Ollama `/api/embed` 嵌入模型同步，并在问答页填写同一模型和回环地址；嵌入模型与随后生成答案的模型分别设置。填写问题与简短检索词（混合模式中同一检索词也作为语义查询），选择来源、最多 3、5 或 8 条证据，以及混合模式的 25/50/75% 关键词权重。

点击“准备证据”会检索并核验本机文档。混合模式复用双通道有界 RRF 排序、来源筛选、当前索引版本复核，并展示两路排名、贡献与余弦相似度；准备过程可取消。模型/索引异常不会暗中改用单路结果。每份候选原文件还会与扫描快照的 SHA-256 核对，最多取 8 条有效证据。改变问题、检索词、来源、Top K、模式、嵌入模型或权重会清除旧证据及答案。没有可核验的证据时不会调用问答模型。

检查编号、来源、页/段落位置及片段后，选择 Ollama 或 OpenAI 兼容协议，填写本机模型名称，点击“用本机模型生成答案”。也可从本机服务获取模型列表。接口只接受 `127.0.0.1` 或 `::1` 回环地址：Ollama 使用 `/api/chat`，OpenAI 兼容服务使用 `/chat/completions`。远程地址、账号密码、URL 查询参数和重定向均不接受。调用前再次核验原文件版本；取消会中断正在进行的流式请求。

模型必须返回包含 `status`、`answer`、`citations` 的 JSON。`citations` 只能是本次证据的编号；编号缺失、越界、重复或输出不合约时，应用不采纳答案。模型报告证据不足时只显示证据不足提示。答案及引用可以复制到其他应用，也可以打开原文件核对。引用编号有效仍不保证陈述在语义上真实受证据支持，使用者应检查原文。

应用不把问题、证据或答案写入自身配置或日志；混合检索会把检索词发送给选定的本机 Ollama 嵌入服务，生成答案时会把有限证据片段发送给选定的本机问答服务，服务日志由各自设置决定。中文关键词仍是短语字面包含匹配，RRF 排名分不是事实可信度；不自动联网。[固定样例 RAG 评测](knowledge-eval.md)可在同一批题上对照关键词与混合检索，十题以内的样例仍不足以证明普遍效果提升。
