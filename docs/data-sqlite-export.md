# 表格另存 SQLite（Stage81 开发中）

当前源码 v0.81.0-dev.1；尚未发布为正式安装包，正式版仍为 v0.80.0。九项后台验证、416项完整测试和严格Clippy通过；原生预览返回、确认保存、主动查看及实例保留验证通过，明暗/窄窗口已实屏检查；最终产物与正式发布仍待验收，原生文件选择器尚未自动验收。

从统一搜索查找“表格另存 SQLite”“CSV转SQLite”或“JSON转SQLite”，也可在数据工作台展开“另存为 SQLite”。先解析、筛选、排序或清洗表格，再选择保存范围、表名和新文件路径，点击“预览保存…”。

默认保存全部筛选结果，按当前排序写入；勾选“保存全部行”则忽略筛选/排序，按原始顺序写入。预览展示真实行列数、目标、字段和前五行样本；保存包含整个选择范围，不只包含屏幕上的200行。确认前不写文件，关闭确认窗口可返回编辑。确认后写入打开预览时的独立快照，后续编辑不会改变已批准的内容。

保存只创建新的单表数据库，不追加或替换已有数据库。表名和字段正确引用，值使用参数绑定。字段名不能只在ASCII大小写上不同；空名、NUL及超过512字节的标识符拒绝。最多10000行/128列，另存快照最多32MiB。

CSV字符串不自动猜测数字，保留前导零与空字符串。JSON NULL保持NULL，可精确表示的整数/浮点按值保存；布尔变为整数0/1，超过SQLite有符号64位整数范围的正整数变为十进制文本，数组/对象变为JSON文本。预览列出这些转换的数量；此格式不能仅靠列声明恢复所有原始JSON类型。

后台先写独立临时数据库，事务提交并校验行数和数据库完整性，再无覆盖发布目标文件。目标在确认后出现也会拒绝，不覆盖其内容。当前发布方式需要支持硬链接的文件系统，例如NTFS；不支持时失败并保留原表格。可在提交目标前取消，已发布成功不会因晚到的取消自动删除。正常失败/取消清理本次临时数据库；强制终止可能遗留 `.zi-sqlite-export-<UUID>.sqlite` 临时文件。

后台任务归属于发起的命名数据实例；切换工具或实例仍收取结果，写入过程中禁止关闭该实例或保存工作实例快照。后台任务页可以取消并返回发起实例。成功显示实际文件大小与行数；点击“用 SQLite 浏览器查看…”才打开，只读浏览器已有工作正在读取时拒绝替换，可稍后重试。

SQLite浏览器支持最多128列、每页50行；长文本和BLOB仍受原有预览限额约束。这里的新文件另存能力不改变浏览器的只读性质，也不等于任意SQL、现有库改表、通用授权写入、Agent写操作或可保存配方已实现。
