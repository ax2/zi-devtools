# 文档解析与分块

先在“本地知识源”添加文件或目录并手动扫描，再从侧栏“文档解析与分块”选择知识源、文档，点击“解析并预览分块”。解析在后台运行；正文只在本次进程内存中展示，不上传，也不写入知识源配置。解析前会重新计算原文件 SHA-256；内容已变化时，先回到知识源刷新扫描。

支持 Markdown、UTF-8 文本、UTF-8 HTML、PDF 和 DOCX。Markdown 提取可见文本，HTML 跳过脚本与样式内容，PDF 按页提取嵌入文字，DOCX 读取主正文段落。每个分块保留页码或段落位置、顺序号与 SHA-256。分块长度最多 800 个 Unicode 字符，相邻分块重叠 100 个字符；列表每页显示 20 个，可翻页查看所有分块。

单文件上限 16 MiB、提取正文 4 MiB、PDF 200 页、最多 2000 个段落与分块。损坏文件、过期快照和超限都会显示错误。加密 PDF 与只有图片的扫描 PDF 不能提取文字，当前没有 OCR；复杂 PDF 排版、DOCX 文本框及网页隐藏但未使用 script/style 标签的内容可能无法准确还原。索引、跨文档搜索与问答将在后续阶段接入。
