# 文档解析与分块

先在“本地知识源”添加文件或目录并手动扫描，再从侧栏“文档解析与分块”选择知识源、文档，点击“解析并预览分块”。解析在后台运行；正文只在本次进程内存中展示，不上传，也不写入知识源配置。解析前会重新计算原文件 SHA-256；内容已变化时，先回到知识源刷新扫描。

支持 Markdown、UTF-8 文本、UTF-8 HTML、PDF、DOCX、PNG、JPEG 和 WebP。Markdown 提取可见文本，HTML 跳过脚本与样式内容，PDF 按页提取嵌入文字；没有嵌入文字的 PDF 页面会用 Windows 原生 PDF 渲染器栅格化后交给本机 OCR，选择文档后手动点击“解析并预览分块”才会处理。扫描页 OCR 会沿用当前会话选择的本机已安装语言；未选择时跟随 Windows 用户首选语言。图片预览也可使用同一语言选择；扫描文件时不会触发 OCR。识别结果会合并相邻汉字间的空格，保留拉丁字母边界和换行，减少中文字面检索漏命中。图片最多 16 MiB、1600 万像素；单份 PDF 最多 OCR 50 个无文本页面，单页渲染长边最多 1200 像素、最多 800 万像素；识别正文最多 4 MiB。没有可用 OCR 语言功能时会明确失败，不会切换到在线服务。每个分块保留页码、段落或图片 OCR 位置、顺序号与 SHA-256。分块长度最多 800 个 Unicode 字符，相邻分块重叠 100 个字符；列表每页显示 20 个，可翻页查看所有分块。

预览完成后可点击“导出完整文本…”将所有分块按页码/段落重组为 Markdown；导出会去除用于检索的 100 字符分块重叠，不会重复正文。通过保存对话框选择路径后，应用使用同目录暂存并以无覆盖方式发布；同名文件存在时会报错并保留原文件。导出不会自动打开文件，也不会自动写入知识源或索引。

单文件上限 16 MiB、提取正文 4 MiB、PDF 200 页、最多 2000 个段落与分块。损坏文件、过期快照和超限都会显示错误。加密 PDF 不支持；无文本页面超过 50 页时需先拆分 PDF。扫描页 OCR 只保留每页识别出的文本和页码，不提供文字坐标、OCR 编辑或独立导出；当前中文质量证据仅覆盖高对比度合成图片和单页扫描 PDF，真实扫描件、复杂排版、倾斜/低对比度、多语言混排仍需更多样本评估。可随后在[增量知识索引](knowledge-index.md)手动保存分块；检索与引用问答已提供独立的关键词、混合检索和本机模型工作台。
