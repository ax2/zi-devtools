# SQLite 浏览器

从首页搜索“SQLite”或左侧“SQLite 浏览器”打开。输入数据库绝对路径，或点“选择文件…”，再选“打开数据库”。数据库打开后默认只读浏览；工具列出普通表和视图，可按页预览、导出当前页 CSV、创建一致的本机数据库副本，或把当前页的冻结快照送入数据工作台。只有主动选择单元格或行、查看变更预览并再次确认后才会修改源数据库。

## 创建本机数据库备份

点“备份数据库…”并在系统保存对话框中选择目标文件，即表示明确授权在所选位置创建副本。程序使用 SQLite 在线备份接口生成一致快照，包含已提交的 WAL 数据；源数据库只读打开，不修改源库。备份完成前可以取消；进度明确区分数据库复制、完整性检查和无覆盖发布阶段。副本会执行 `integrity_check`，然后通过同目录临时文件无覆盖发布。目标文件已存在、路径无效、源库被替换或目标目录不支持同卷硬链接时会拒绝发布，临时文件会清理。工具不自动备份、不创建恢复点，也不负责还原数据库。

## 编辑单个单元格

选中数据格后点“编辑选中单元格…”。新值使用 JSON 标量格式：文本需带双引号，例如 `"ready"`；也可输入整数、小数、`true`、`false` 或 `null`。程序先验证数据库结构和主键，再在事务中试运行单条更新，读取 SQLite 实际应用列约束后的值并回滚。预览对话框显示旧值和新值；只有再次点“确认写入”才会重新检查数据库结构、主键和原值，并在事务内提交更新。

每次操作最多修改一个普通表中的一个非主键标量单元格。定位要求当前页包含完整、可表示的主键列；BLOB、截断值、非 UTF-8 文本和非有限数不能编辑。程序不接受 SQL，不修改主键，也不支持视图、虚拟表或无主键表。为避免预览遗漏数据库内部副作用，含触发器或任意外键关系的数据库暂时拒绝写入。新值对象、数组和超出 SQLite 64 位整数范围的整数也会被拒绝。

确认前若数据库文件被替换、结构或目标旧值改变，程序拒绝提交并要求重新读取、预览。取消预览不会保留更改；提交失败时 SQLite 事务回滚。WAL 模式下 SQLite 仍可能管理辅助文件。更新由单元格的 SQLite 列亲和性处理，预览显示数据库实际保存值；CHECK、UNIQUE 等约束失败时不提交。

提交后，SQLite 浏览器保留最近最多 20 步单格操作的本机撤销/重做记录。撤销和重做也会显示目标数据库、表、主键、新旧值，并要求再次确认；执行前复核文件身份、结构和当前值，数据库被外部修改时拒绝操作并清空失效历史。新修改会清空重做记录。历史只存在当前应用会话，退出后不恢复。可在修改前主动创建独立副本；目前没有自动备份或跨重启撤销能力。

## 删除当前页的单行

在目标行任一单元格上单击以选中该行，再点“删除选中行…”。程序会在立即事务中按主键核对整行内容、试运行删除并回滚；预览会显示数据库、表、主键及各列值（过长内容会标注为截断摘要）。只有再次点“确认删除行”才会重新检查文件身份、结构、主键和全部列值，并提交单行删除。操作不接收 SQL，也不能批量删除。

删除可在当前应用会话中通过撤销恢复，重做会再次删除；撤销/重做仍需逐次确认。行快照最多随最近20步历史暂存在内存，退出应用即丢失。`rowid` 表会一并核验并恢复原始内部行身份，`WITHOUT ROWID` 表按主键恢复。遇到生成列/隐藏列、无主键、外键、触发器、BLOB、超长或其他无法精确读取的值，或 `rowid` 被所有别名列遮蔽时拒绝删除，以免撤销无法完整还原。恢复前如果目标主键或原始 rowid 已被占用会拒绝覆盖；数据库内容或文件身份发生变化也会拒绝操作。此功能不是数据库备份。

## 只读查看与导出限制

最多列出前 200 个表/视图、128 列，每页 50 行，最多浏览前 10000 行。查询有约 5 秒预算，停止读取可取消后台预览，锁等待最多 1 秒。分页每次重新读取，其他程序修改数据库时各页不保证属于同一快照。

文本单格最多预览 4 KiB、整页最多保留 2 MiB 文本；BLOB 只显示长度和最多 24 字节十六进制前缀。CSV 只包含当前页已显示的值，NULL 导出为空，BLOB 导出为预览标记；已有文件不会被覆盖，并为可能触发电子表格公式的文本添加安全前缀。

数据库路径、编辑草稿、预览和撤销/重做历史只保留在当前应用进程，不上传或自动保存到历史。当前页接力创建新的数据实例，不修改 SQLite 文件。备份路径由用户逐次选择，不写入配置或历史。工具版本 `1.5.1`；完整历史见 [工具版本目录](tool-versions.md)。
