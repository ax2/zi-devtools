# SQLite 浏览器

从首页搜索“SQLite”或左侧“SQLite 浏览器”打开。输入数据库的绝对路径，或点击“选择文件…”，再点击“只读打开”。工具列出普通表与视图；选择对象后显示列结构、当前页数据，可翻页或主动导出当前页 CSV。

首版只执行程序生成的表/视图预览查询，不接受任意 SQL，也不修改数据库内容。连接使用 SQLite 只读标志并设置 `query_only`；WAL 模式下 SQLite 仍可能管理辅助文件。数据库路径和结果只留在当前应用进程，不上传或自动存入历史。

最多列出前 200 个表/视图、每个结果 64 列；每页 50 行、最多浏览前 10000 行。每次查询的 SQLite 进度回调设置约 5 秒预算，可点击“停止读取”，数据库锁等待最多 1 秒。超时、取消、文件损坏或文件被替换会显示错误。分页每次重新读取，其他程序修改数据库后各页不保证同一快照。

文本单格最多预览 4 KiB、整页最多保留 2 MiB 文本预览；BLOB 只显示长度与最多 24 字节十六进制前缀。截断会在界面提示。CSV 只包含当前页已显示的预览值，NULL 导出为空，BLOB 导出为预览标记；已有文件不会被覆盖。可能触发电子表格公式的文本与列名会在导出时加安全前缀。写模式及事务回滚继续保留在规划中。
