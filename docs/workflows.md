# 操作流程与文件重用（v0.82.0-dev.2 开发中）

此功能尚未正式发布。按Ctrl K搜索“操作流程”“多步清洗”或“连续转换”，进入数据工作台；先解析CSV/TSV或JSON对象数组，再展开“操作流程 · 连续预览”。

添加列操作或选列步骤。列操作包括去空白、大小写、空值处理、改名和类型转换；可以上移、下移、移除，最多32步。列按名字绑定，改名后的下一步使用新列名；选择保留列沿用输入表顺序。流程处理当前解析表的全部行，包含筛选隐藏的行；原始输入框中的未重新解析编辑不改变这份表格快照。

点击“预览全部步骤”在后台生成完整结果，逐步报告行列数、变化条数和最多六处变化样本。错误显示步骤和转换错误；不会把之前成功步骤自动写回原表。预览完成后点击“应用流程结果”才替换当前数据表，原始输入保留；流程区域的“撤销最近一次表格修改”或列转换区域可以撤销最近一次修改，仅支持一层。CSV字符串前导零不会隐式转换，JSON类型和转换限制沿用现有列转换说明。

编辑步骤或名称、重新解析、手工转换、合并或撤销都会清除旧流程预览。任务返回前或应用前还会复核来源；来源变化拒绝旧结果。预览中编辑器暂禁用，可以取消；取消在有界步骤前后检查，不承诺立即中断单个转换。切换工具或实例不会自动应用，任务中心可返回准确实例、查看状态或取消该轮任务。运行中不能关闭实例或保存快照。

## 保存流程并再次使用

点击“保存流程…”选择一个新的 JSON 文件名。文件只包含流程名称、格式版本、步骤和参数；参数中的文字按原文保存，不附带输入表、预览结果或文件/网络授权，也不会从其他工具读取凭据。已有文件拒绝覆盖；需要更新时请另存新文件。保存时冻结步骤快照并在后台写入，不会运行流程。磁盘写入失败会保留当前步骤，但目标可能留下不完整文件；检查目标后另选文件名重试。

以后先解析一份新的表格，再点击“使用已有流程…”。读取后显示名称、步骤及参数，确认才替换当前步骤；取消或按 Esc 保留原步骤及其有效预览。确认替换会清除原流程预览，当前表格和原始输入保留，不自动预览、应用或保存。确认期间禁止开始或应用流程，也不能再次读取或保存定义。随后主动预览并应用；新输入缺少引用列时会报告具体步骤，原表保留。

流程文件最多256 KiB，格式版本为1；未知版本/字段、损坏文件和无效参数拒绝读取。定义中的文字与参数只交给已支持的表格动作，不作为脚本或命令执行。

**工作实例快照仍不包含流程步骤。** 跨次使用需要单独保存流程文件；未另存的步骤仅在本次运行保留。自动保存、流程库搜索、逐步完整产物和文件写步骤仍在后续开发，不能把这版视为完整自动化平台。

表格最多10000行/128列、8MiB，流程最多32步；列引用和新列名有长度限制，填充参数最多4096字节。应用结果后，可继续现有CSV/JSON导出或新SQLite另存，文件写入仍需独立选择目标和确认，不因运行流程自动获得文件或网络权限。插件、图片、MCP和Agent尚未接入此执行器。

架构、授权及扩展验收计划见[流程设计](workflow-design.md)。正式版状态以[版本下载](https://github.com/ax2/zi-devtools/releases/latest)为准。
