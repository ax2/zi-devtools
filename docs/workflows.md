# 操作流程与文件重用（工具0.13.0 / v0.82.0-dev.70 开发中）

此功能尚未正式发布。按Ctrl K搜索“操作流程”“多步清洗”或“连续转换”，进入数据工作台，展开“操作流程 · 连续预览”。可以先建立或读取流程，再准备输入表；没有已解析表格时，预览和应用禁用，保存与读取定义仍可用。

添加列操作、选列或行步骤。列操作包括去空白、大小写、空值处理、改名和类型转换；可以上移、下移、移除，最多32步。列按名字绑定，改名后的下一步使用新列名；选择保留列沿用输入表顺序。流程处理当前解析表的全部行，包含筛选隐藏的行；原始输入框中的未重新解析编辑不改变这份表格快照。

没有已解析表格时，列名可以手动填写，保留列可以逐项添加、修改或移除。随后载入或填写CSV/TSV、JSON对象数组并点击“解析数据”，已有流程定义会保留，再按新表的列选择和调整。已载入流程引用的保留列若不匹配，也可以直接更名或移除；其他缺少的列由预览报告具体步骤。未知列或重复保留列不会改变后续步骤的预测选择列表。

点击“预览全部步骤”在后台生成完整结果，逐步报告行列数、变化条数和最多六处变化样本。错误显示步骤和转换错误；不会把之前成功步骤自动写回原表。预览完成后点击“应用流程结果”才替换当前数据表，原始输入保留；流程区域的“撤销最近一次表格修改”或列转换区域可以撤销最近一次修改，仅支持一层。CSV字符串前导零不会隐式转换，JSON类型和转换限制沿用现有列转换说明。

编辑步骤或名称、重新解析、手工转换、合并或撤销都会清除旧流程预览。任务返回前或应用前还会复核来源；来源变化拒绝旧结果。预览中编辑器暂禁用，可以取消；取消在有界步骤前后检查，不承诺立即中断单个转换。切换工具或实例不会自动应用，任务中心可返回准确实例、查看状态或取消该轮任务。运行中不能关闭实例或保存快照。

任一数据实例还有活动任务时，正常退出确认暂时禁用，包括未选中实例中的流程文件读写。可等待完成，或从后台任务取消支持取消的操作；流程文件读写目前不提供取消。空实例中已读取但未确认的流程也属于待处理内容，关闭需要确认放弃，不能无提示丢失。退出提示说明流程需单独保存为文件，实例快照不含步骤。

## 保存流程并再次使用

点击“保存流程…”选择一个新的 JSON 文件名。文件只包含流程名称、格式版本、步骤和参数；参数中的文字按原文保存，不附带输入表、预览结果或文件/网络授权，也不会从其他工具读取凭据。已有文件拒绝覆盖；需要更新时请另存新文件。保存时冻结步骤快照并在后台写入，不会运行流程。先在同目录暂存写完并同步，再发布最终文件名；Windows使用不覆盖移动，保存过程不依赖硬链接，其他平台使用无覆盖硬链接。普通写入或提交失败会保留当前步骤，最终目标不出现半文件，同名竞争保留已有文件；尝试清理本次暂存后可另选文件名重试。进程崩溃或暂存清理受阻可能留下 `.zi-local-*.tmp`，不声称断电完全持久；未实际验收网络盘/FAT。输出使用普通Windows文件名，不支持设备名或数据流，目录别名解析后在固定位置保存。

以后点击“使用已有流程…”，读取后显示名称、步骤及参数，确认才替换当前步骤；取消或按 Esc 保留原步骤及其有效预览。确认替换会清除原流程预览，当前表格和原始输入保留，不自动解析、预览、应用或保存。确认期间禁止开始或应用流程，也不能再次读取或保存定义。可以在确认之前或之后解析新表，随后主动预览并应用；新输入缺少引用列时会报告具体步骤，原表保留。

流程文件最多256 KiB，新建格式版本为2；兼容读取版本1的列转换/选列定义，版本1不得携带新增行步骤；未知版本/字段、损坏文件和无效参数拒绝读取。定义中的文字与参数只交给已支持的表格动作，不作为脚本或命令执行。

**工作实例快照仍不包含流程步骤。** 跨次使用需要单独保存流程文件；未另存的步骤仅在本次运行保留。自动保存、完整跨次流程索引、逐步完整产物和可保存文件写步骤仍在后续开发；已支持流程收藏、最近载入及托盘/统一搜索入口，不能把这版视为完整自动化平台。

表格最多10000行/128列、8MiB，流程最多32步；列引用和新列名有长度限制，填充参数最多4096字节。应用结果后，可继续现有CSV/JSON导出或新SQLite另存，文件写入仍需独立选择目标和确认，不因运行流程自动获得文件或网络权限。插件、图片、MCP和Agent尚未接入此执行器。

架构、授权及扩展验收计划见[流程设计](workflow-design.md)。正式版状态以[版本下载](https://github.com/ax2/zi-devtools/releases/latest)为准。

## 筛选、排序与去重

点击「添加行步骤」选择筛选、多列排序或按列去重。每一步仍按当时的列名绑定，可与列转换/改名/选列串联；步骤处理上次解析的全部行，界面的临时筛选不影响流程。先预览，再应用，可撤销最近一次表格修改。

筛选支持包含/不包含文本（可区分大小写）、等于/不等于JSON值、是/不是null。JSON相等需填写合法值：数字 `1`、文本 `"001"`、布尔 `true`、`null` 或数组/对象；区分数字与文本。CSV默认字符串，不自动把 `001` 转数字；需要数字比较先添加显式列转换。文本包含按显示值匹配，null显示为空，空查找词拒绝。

排序最多4列，可调优先级、升降序；同值保留当前顺序。升序采用固定类型顺序：null、布尔、数字、文本、数组、对象；降序整体反转该顺序。数字按精确十进制大小比较，超过浮点精度的大整数不会合并为同值。数值1与1.0排序视为相等并保持先后；文本按Unicode比较，不使用自然排序或中文拼音；数组/对象按规范JSON字符串比较。

去重按选择列的组合JSON表示判定，保留当前顺序首条，其余列完整保留。数字1、数字1.0与文本 `"1"` 分别保留；若希望忽略大小写/空白或统一类型，可在前面添加列转换。先排序再去重可选择每组保留哪条。至少选一列，不允许重复列名。

行步骤报告变化行数，以及最多六个移除/移动行号样本；筛选与去重统计删除数，排序统计位置改变数。筛选可产生零行的有效结果；来源和原始输入仍保留。筛选/去重逐行检查取消，稳定排序在最多10000行的有界操作前后检查，不能立即打断排序。

## 应用前检查表格

预览完成后点击「查看输入与结果表格…」，只读检查冻结输入或流程结果。查看筛选独立于原表，每页50行，保持快照顺序；筛选只减少查看行，不改变将来应用的完整结果。空结果仍显示列结构。横纵滚动查看所有列，快照行号指当前输入或结果的行位置，不代表跨步骤同一原行。

单元格按JSON显示，以区分 `null`、`""`、文本 `"001"` 与数字 `1`。点击单元格查看类型及有界片段，长值显示省略号；「复制完整JSON值」由用户主动复制未截断值。检查器不应用、不运行、不写文件。关闭或Esc返回已有预览，再点击应用。修改步骤或来源导致预览失效时，检查器与单元格选择一并清除。切换快照、查看筛选或分页会清除旧选择；检查状态不保存到流程文件。

## 流程文件夹

点击“流程文件夹…”主动选择目录，在后台检查其直接 JSON 文件，不递归子目录。按流程名称或文件名搜索，列表显示步骤数与跳过文件数；悬停文件夹名称可查看完整路径。“刷新列表”重新检查当前目录。“载入并确认…”重新读取文件，并进入原有确认界面；选择取消保留当前步骤和有效预览，确认才替换步骤，不执行流程。文件变更后以重新读取内容为准，已删除或损坏文件报告读取错误。

最多枚举1000个目录项、累计读取8MiB、列出256个有效流程，每个文件仍最多256KiB；达到任一上限标明部分列表，不表示整个目录。观察到的链接/重解析目录与文件跳过，普通文件存在扫描期间变更的可能，列表不是授权或文件锁。各实例保留各自文件夹和搜索词；跨次完整流程索引仍待开发；显式流程收藏见下文。流程文件操作沿用后台任务状态与退出保护，目前不提供手动取消。

## 记住流程目录位置

点击“记住此目录”只将目录路径写入界面偏好，不保存流程正文或表格，也不授予自动执行权限。下次打开数据工作台或新建实例恢复该位置；点击“刷新列表”才检查文件。已选择其他目录的实例不会被共享记忆强制替换，重新启动后只恢复共享位置，不恢复未保存步骤。若位置被删除或不可访问，刷新报告错误，可以选择其他目录。

“忘记已记住目录”只删除记忆设置，不删除文件/文件夹、当前列表、输入表、步骤或有效预览。设置保存失败显示未保存，当前目录选择和原记忆状态保留，可重试；不将失败误标为成功。路径保存沿用界面偏好的原子写入和多窗口无关设置合并，不写入实例快照或流程定义。

## 从 Ctrl K 打开流程

在任一打开的数据实例主动检查流程文件夹后，Ctrl K搜索可按流程名称、文件名或所属实例名称找到已检查流程。工具和流程共享↑↓、Enter及鼠标选择；流程行显示名称、步数、文件名与实例。空搜索优先显示收藏流程，再显示工具；输入“流程”可查找所有已检查流程。最多显示100条流程匹配，超出显示总数并提示细化关键词。总数只覆盖已检查的列表，不等于磁盘中的全部流程。

选择流程后复核所属实例、当前列表和文件名，重新后台读取文件，再显示原有确认界面；不把路径拼成工具ID或命令。实例已关闭、列表变化、实例忙碌或已有未确认流程会拒绝打开，原活动实例保留。文件删除、损坏或改变后以实际读取为准；文件内容改变时，确认界面显示重新读取的名称与步骤，不使用缓存定义。取消保留旧步骤、表格和有效预览；确认只替换步骤，仍需主动预览与应用。

搜索不在按键时扫描磁盘或读取流程正文，缓存仅包含名称、文件名、步数和实例身份等元数据，列表修订、实例变化或查询变化使缓存失效。记住目录的位置不会在新启动时自动建立索引，先刷新目录才能检索其中未收藏的流程。跨次完整元数据索引、托盘流程入口与通用跨工具自动执行继续开发。

## 跨次收藏流程

在Ctrl K的已检查流程结果旁点☆，明确将文件位置、名称和步数摘要保存到界面偏好。最多100个，原文件、流程正文、表格和执行授权不写入收藏。下次启动无需先检查目录，Ctrl K空搜索或输入名称/文件名即可找到收藏。名称与步数标明来自收藏时，打开后以后台重新读取的实际文件为准，进入当前活动实例的确认界面；仍需主动确认、预览、应用。

点★移除收藏，只移除偏好条目，保留原文件和当前数据。文件丢失、损坏、超出256KiB或为链接时报告读取失败，当前步骤、输入表和预览保留；可移除失效收藏，再检查新位置后收藏。保存失败保留旧收藏并报告错误；多个窗口按路径合并增删，空闲时刷新共享收藏，无关本地设置保留。已有同一路径来自不同实例的搜索结果仍标明所属实例：普通结果载入所属实例，收藏结果载入当前实例。

## 搜索范围与键盘切换

Ctrl K提供全部、工具、流程、收藏四种范围，可点击或用Ctrl+1、2、3、4切换。切换保留搜索词，将选中位置归零并返回输入框；仍使用↑↓、Enter和Esc。当前应用保留最后一次范围，重新启动默认全部。计数只反映当前范围及关键词；已检查列表的总数可能超过显示上限100条，提示细化关键词，不能当作全盘流程数量。

工具范围不显示流程；流程范围显示流程收藏与各实例的已检查流程，空搜索可浏览已有元数据，不扫描文件；收藏范围同时显示已收藏工具和流程位置，不显示普通已检查流程。工具收藏只显示当前可用入口，禁用插件不会借收藏绕过禁用状态。无匹配时提供与范围相符的提示。范围切换不改变当前表格、步骤、有效预览或收藏，不预览或执行。

## 最近载入流程

通过文件选择、已检查列表、收藏或最近入口后台实际读取并校验成功后，记录当次名称、步数和位置，最多20条；排序按本窗口成功事件和偏好保存合并顺序。这里只代表载入并等待确认，取消确认也不抹去真实载入记录，不代表预览、应用、执行或授权。读取失败、丢失/损坏文件、忙碌拒绝、已关闭实例不产生成功记录。

Ctrl K全部或流程范围显示最近载入记录，同路径已收藏时优先收藏行，避免重复；工具/收藏范围不混入普通最近记录。重启恢复元数据，不扫描或读取正文，选择后仍重新读取到当前实例确认。点×只移除记录，保留原文件、输入表、步骤及有效预览。多个窗口合并有界待提交成功事件和明确移除，不用陈旧整个列表覆盖其他窗口记录；坏偏好不覆盖，失败保留当前待提交，30秒重试，统一入口提示未保存。关闭应用前未成功保存的最近元数据可能丢失，不把内存结果称为跨次保存成功。

## 托盘收藏与最近载入（dev.66）

通过实际Rust托盘的收藏/最近/全部或独立流程页访问已保存的摘要，每组最多6条；全部流程搜索打开统一搜索的流程范围。键盘上下/Enter支持工具和流程混合选择；入口在打开前复核最新偏好，过期或移除时提示重新打开面板。恢复主窗口后重新读文件并确认，取消保留表格和旧预览。列表不读取流程正文、不扫描目录；载入不代表应用。

## 完整预览结果另存文件

预览成功后点击“保存流程结果为文件…”，选择CSV或SQLite、新文件路径（SQLite可填写表名），点击“预览保存流程结果…”。确认框展示完整行列数、流程步数、目标和前五行样本；点击“确认保存新文件”才启动写入，返回编辑不会创建文件。无需先应用流程结果；保存后原表和待应用预览均保留。

CSV不保留JSON类型：null写为空单元格，数组/对象写为JSON文本。默认开启文本公式防护，对危险前缀文本增加单引号，可关闭；数值不套用文本防护。SQLite保留NULL、普通整数、浮点和文本，布尔转0/1，超大整数及数组/对象转文本；CSV来源字符串不会被隐式转数值。快照和CSV输出各最多32MiB。

后台写入绑定创建输出的实例，任务中心可返回保存区域或取消对应运行。确认前复核原表、定义和完整结果。只创建新文件，不覆盖已有文件；同目录暂存并同步后使用无覆盖硬链接发布，不支持硬链接的磁盘会失败。冲突保留已有目标。发布前取消不产生最终文件，发布完成后保留已创建文件。普通失败清理暂存；崩溃或目录访问受阻可能遗留暂存。

当前可保存一个最终结果输出配置，执行文件写入仍需每次审核。统一动作注册、多产物输出、图片/插件/MCP/Agent执行仍需继续实现。

## 保存与恢复输出设置（格式3）

展开输出区域，勾选“将输出设置保存在流程中”，选择CSV公式保护或SQLite表名，再用“保存流程…”另存配方。没有预览结果时也可编辑配置；目标选择和文件写入需要完整预览。取消勾选会移除保存的配置，手动输出仍可使用。

格式3的output声明使用版本1，只保存格式与转换选项，不接受路径、授权、命令或未知字段。旧格式1/2无输出声明继续兼容。读取文件仍需要确认替换，确认框展示输出摘要；确认后恢复格式/表名/保护，清空上次目标路径。预览只计算表格，不能因保存的声明自动创建文件。每次结果输出仍选择新目标、检查全量结果并确认。当前仅一个最终结果输出，不是任意跨工具流程平台。

## 文件结果与当前页接力

SQLite结果保存成功后，点击“查看已保存的 SQLite 结果…”进入数据库工作台。入口使用完成回执中的格式和实际路径；后续改变输出格式或新目标不会把旧CSV误当成SQLite，也不会打开未保存的目标。

数据库页点击“当前页送到数据工作台…”，先查看当前页范围、样本和类型说明，再确认创建独立实例；取消保留现有工作。仅传递当前读取的最多50行，不代表全表或一致性跨页快照，不自动查询后续页。原流程实例和数据库均保留。

NULL、SQLite整数、有限浮点和完整UTF8文本按存储类型接力；前导零文本与内嵌NUL保留，0/1不会恢复为布尔，JSON文本不会自动解析成对象。截断值、BLOB、非UTF8或非有限值会明确拒绝，避免把不完整预览当成完整数据。空页保留列结构，不保留SQL声明类型。目标JSON表示最多2MiB、列名最多4KiB；超限或实例数达到16时不创建新实例。WAL数据库仍可能由SQLite管理辅助文件，接力不执行写SQL。
