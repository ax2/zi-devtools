# 统一前缀快捷指令（开发中）

程序开发版 0.82.0-dev.13；独立工具版本见工具清单。全局前缀沿用设置中的可配置系统快捷键，默认 Ctrl+Alt+Space；系统冲突仍由原注册服务提示并保留旧绑定。

按前缀后松开 Ctrl/Alt，再按下列键。多键序列是逐次按键，不是同时按住。快捷面板会显示当前序列及可选下一步，8 秒无操作收起，Esc 或失焦取消。普通应用输入不被全局键盘钩子采集；序列只在聚焦面板或主动开启的本窗口序列界面处理，输入法组合不执行序列。

| 序列 | 行为 |
| --- | --- |
| C / T | 打开计算器 / 时钟工作台 |
| J / D / N / A / F / G | JSON / 数据 / 备忘 / 日程 / 文件 / 图片 |
| S F / S C | 打开截图工作台 / 隐藏工作台并启动快速截图 |
| R O / R T | 打开录屏配置 / 展开教程辅助 |
| R Z / R X | 开关鼠标聚焦放大 / 关闭所有教程效果 |
| R S | 使用当前配置请求开始；配置不足则打开工作台补齐 |
| R P / R E | 暂停或继续 / 请求结束录屏 |
| K | 返回全工具搜索，包括已启用插件 |

从托盘打开仍直接显示搜索/收藏/最近；面板内可切换到前缀指令。工具库的“统一快捷指令”列出常用键序列，也可以在本窗口输入序列。工具导航只打开工具，不自动运行它的处理动作；录屏控制和快速截图命令是明确的操作例外。

每个可用工具有 `open:<tool-id>` 命令，名称变化不改变身份；未设置默认序列的工具通过 K 搜索。工具库的“统一快捷指令”现在可搜索全部可用工具并编辑附加键：1–4 个 A–Z 字母，用空格分隔，例如 Q A；空序列取消绑定，K 保留搜索。点击工具名称编辑，先“写入草稿”，检查后“保存并生效”；保存成功后才改变当前绑定。重复序列和前缀重叠（例如 C 与 C A）禁止保存。“使用此项默认”、“恢复默认（草稿）”和“放弃修改”提供回退。支持另存和导入快捷配置 JSON，详见下文。部分工具功能共享一个工作台页面；打开不代表新建工作实例。

原录屏直接系统热键保留，可在序列面板不可用时直接结束录屏。物理跨应用唤起、不同输入法、远程桌面与真实快捷键冲突还需专项验收；合成原生 UI 检查不替代这些验收。

附加键主动保存到本机界面偏好文件，不包含工具输入或处理结果。旧偏好自动使用默认序列。插件停用后保留自定义绑定，并预留其键序列；恢复插件即可重新使用。新工具默认或外部修改造成运行时冲突时，停用所有相关序列并提示修正，K 搜索继续可用。保存失败保留原绑定和草稿，不删除已有文件。

## 配置导入与另存

“另存草稿配置”导出当前已写入草稿的自定义附加键；编辑框尚未写入草稿的文本不包含在内。只包含格式版本、稳定指令标识和序列，保留空序列（取消绑定）及停用插件的绑定；不包含工具输入、系统前缀、收藏/历史或授权。后台另存新文件，已有文件不覆盖；失败可能保留不完整文件，需检查后另选文件名。

“导入快捷配置”后台读取后显示变更和冲突。“合并”覆盖文件列出的指令，保留其他自定义键；“替换”以文件为全部自定义配置，未列出的工具恢复本机默认。取消导入保留原草稿。确认只放入草稿，仍需检查并“保存并生效”；冲突可进入草稿修正，但不能生效。导入本身不会运行工具或控制录屏。

文件最多256 KiB/4096项；拒绝重复指令、未知格式版本/字段、无效标识和非法键序列。K仍保留搜索。退出前提醒保存快捷键草稿或处理待确认导入；后台文件操作进行中禁止正常退出。隐藏到托盘仍继续处理。
