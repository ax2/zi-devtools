# 图片接力（dev28基础 / dev29剪贴板接入）

## dev86：图片信息进入文本接力

单张图片、已生成编辑结果和截图选区新增“生成图片信息报告”。后台捕获当前内存材料，生成版本1 JSON，包含宽高/像素数、透明通道与实际透明像素、来源工具/独立版本/接力UTC链。已有PNG/JPEG/WebP编码结果优先，显示其真实格式及精确字节数；未编码原图或截图的encoding为null，不能据此推算最终文件大小。报告不包含路径，不读取或写入图片文件。

生成后可展开报告，或通过顶部统一“发送结果到工具…”预览确认，再替换JSON等工具输入或创建备忘草稿。接收不自动运行文本工具，备忘需另行明确保存。取消确认保留来源和目标草稿。每个来源工具只保留一份会话报告；材料变更后旧报告可查看，但统一入口不发送旧报告，请重新生成。后台返回时材料或图片模式改变则丢弃过期返回，不覆盖旧报告。

报告上限48KiB，图像预算沿用既有图片接力。报告生成尚无中途取消按钮，线程期间不能直接退出；不强引用已完成报告的旧图像，不把报告视为永久材料库或可执行配方。dev87/88 已加入批量/元数据文本报告；插件和通用图像端口继续开发。

图片转换1.3.0、裁剪标注1.2.0和截图工作台0.3.0共享内存图片接力。加载图片或生成结果后，点击“发送图片到工具”，后台准备快照，查看尺寸/图片预览/来源版本链，再选择目标并确认。截图传递透明选区结果；转换优先当前实际PNG/JPEG/WebP编码结果，保持其像素尺寸；编辑有未预览操作时先生成编码结果，不偷偷传未编辑原图。

目前可进入图片转换或裁剪标注，当前来源工具不作为自身目标。来源工作与截图保持不变，目标后台任务进行时禁止接收；目标已有输入/操作/原图/预览时须明确勾选替换。进入后只设定内存原图及PNG默认格式，清除目标旧输出路径，不自动编码、另存或联网；需要用户手动生成预览并选择输出路径。内存来源没有伪造文件路径，不创建磁盘临时图片。

取消会立即释放界面控制，尚在运行的有界后台准备结束后丢弃结果；不启动叠加准备任务。常用搜索/前缀在确认弹窗显示时不抢输入。每次成功接力将实际目标ID计入最近/使用记录。

来源链每步记录实际工具ID、工具独立版本和接力UTC时刻，最多128步。时间不代表原图拍摄或原文件创建时间；不传播原文件完整路径，不证明图像真实。连续转换/编辑保留之前的链。新载入文件建立新链。结果只在本次内存中，尚未导出链或持久保存。

图像最多1600万像素，边长12000、解码分配上限192MiB，编码快照最多128MiB，源编码使用不可变共享字节快照；解码在后台，内存原图共享Arc，截图RGBA转换只在后台复制一次。dev29新增选中剪贴板PNG图片作为接力来源（超级剪贴板0.5.0）；dev89 已加入元数据清理输出；dev90已加入批量成功文件输出接力，插件继续开发，也不是整套类型接力协议已完备。原有文本接力继续可用，剪贴板富文本与文件引用另行实现。

## dev89：已清理图片接力

元数据工具完成“生成清理预览并复检”后，可通过“发送图片到工具…”查看实际编码图片，再选择转换或裁剪并确认。只传已复检的清理结果，不回退原图；任务中、质量变化或复检摘要缺失时不能发送。源编码使用不可变共享快照，不复制大字节缓冲，不读取磁盘或自动清理。

取消保留源清理结果和目标现有工作；目标有内容需明确允许替换。接收工具只获得内存像素及来源工具版本链，不自动编码或保存，旧输出路径清除。元数据源结果仍可返回使用。原图/清理摘要仍可另行发送到 JSON、备忘等文本工具。这里的图片接力不代表所有文件/批量输出和插件端口已经互通。

接力弹窗在图片准备前后使用同样的预览占位区，并固定顶部锚点，避免内容高度改变导致确认控件随垂直居中移动。

## dev90：批量成功输出逐项接力

批量任务结束后，在成功项旁点击“发送此图片…”，只读取这一项，后台核对生成时的精确字节数和 SHA-256，再显示实际图片预览。PNG/JPEG/WebP 均使用实际保存字节解码。失败、未处理或缺少生成摘要的条目不提供可用入口；批量任务进行中不能发送。

生成摘要直接来自保存前的编码字节，不重新读取整个批次。发送时只允许普通文件，读取上限128MiB，沿用1600万像素和192MiB解码预算；读取前后核对本次文件身份、大小、修改时间并重新打开路径，分块读取支持取消。文件删除、内容改变、替换或超限会阻止本次接力，已完成输出仍保留；包括同长度、恢复修改时间的内容改变。文件身份从用户选择后的后台捕获开始，不声称从生成时一直持有原对象；选择前替换为完全相同字节的文件仍属于内容相同的当前快照。

确认后可进入转换或裁剪，来源输出与批量清单保留；目标已有工作须明确允许替换，切换目标后重新确认。只接收内存像素和image-batch独立版本来源链，清空旧输出路径，不自动编码、保存或联网。预览准备完成后使用该不可变内存快照，后续磁盘变化不改写已准备图片。此功能不将报告文件名当成文件引用，不代表插件图像端口已完成。
