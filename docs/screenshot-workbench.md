# 截图与透明套索

开发中，工具 0.1.0，程序 0.82.0-dev.11。通过工具库搜索“截图”或统一前缀后按 S F 打开，也可以在图片工作台选择“截图与透明套索”。

点击“捕获主屏幕”才读取当前屏幕。捕获包含当前可见窗口（也可能包含本程序）；它是静态画面，不会自动刷新或持续采集。画面和结果仅保留在当前会话内，另存前不写截图文件。

在缩放后的画面拖出矩形或自由轮廓，松开自动闭合。自由轮廓按偶奇规则填充，自交区域可能形成透明孔洞。边缘使用 2×2 采样，轮廓外 alpha 为零；输出按最小包围框裁剪，原始画面保留。Esc 或“重新选择”清除选区和旧预览。

棋盘格代表透明，预览下方显示原始输出像素尺寸。点击“另存透明 PNG”选择位置后后台保存；已有文件拒绝覆盖。屏幕捕获和编码在后台执行，任务期间不能启动另一项截图任务，退出保护会等待后台任务完成。未保存结果完全退出前可以返回截图保存或明确放弃；切换其他工作台仍会接收后台结果。输出不自动上传、不自动复制到剪贴板。

限制为主屏幕、1600万像素、2048轮廓点，超过点数需要重选。当前使用工作台画布选择，尚不是覆盖桌面的全屏选择层。窗口捕获、屏幕选择、光标放大镜、节点调整/羽化/撤销、标注/打码/置顶/复制及跨屏混合 DPI 继续开发。长截图/OCR另行验收。系统保护内容可能无法捕获。

验证分别记录像素算法、PNG 重读、UI 合成布局和真实屏幕捕获，不将合成图视为真实桌面或物理鼠标验收。网站配图仍需 WebP；用户要求的透明截图输出为 PNG。
