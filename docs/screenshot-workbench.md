# 截图与透明套索

开发中，工具0.4.0，程序0.82.0-dev.86。工具库搜索“截图”或统一前缀后按S F打开工作台；前缀后按S C直接启动快速截图。附加序列可在统一快捷指令中修改。

点击“捕获主屏幕”或S C才读取当前屏幕。程序先隐藏主工作台，再后台捕获主屏幕并打开原生全屏选择层。画面是静态快照，不会自动刷新或持续采集；其他可见窗口（包括本程序已打开的小窗）可能包含在快照中，系统保护内容可能无法捕获。画面和结果保留在会话内，另存前不写截图文件。

在屏幕实景上拖动矩形或自由轮廓，松开自动闭合并返回工作台预览。R切矩形、F切自由轮廓；Space切换放大镜、Backspace重新选择、Enter截取整屏、Esc取消。选择层关闭/取消后恢复主窗；Esc保留此前工作台的原图与未保存结果，新捕获未确认前不替换旧工作。后台捕获失败也恢复主窗。

放大镜来自捕获源像素，显示相对本屏幕的物理像素坐标及RGB；屏幕边缘时移动放大镜框避免越界。颜色和坐标来自静态快照。选区分别按水平/垂直比例换算到原图像素，不使用缩略图尺寸输出。

自由轮廓按偶奇规则填充，自交区域可能形成透明孔洞；边缘使用2×2采样，轮廓外alpha为零，按最小包围框裁剪。工作台保留原始捕获，还可在缩放画布上重新选择。棋盘格代表透明，显示输出像素尺寸。

点击“另存透明PNG”选择位置后后台保存；已有文件拒绝覆盖。后台任务期间不能重复捕获或直接退出。未保存结果退出前可以返回截图保存或明确放弃；切换其他工作台仍接收后台结果。输出不自动上传或复制到剪贴板。

保存先完整写入同目录暂存文件，再无覆盖发布为最终PNG；失败仅清理暂存，原始捕获/透明选区保留，最终位置不会暴露半成品。没有新增保存过程取消功能。

透明选区可主动生成[图片信息报告](image-relay.md)，经统一接力交给JSON、备忘等。报告基于内存选区的实际尺寸/透明度；尚未编码时最终文件大小为空，不因生成报告而保存图片。

上限为1600万像素、2048轮廓点；超出点数需要重选。当前只接入主屏幕；其他屏幕/窗口、轮廓节点调整/羽化/撤销、标注/打码/置顶/复制继续开发，长截图/OCR另行验收。真实多屏、混合DPI和物理跨应用快捷键仍需专项验收，不用合成夹具冒充。

网站配图仍需WebP；用户要求的透明截图输出为PNG。验证分别记录像素算法、PNG重读、原生窗口几何/消息和UI合成布局，不将合成图当作真实用户内容。
