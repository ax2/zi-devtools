# 截图与透明套索

开发中，工具0.15.0，程序开发版本不变。工具库搜索“截图”或统一前缀后按S F打开工作台；前缀后按S C直接启动快速截图。附加序列可在统一快捷指令中修改。

点击“捕获主屏幕”或S C才读取当前屏幕。程序先隐藏主工作台，再后台捕获主屏幕并打开原生全屏选择层。画面是静态快照，不会自动刷新或持续采集；其他可见窗口（包括本程序已打开的小窗）可能包含在快照中，系统保护内容可能无法捕获。画面和结果保留在会话内，另存前不写截图文件。

在屏幕实景上拖动矩形或自由轮廓，松开自动闭合并返回工作台预览。R切矩形、F切自由轮廓；Space切换放大镜、Backspace重新选择、Enter截取整屏、Esc取消。工作台提供最多20步“撤销选区/重做选区”，也可用Ctrl+Z撤销、Ctrl+Y或Ctrl+Shift+Z重做；快捷键只在对应历史非空且工作台空闲时生效。历史只记录轮廓坐标，从原捕获重新计算像素，不保留多份完整图片；更换一张新捕获会清空旧选区历史。选择层关闭/取消后恢复主窗；Esc保留此前工作台的原图与未保存结果，新捕获未确认前不替换旧工作。后台捕获失败也恢复主窗。

放大镜来自捕获源像素，显示相对本屏幕的物理像素坐标及RGB；屏幕边缘时移动放大镜框避免越界。颜色和坐标来自静态快照。选区分别按水平/垂直比例换算到原图像素，不使用缩略图尺寸输出。

自由轮廓按偶奇规则填充，自交区域可能形成透明孔洞；边缘使用2×2采样，轮廓外alpha为零，按最小包围框裁剪。工作台保留原始捕获，还可在缩放画布上重新选择。选择完成后点“编辑轮廓”，将鼠标移到边界橙色控制点并拖动以调整顶点；矩形会展开为四角控制点，手绘轮廓可逐点微调。拖动后的透明预览重新从原捕获计算，且可以撤销/重做；按Esc退出编辑，拖动中按Esc还原当前编辑。点击空白不会创建新选区。棋盘格代表透明，显示输出像素尺寸。

点击“另存透明PNG”选择位置后后台保存；已有文件拒绝覆盖。点击“复制透明PNG”会将 PNG 和兼容的透明位图格式写入系统剪贴板，明确替换剪贴板当前内容；复制仅支持不超过400万像素的选区，PNG超出剪贴板格式容量时会报告失败。复制在后台执行。后台任务期间不能重复捕获或直接退出。未保存结果退出前可以返回截图保存或明确放弃；切换其他工作台仍接收后台结果。输出不会自动上传或复制到剪贴板。

点击“箭头、文字、打码…”会把当前透明选区通过内存接力交给图片编辑器，并预选该目标。确认接力后可使用编辑器的箭头、文字、黑色遮挡和像素化打码；像素块大小可调，涉及高度敏感信息时请使用黑色遮挡并检查输出预览。若编辑器已有工作，会先明确询问是否替换。取消接力保留截图与图片编辑器当前工作，不创建临时图片或自动保存。

也可在截图页选择“黑色遮挡”“像素化”“模糊”或“箭头”，然后在下方透明 PNG 预览中拖出矩形或箭头；矩形至少覆盖2×2个输出像素，箭头从尾部拖向尖端且长度至少6像素，最多保留100项。黑色遮挡写入不透明黑色像素；像素化块大小可调为4–64输出像素，按块计算alpha加权颜色平均，同时保留每个像素原有alpha；模糊半径可调为4–32输出像素，先水平再垂直计算alpha加权盒式均值，仅改变选区内可见像素的RGB，保持透明边缘不变。模糊适合弱化背景或非敏感细节，不保证无法还原，高敏信息请用黑色遮挡。箭头使用红色主体和白色描边以适应不同背景，绘制时保留选区原有alpha。所有标注共用独立撤销/重做历史，且每次修改都从原捕获和当前轮廓、羽化重新渲染，不在已处理图像上重复累积。拖动时显示区域提示，箭头显示方向预览，松开后后台生成实际预览。重新选择会清除当前选区标注；撤销/重做选区则恢复对应标注。生成失败时保留上一份有效预览，恢复有效状态后才可另存或复制。

保存先完整写入同目录暂存文件，再无覆盖发布为最终PNG；失败仅清理暂存，原始捕获/透明选区保留，最终位置不会暴露半成品。没有新增保存过程取消功能。

透明选区可主动生成[图片信息报告](image-relay.md)，经统一接力交给JSON、备忘等。报告基于内存选区的实际尺寸/透明度；尚未编码时最终文件大小为空，不因生成报告而保存图片。

羽化半径可设为0–32像素，点击“应用羽化”后才从原始捕获重新计算；0保留原有硬边缘，较大值使边缘向选区内部逐渐透明。应用后可撤销/重做，切换半径不会自动反复启动图像计算。羽化只改变透明度，不修改RGB通道或选区包围框。

文字标注：选择“文字”，输入1–80个单行字符，设置12–96px字号，移动鼠标可预览，点击透明 PNG 预览放置。使用Windows本机字体，红色文字带深色描边；缺字或找不到字体时保留上一次有效预览并显示错误。文字与黑色遮挡、像素化、模糊和箭头共用100项撤销/重做历史，编辑从当前选区、羽化和原始捕获重算；透明轮廓外不会被文字涂出不透明像素。

模糊遮挡：选择“模糊”，拖出至少2×2像素的矩形，拖动时预览覆盖区域，松开后后台渲染。半径可调4–32像素，默认12像素；对矩形内部先水平、再垂直做alpha加权盒式模糊，只改变RGB并保持原alpha和矩形外像素不变。最高半径会暂用不超过裁剪图像大小的RGBA缓冲；内存不足时操作失败并恢复上次有效预览。模糊不是安全擦除方式，高敏内容使用黑色遮挡。
渐变遮挡：选择“渐变遮挡”，在预览上拖出至少2×2像素的区域，并选择横向、纵向或对角线方向。渲染用三色不透明色阶替换区域内可见像素的RGB；保留原alpha，透明像素、选区外以及矩形外均不变。遮挡加入与其他标注相同的100项撤销/重做历史，并从原始捕获重算。颜色目前为固定预设；对极敏感内容建议使用纯黑遮挡。
置顶截图：完成透明PNG截图后点“置顶截图”，创建独立原生窗口并保持在其他窗口之上；主工作台可切换到其他页面。置顶窗口固定显示这一版快照；点“更新置顶截图”换成最新结果，关闭窗口或点“取消置顶”则移除快照并关闭小窗。

上限为1600万像素、2048轮廓点；超出点数需要重选。剪贴板复制使用已有剪贴板图像限制：400万像素、PNG不超过16MiB。当前只接入主屏幕；置顶截图继续开发。长截图/OCR另行验收。真实多屏、混合DPI和物理跨应用快捷键仍需专项验收，不用合成夹具冒充。

网站配图仍需WebP；用户要求的透明截图输出为PNG。验证分别记录像素算法、PNG重读、原生窗口几何/消息和UI合成布局，不将合成图当作真实用户内容。
