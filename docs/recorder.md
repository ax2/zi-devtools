# 屏幕录制（Stage 30 / v0.30.0）

在工具首页搜索“屏幕录制”或从左侧菜单打开。点击“鼠标框选区域”，在主显示器上按住左键拖出矩形，松开后显示实际像素尺寸；也可一键选择整个主屏幕。选区太小会要求重选，按 Esc 可取消。确认 MP4 保存路径，选择静音、系统声音、麦克风或“系统声音 + 麦克风”，以及 0/3/5 秒倒计时后点击“开始录制”。搜索“双声源混录”可直接进入预选双声源的录屏页。录制中可暂停/继续，结束时点击“停止并保存”，完成后可打开视频或所在文件夹。已有同名文件不会被覆盖。

开始倒计时前会检查选区和保存路径，避免等待后才发现同名文件。录制期间可将主窗口隐藏到托盘：右键托盘图标，在“屏幕录制”子菜单查看状态、暂停/继续或停止保存；倒计时期间可从托盘取消。操作托盘不会自动弹出主窗口。成功保存后，保存框自动建议同目录的新文件名，可直接开始下一段；先前的视频仍可通过“打开视频”访问。

使用 Windows Graphics Capture、WASAPI 与系统 H.264/AAC 编码器，无需外装 FFmpeg 或 OBS。录制包含鼠标光标。双声源模式要求默认播放设备和默认麦克风均可用；选中声音模式后可分别设置系统声与麦克风 0–200% 录制增益，100% 为原始音量，0% 静音。双声源各按一半幅度混为一个音轨，超过 100% 时仍可能削波。音频设备先全部准备再启动采集，减少双声源启动等待。采集按排除暂停的录制时间线补静音，避免设备晚启动或无声区间导致音轨提前。选择区域期间不会启动捕获。编码先写入同目录临时文件，完整封装后原子移至目标路径；意外同名冲突时保留已完成的临时视频并显示路径。

当前只支持主显示器。多显示器跨屏选区、实时音量电平与长时间录制仍在规划。真实桌面已分别验证无声、系统声音、麦克风和双声源 MP4 封装及音视频轨道时长，双声源模式包含暂停/继续；鼠标拖动全屏选区已通过 UI 夹具。不同显卡、显示缩放、声卡时钟和第三方播放器仍需更多设备验证。
