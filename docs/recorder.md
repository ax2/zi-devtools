# 屏幕录制（Stage 38 / v0.38.0）

在工具首页搜索“屏幕录制”或从左侧菜单打开。先在“录制屏幕”选择目标显示器，点击“鼠标框选区域”，在该屏幕上按住左键拖出矩形，松开后显示实际像素尺寸；也可一键选择该整屏。选区太小会要求重选，按 Esc 可取消。确认 MP4 保存路径，选择静音、系统声音、麦克风或“系统声音 + 麦克风”，以及 0/3/5 秒倒计时后点击“开始录制”。搜索“双声源混录”可直接进入预选双声源的录屏页。录制中可暂停/继续，结束时点击“停止并保存”，完成后可打开视频或所在文件夹。已有同名文件不会被覆盖。

可在“录满后自动停止”选择关闭（默认）、1、5、15、30 或 60 分钟。时间按实际录制时长计算，开始前倒计时和暂停期间不计入；到时自动进入与手动停止相同的 MP4 保存流程。选择保存在本机界面偏好中，开始录制后不能改变本次设置。开始倒计时前会检查选区和保存路径，避免等待后才发现同名文件。托盘可用时，“开始录制时最小化窗口，结束后自动恢复”默认开启，关闭此选项后会记住选择，避免应用窗口挡住整屏画面；倒计时取消、启动失败或 MP4 保存完成也会恢复窗口。录制中可从托盘菜单查看状态、暂停/继续或停止保存；倒计时期间可从托盘取消。也可按已配置的全局快捷键（默认 Ctrl+Alt+Space）打开独立快捷面板，查看录制时间、暂停/继续或停止保存，并在倒计时中取消；停止或取消后面板收起。快捷面板可能出现在录制画面中，需要干净画面时使用托盘菜单。若托盘不可用，则保持窗口显示和原有按钮，避免无法停止。录屏期间手动选择“托盘”也会最小化，以保持录制状态和托盘操作继续运行；手动最小化不会触发自动恢复。成功保存后，保存框自动建议同目录的新文件名，可直接开始下一段；先前的视频仍可通过“打开视频”访问。

使用 Windows Graphics Capture、WASAPI 与系统 H.264/AAC 编码器，无需外装 FFmpeg 或 OBS。录制包含鼠标光标。双声源模式要求默认播放设备和默认麦克风均可用；选中声音模式后可分别设置系统声与麦克风 0–200% 录制增益，100% 为原始音量，0% 静音。双声源各按一半幅度混为一个音轨，超过 100% 时仍可能削波。录制中分别显示短时峰值电平，静音或暂停时归零，可尽早发现没有采到声音；它表示采集状态，不替代最终 AAC 波形检查。音频设备先全部准备再启动采集，减少双声源启动等待。采集按排除暂停的录制时间线补静音，避免设备晚启动或无声区间导致音轨提前。选择区域期间不会启动捕获。编码先写入同目录临时文件，完整封装后原子移至目标路径；意外同名冲突时保留已完成的临时视频并显示路径。

当桌面静止、系统不送来新画面帧时，录制线程会定期补送当前帧，维持连续的视频时间线；暂停期间不补帧，停止时按同一录制时刻封装视频与音频。主屏真实设备的四种声音模式短录、12 秒静态桌面录制及 12 秒动态窗口录制已核对 MP4 音视频轨时长。另在 60 秒动态窗口录制中，麦克风单路的视频/音频为 60.033/60.160 秒，系统声与麦克风混录为 60.067/60.139 秒；两次均完成 MP4 封装与尺寸检查。当前主屏及声卡的 120 秒双声源录制中途暂停 3 秒，视频/音频轨为 120.033/120.107 秒，完成 MP4 封装；自动停止在真实主屏录制中设置 1 分钟，中途暂停 3 秒，约 63.18 秒后自行停止并完成 MP4。

显示器选择能力目前标记“进行中”：代码已按设备名定位录制目标，并在启动前复核位置与分辨率；本机只有一块显示器，未验证第二块屏幕或混合 DPI。跨显示器的一块连续选区需要多路采集与合成，尚不支持。超过 120 秒的长时间录制、热拔插、不同声卡与显卡和第三方播放器仍需更多设备验证。
