# 工具集合 v0.3.0

状态：开发中。工具集合用于把跨分类的工具按具体任务整理起来，例如“发布前检查”或“Java / Django 排查”。独立版本和剩余规划见 [工具目录](tools.json) 的 `command-collections`。

## 当前可用

- 在工具库创建集合；名称最多 40 个字符，忽略大小写检查重名。
- 在工具行的“集合”菜单将内置或已启用插件工具加入/移出一个或多个集合。
- 选择集合后按自定义顺序浏览，拖动行左侧的 ↕ 手柄可调整位置并立即保存；落点有插入线提示。搜索时按相关度排序，不改变集合保存顺序。
- 工具库与快捷面板可筛选集合；保留工具原始名称、分类、版本和用途搜索，点开仍进入原有工具页面。
- 在工具库重命名或确认删除集合。删除只移除这个集合及其 ID 列表，不删除工具或工具数据。
- 可导出所有集合为独立 JSON 文件；文件只包含 schema 版本、集合名称和有序工具 ID，不包含本机 UUID、收藏、工具输入或其他偏好。
- 导入先校验并显示预览，列出集合与工具入口数量、名称冲突改名；只有确认后才保存。导入不会覆盖或删除现有集合，保留未知或已卸载插件 ID。
- 全局快捷面板新增“集合”页签，可搜索集合内工具并用方向键、Enter 快速打开。
- 集合仅保存在本机 UI 偏好文件中，不读取项目目录或工具输入，也不触发任何工具操作。

最多 128 个集合，每个集合最多 512 个工具入口；未知、停用或卸载插件 ID 会保留，重新可用时恢复显示。超出上限或保存失败时不提交内存中的改动。

## 多窗口保存

工具集合以 UUID 标识。跨窗口保存会合并独立新建的集合，以及同一集合中基于相同快照新增/移除的不同工具；不同窗口提出的排序变化按成员变更合并，陈旧排序不会恢复已移除工具。同一个名称被并发改动时，最后保存的名称生效。删除优先于另一窗口对已删除集合的陈旧修改。自定义顺序保存在工具 ID 数组中。

导入文件使用 `zi-devtools/tool-collections` schema 1，大小不超过 1 MiB；最多导入 128 个集合、每个集合 512 个入口。缺字段、未知字段、重复集合名、重复工具 ID、无效名称和超限数据均拒绝。预览后本机集合内容发生变化时，确认会失效并要求重新预览。

## 后续范围

工作区其他偏好迁移和跨设备同步尚未实现。集合本身只管理快捷入口，不是可自动执行的工作流或授权边界。

## 验证

自动测试覆盖新增、重命名、删除、重名拒绝、加入/移出、前后排序、保存失败不提交、旧偏好兼容、双窗口成员/排序合并，以及便携文件往返、冲突改名、未知工具 ID、恶意/超限输入和陈旧预览拒绝。快捷面板目录过滤验证成员与顺序。工具库深浅主题截图验证了拖动手柄及排序提示的真实渲染；导入预览仍需桌面实机交互验收。
