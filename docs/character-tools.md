# 字符工具集

在工具首页搜索“ASCII”“表情”“颜文字”或“字符画”，三个工具也可收藏，之后从最近使用和快捷入口打开。

**ASCII 码表**列出 0–127 的十进制、十六进制、可显示字符与控制符名称。输入 `65`、`0x41`、`A`、`LF` 等可筛选。控制符不可直接复制为普通文字；中文和表情不属于 ASCII。

**特殊字符与表情**提供标点、数学符号、箭头、常用 Emoji 和颜文字精选条目，可按类别或名称查找，点击“复制”后粘贴到其他应用。它不覆盖完整 Unicode，具体显示取决于目标应用和系统字体。

Windows 上若存在 Segoe UI Emoji，应用会将它作为回退字体，补足部分默认字体缺失的表情图形；预览仍为单色字形，复制的是原始 Unicode 字符。

**ASCII Art 字符画**有文字横幅与图片两种模式。横幅支持最多 40 个英文字母、数字和部分标点，使用内置 5×7 点阵；不支持的字符以 `?` 替代并显示数量。图片模式只读取用户明确选择的 PNG/JPEG/WebP，源文件最多 10 MiB、20 百万像素；输出宽 8–120 字符，高度最多 120 行，透明像素按白底处理。预览可复制，另存 TXT 不覆盖已有文件。处理不上传图片，字符画仅是视觉近似。
