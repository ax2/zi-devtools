# 数据工作台使用说明

## 转换与合并

解析左表后，从列转换选择操作并预览，再应用。原始输入保留，重新解析会重置全部转换。只保留最近一次转换或合并的撤销快照，撤销入口位于列转换面板。

合并与关联使用当前数据表的全部行，不使用筛选子集。右表支持粘贴和 UTF-8 文件读取（最多 2 MiB）；输入有内容时先清空才能载入文件。

- 左连接：保留全部左行；未匹配右侧补 null。
- 内连接：仅保留匹配组合。
- 按行追加：两表列名集合须相同，右表按左表列顺序重排。
- 按行号拼列：行数必须相同，严格按当前位置拼接。

连接只支持单列键。字符串、数字、布尔按 JSON 表示精确匹配：字符串 `"1"`、数字 `1` 与数字 `1.0` 不会互相转换；非空字符串不会自动去空白。null、空白字符串、数组和对象不参与匹配。需要统一格式时先使用列转换。

重复键保留所有匹配组合，报告显示重复键组数而非重复行数。未匹配右行包括空键或未被任何左行使用的右行。右表重名列添加 `_right1`、`_right2` 等唯一后缀，左右关联键都保留。

预览在后台生成，可取消；输出超过 10000 行、128 列或 8 MiB 单元格内容时整体失败，原表不变。最多预览 8 行，应用后可查看更多并导出。左表变换、重新解析或撤销会使旧合并任务及预览失效。应用合并后清空筛选与旧导出结果。

## 类型边界

CSV 单元格默认是字符串，JSON 保留类型。整数转换支持 i64/u64 范围，不接受小数或指数文本。数字转换中的小数使用浮点表示，可能舍入。布尔转换只接受 true/false，忽略大小写及首尾空白。null 保留；空字符串需要显式转换为空值。任一行失败时不应用整列，并显示首个失败行。

## 后台任务中心

数据解析、合并和文件校验在切换页面后继续收取结果。任务中心保留本次运行最近 50 条状态记录（不保存输入和文件路径），显示耗时与文件校验进度，支持取消合并/校验及返回对应工具。数据解析有 2 MiB 上限，目前不能中途取消。取消请求显示“正在取消”，待工作线程返回后再结束。完成不代表自动应用合并结果；需回到数据工作台确认。其他工具的任务暂在各自页面查看。
