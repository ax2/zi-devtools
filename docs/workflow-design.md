# 可保存的操作流程：设计与实施计划

2026-10-03 建立设计，2026-10-07 更新实施边界。开发版已支持可保存和读取的表格顺序流程：列清洗、选列、筛选、稳定排序、去重，后台完整预览后主动应用，见[使用说明](workflows.md)。本文其余通用运行、授权写入、跨工具和恢复能力仍是规划，对应 `pipeline`，后续与 `workflow-builder`、`plugin-sdk` 共同推进。当前跨工具结果接力仍需逐次选择目标，表格流程不等于自动跨工具执行。

## 使用目标

用户把经常重复的工作保存为有名字的流程，下次换一份输入即可使用；不需要重新寻找每个工具或手工复制中间结果。普通用户看到“步骤”“输入”“结果”“保存位置”，实现协议放在扩展开发文档中。

首条完整示例：打开 CSV/JSON → 选择保留列 → 去除空白 → 转换字段类型 → 检查结果 → 导出 CSV 或另存新的 SQLite。范围、列、转换规则可以保存；文件正文、凭据和输出目录权限不因保存流程而默认保存或授予。后续示例包括图片裁剪/缩放 → WebP 编码预览 → 批量输出 → 校验，以及目录对比 → 选择差异 → 预览复制/移动计划 → 执行 → 操作报告。

## 入口与界面

- 工作台提供“保存为流程…”和“使用已保存流程…”；工具库、Ctrl K、收藏和最近使用使用同一稳定 ID。结果旁显示兼容的下一步，附推荐原因；没有兼容动作时说明原因。
- 流程界面采用顺序步骤列表。选择步骤显示输入范围、参数、样本、实际行列数或文件数量、转换变化及错误。宽窗口左右布局，窄窗口上下布局，运行/停止/保存操作保持可见。
- “预览全部步骤”仅执行纯转换，产物留内存。写文件、删除、外部程序和网络请求在副作用边界停下，显示实际目标和影响，等待已有授权范围内的执行或明确确认。
- 运行时允许浏览已完成步骤，禁止修改此次运行的输入和参数。修改流程会创建新修订，不会影响已运行的快照。取消后可以保留已完成的只读中间结果，显示尚未运行的步骤。
- 从任务中心返回准确的流程实例和运行版本；同名两次工作互不覆盖。关闭视图不等于取消任务，完全退出时说明仍在运行的任务与未保存草稿。
- 保存、收藏与最近使用分别表示定义持久保存、快捷入口和访问记录，不把打开一个流程误记成执行成功。

## 可重用定义与本次运行分开

| 对象 | 内容 | 保存规则 |
| --- | --- | --- |
| 流程定义 | 稳定 ID、名字、说明、格式版本、修订、步骤和参数 | 用户明确保存；保存失败保留编辑；未知字段/版本拒绝，原文件保留。 |
| 输入槽 | 期望类型、必要字段或文件类型、用户可更换的输入 | 不默认内嵌正文；本次选文件、粘贴或选择已有结果。 |
| 本次运行 | 流程修订、输入版本、状态、当前步骤、错误与结果引用 | 默认内存；用户可选择保存历史和内容，显示保存位置与占用。 |
| 产物 | 文本、JSON、表格、图片、文件集合、报告等逻辑类型与版本 | 小结果有界内存，大结果文件引用；内容可选择保存，来源可追溯。 |
| 授权 | 动作、目标范围、期限、必要指纹与失效条件 | 与流程定义独立；导入流程不导入授权、凭据或历史内容。 |

外部输入引用记录大小、修改时间及需要时的内容指纹。重新运行重新读取和校验；丢失、变化或不匹配显示具体输入槽，不默默沿用旧快照。选择保存内容时需提供删除、导出、容量与保留策略；用户原文件、固定产物不随可重建缓存自动清理。

表格产物保留原列名、逐单元格类型和行顺序。CSV 字符串前导零不能在隐式转换时丢失。JSON 到表格、表格到 CSV、图片编码和文档正文提取都是明确动作；显示类型损失或限制。模型生成的计划、插件返回内容与导入流程都不获得额外文件或网络权限。

## 动作适配与现有代码

| 当前模块 | 可复用行为 | 必须调整的边界 |
| --- | --- | --- |
| `src/workbench/transform.rs` | 十一种列操作、参数校验、变更样本、转换预览及撤销 | 将纯转换从页面 State 拆成有版本动作；以明确列标识绑定，不把易变化的列下标当作唯一身份。 |
| `src/workbench.rs` | Dataset、解析、显示范围及工作实例 | 输入/输出引用有界快照；独立实例保留；筛选/排序范围在运行开始时冻结。 |
| `src/workbench/sqlite_export.rs` | 新目标、类型说明、后台写入、事务、取消、校验和主动打开 | 复用现有写路径；流程运行器不得另写一条绕过预览/目标复核的路径。 |
| `src/app/handoff.rs` | 来源快照、目标选择、拒绝覆盖草稿 | 把手工接力与自动步骤桥接到共同的类型兼容性检查；已有手工入口保持可用。 |
| `src/app/registry.rs` | 稳定工具入口与同源发现信息 | 动作与工具分开注册，依赖、输入输出类型、可用性和授权状态明确显示。 |
| `src/plugins.rs` | 插件清单、启停、安装指纹和执行 | 插件动作声明真实输入输出及副作用；HTTP/外部命令需授权，清单或实现指纹变化重新复核。 |

只读结果与纯转换可以直接串联；保存步骤必须走统一执行边界。GUI、插件和未来 Agent 使用同一动作定义、参数校验与权限入口。未知副作用不能假定为纯动作；进程独立和能力声明不等于系统沙箱。

动作契约需要稳定动作 ID、实现版本、输入/输出逻辑类型、参数 schema、预算、预览/取消能力、副作用类别和幂等声明。运行保留使用的实现版本；缺失插件或版本不兼容时阻止相关步骤并提供修复入口，不自动换成另一动作。

## 状态与失败语义

运行状态为待执行、准备中、运行中、等待确认、正在取消、已取消、成功、失败、部分完成。步骤状态与运行状态分别保存；所有输出绑定实例、运行 ID、流程修订和输入版本，迟到回调不能写入新一轮结果。

修改参数会使该步骤及下游预览失效，上游有效结果仍可浏览。替换输入使全部步骤失效。删除、移动或重新排列步骤立即检查类型兼容性。预览失败指出步骤、字段/行、原始错误和可调整参数；不能跳过失败并报告整条成功。

取消在读取/转换循环与提交前检查；已提交的文件不因取消自动删除。写步骤按真实情况报告已完成与未完成文件，不承诺整条流程全局事务。只有经过验证的纯动作或幂等动作可自动重试；未知网络请求、外部命令与文件写入不因观察超时自动重放。运行期间删除定义不影响已冻结快照，但仍可取消任务。

恢复已保存运行时重新核对输入、动作实现、输出和授权。没有足够证据不能从任意步骤自动继续，尤其不能重放已经提交的副作用；显示已完成报告和重新运行的具体影响。

## 保存与授权

先实现新文件输出，再逐项扩展已有数据库更新、批量复制/移动、改名、回收站等。用户可以授权本次、当前会话或选定流程在指定范围内操作；允许更多写操作是产品目标，不把所有功能长期限制成只读。

预览展示目标、范围、差异、冲突策略和恢复条件。提交前重新检查源与目标，变化使旧预览失效。自动备份、事务和可恢复日志按动作分别验证，能够实际恢复才显示“可撤销”。授权页面能查看和撤销，扩大范围、改变动作实现或增加外发目标需复核。

流程文件导入先预览动作、依赖、网络目标、路径参数及缺失实现；不运行，不恢复权限、不读凭据、不自动扫描输入目录。导出定义不含令牌、连接密码、正文历史或权限记录。用户主动保存的数据和文件路径可以保留，但界面说明内容与位置，并提供管理入口。

## 实施顺序与验收

1. 提取表格动作契约与纯执行器，保留现有转换行为；输入槽/列绑定、参数及类型预校验、限额、取消和确定性结果。
2. 顺序步骤编辑与逐步预览，支持重排、禁用、参数变化失效、明确错误位置；实际原生鼠标和键盘验证宽窄窗口、明暗主题及固定操作区。
3. 显式保存/读取/导入/导出流程定义，未知版本保护、保存失败保留草稿、命名与修订；工具库与 Ctrl K 同源搜索、收藏、最近和实例恢复。
4. 统一运行/任务中心，接入 CSV 和新 SQLite 导出，验证输入冻结、来源保留、实例隔离、目标冲突、取消边界、后台错误及执行完成校验。
5. 扩展图片和文件链，逐项验证部分完成、输入外部变化、磁盘满、文件占用、冲突策略和恢复；同一契约接入插件、MCP 和 Agent，明确各动作支持范围。

这五项覆盖完整方向，某轮只交付一部分时如实记录。`pipeline` 在具备实际入口、可编辑多步、逐步预览、保存重用、失败定位及完整示例链验收之前不能标为 implemented。后续复杂分支与流程画布不替代顺序流程核心能力。

验收必须包含：前导零/空串/null/布尔/大整数和 Unicode；缺失/重名/重排列；空表和超限数据；参数修订造成下游失效；两个实例同时运行与迟到结果；步骤失败、取消后保留结果；保存失败及损坏/未知格式；现有目标/竞态目标/来源变更；导入不执行不扩权；缺失或更新插件；远程外发范围说明；副作用失败不自动重放。

规模验证沿用架构复查目标：300 工具、100 模板、1000 保存实例和至少30条用途查询，记录真实搜索耗时/资源与可到达性，避免把目录数量等同于打开全部工作台。每阶段维护实际测试和交互证据，未完成的项目保留在工具规划列表。
