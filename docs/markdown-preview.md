# Markdown 预览（Stage 44 / v0.44.0）

从侧栏或 Ctrl K 搜索进入“Markdown 预览”。选择本机 `.md`/`.markdown` 文件并读取，或直接在输入区粘贴文本。输入为 UTF-8，可带 BOM，最多 2 MiB。点击“生成安全预览”后，页面按标题、段落、列表、代码块、引用和表格显示内容，并可展开查看将导出的 HTML 源码。编辑草稿后必须重新生成预览。

原始 HTML 会被转义为文本，图片只显示替代文字、不加载本地或远程资源。仅保留 `http://`、`https://` 链接与页内锚点；其他协议及相对文件链接只显示文字。导出的 HTML 内置样式与限制性 Content Security Policy，没有脚本或网络依赖。它适合阅读和分享普通文档，不是完整浏览器或 HTML 沙箱；导出前仍应检查预览和源码。

确认内容后，输入 `.html` 路径并点击“确认另存新文件”。应用使用新建文件方式写入，已有目标一律拒绝覆盖，原始 Markdown 不修改。解析事件最多 20 万，输出 HTML 最多 16 MiB；超过限制会明确报错。
