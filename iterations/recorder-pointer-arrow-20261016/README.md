# 教程录屏辅助（0.5.0）

程序版本保持 `0.82.0-dev.105`，未发布。教程录屏新增默认关闭、白色填充与深色描边的鼠标方向箭头，复用预览和视频帧合成，跟随缩放坐标并在画面边缘裁切；另增加 `R F` 一次读取物理鼠标位置并切换到固定焦点，越出选区时不更改设置。两项功能均不采集键盘内容。

录屏合成测试 15 项通过，录屏 UI 与热键命令相关测试各 3 项通过；严格 Clippy、格式、工具目录同步和差异检查通过。没有进行真实桌面录制或最终 MP4 验收，因此物理鼠标快捷键、多屏/DPI与高分辨率性能仍待验证。
