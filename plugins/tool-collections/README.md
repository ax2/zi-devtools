# ZiDevTools 工具集合导入预览

在 Studio 工具中心搜索「工具集合导入预览」。选择并确认共享一份不超过 128 KiB 的 ZiDevTools 版本 1 JSON 导出。工具检查集合名称、重复和成员格式，保持集合与成员的导出顺序。未知工具 ID 作为文本保留。它们的实际可用情况由目标工具中心决定。

如需模拟与现有名称冲突，在「比较名称」填一个字符串 JSON 数组。原生冲突算法会按顺序建议「（导入 n）」并适配 40 字名称限制。导入集合与显式比较名称合计最多 128 项，每组最多 512 个成员，每个成员 ID 最多 512 字节。比较仅使用此处填写的名称。

「起始集合序号」查看从该序号起的最多 16 组。首组的 ID 可单独填写「工具起始序号」继续查看，结果会给出下一页要填的序号。一页最多 16 项工具 ID，具体长度取决于 JSON 转义后的大小。选中最后一项可以直接读回它，空组会显示为空。

导入预览是只读操作。保存、集合编辑和工作区迁移由独立版各自处理，独立版文件上限仍为 1 MiB。
