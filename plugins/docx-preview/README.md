# DOCX 正文分块预览

在 Studio 插件管理启用 `com.zicode.devtools.docx-preview`。到工具中心打开「DOCX 正文分块预览」，明确选择并确认提供一份 DOCX，再点击执行。

只读取该 ZIP 容器的 `word/document.xml`。文件及解压后的正文 XML 均限 128 KiB，归档最多 256 个条目。按提供方原生规则保留段落编号、每块最多 800 字、100 字重叠和每块 SHA-256。报告列出正文段落数、完整分块数，最多显示 8 块和 6 KiB 文本。省略的块会标明截断。

正文处理不读取宏、外链关系、媒体或其它 ZIP 条目，不在磁盘解包。源文件只读。当前范围为现有原生读取得到的正文与表格段落，其余文档格式、OCR、知识源管理、索引、全文检索和保存仍按原范围跟踪。

验收使用独立生成的标准 DOCX，在 Windows 原生适配器和生产 Worker 比对结果。候选未签名，Studio 安装及文件授权另有回执。
