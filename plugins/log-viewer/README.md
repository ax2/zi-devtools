# 本机日志筛选

在 Studio 插件管理安装并审核 `com.zicode.devtools.log-viewer` 后，从工具中心搜索「本机日志筛选」。明确确认一份 UTF-8 日志文件，按需选择级别或填写区分大小写的搜索词，再点击执行。缩进、空行与 Java 堆栈续行沿用独立版的事件判定。结果报告总事件数、匹配数与前 12 条匹配，单条正文最多 512 个 UTF-8 字节，分别标明报告与正文截断。

此候选只接受最多 16 KiB 的单文件快照以及最多 256 字节的搜索词。读取 `.log`、`.out` 和 `.txt` 均需用户确认，二进制或非 UTF-8 文本会失败。工具无需联网，原件不会被更改。大日志流式索引、重新定位时间、轮转和分页属于独立版继续跟踪的范围。

候选的本机原生适配器与生产 Windows Worker 固定向量由 `scripts/verify_log_viewer_plugin.py` 验证。候选未签名，Studio 安装与文件确认另行记录。

## 查看更大日志的末尾

在工具中心搜索「本机日志末尾查看」。Studio 仍会接收整份已确认快照，单文件上限为 32 MiB。插件只读取末尾至多 16 KiB 和至多一个边界字节。报告显示文件总长度、窗口起点、实际分析的半开字节范围、跳过的首部字节及末尾是否有换行。匹配数和事件编号只相对于本次分析范围。

从完整物理行起始，跳过属于窗口前事件的续行。首部窗口从 UTF-8 码点中截入时，仅跳过已裁掉的那一行。末尾如仅缺少 UTF-8 码点的剩余字节，报告裁切的确切字节数。剩余正文中的无效 UTF-8 会明确失败。最后的正常未换行行可显示，并标明没有换行。

原「本机日志筛选」保持 16 KiB 单文件完整分析。末尾查看不联网，不能修改文件，也不会继续读取变动中的日志或自动跟随轮转。
