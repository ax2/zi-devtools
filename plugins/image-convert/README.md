# 保持原尺寸转换图片

在 Studio 工具中心搜索「保持原尺寸转换图片」，选择并明确确认一张静态 PNG、JPEG 或 WebP。选择目标格式后手动执行，生成保持原始像素宽高的派生图片。预览后可使用 Studio 的确认保存，输出文件按目标格式使用 .png、.jpg 或 .webp。原文件保持。

现用独立版共享编码。PNG 和 WebP 使用无损编码，JPEG 质量 35–95（省略为 85），JPEG 不保留透明度。尺寸范围为每边 1–12,000 像素、总计不超过 16,000,000 像素。输入和输出各最多 32 MiB，沿用原有单图执行额度。动画 PNG/WebP 会明确拒绝。

工具只读本次确认的图片快照，唯一权限为 resource.read。此范围提供原尺寸重编码与单图另存。拍摄元数据保留、图片编辑、批量、剪贴板及工作实例由其他原生入口处理。
