# ZiDevTools Agent 运行记录检查

在 Studio 工具中心搜索「Agent 运行记录检查」。选择并确认共享一份 ZiDevTools 导出的 UTF-8 JSON 记录，再执行检查。支持 schema v1–v5，每份最多 64 KiB。工具只读取已确认的文件快照。

报告包含结束时间、状态、批准标志、工具调用顺序和耗时、响应字节、记录中的模型用量、来源和引用数量。步骤中的工具按导出记录的白名单序号显示。模型名、工具名、任务、计划、答案、错误正文、来源路径及运行环境字段均不返回。

检查结果说明原生规则是否认可记录结构，包括 v5 的指纹字段一致性。它无法认证记录作者，也无法验证记录中的行动和事实。检查离线运行。目录浏览、跨记录比较与展示原文仍由独立版提供。
