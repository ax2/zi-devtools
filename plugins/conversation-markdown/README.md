# 会话文件转 Markdown

在 Studio 工具中心搜索「会话文件转 Markdown」，选择独立版导出的会话 JSON 并确认共享。手动运行后查看完整问答的轮数和输出大小，确认保存新的 Markdown 文件。原 JSON 保持原样。

接受 `zi-devtools-conversation` 版本 1，仅包含按顺序排列的 1–16 轮完整问答。输入最多 64 KiB，包括可选 UTF-8 BOM，JSON 转义最多 12,288 个，输出最多 192 KiB。每条原文放入完整的纯文本围栏，保留 Unicode、原始反引号、HTML、Markdown 标记和内嵌换行的文本值。

这个入口读取当前确认的文件并生成新产物。实时对话、历史资料库恢复、模型配置、附件内容及更大文件继续使用独立版原生工作流。
