# 提取 PDF 单页文本

在 Studio 插件管理审核并启用 `com.zicode.devtools.pdf-text`。从工具中心搜索「提取 PDF 单页文本」，明确选择并确认提供一份本机 PDF，填写从 1 开始的页码，再执行。

单文件最多 128 KiB，最多 32 页。预览只包含所选页的嵌入文本，每次最多 6 KiB，并标记截断。返回报告区分有文本、空白、有直绘图像但无可提取文字，以及其它无可提取文字的页面。拒绝加密及无法解析的 PDF。源文件只读。

这项候选沿用 ZiDevTools 原生文档解析的本机 PDF 库。文字顺序和字体映射仍受文件结构及解析器限制。部分复杂字体、表单和嵌入页面可能没有可提取正文。这里未接入扫描件 OCR、全文检索、批量转换、另存及云端服务。

验收入口为 `scripts/verify_pdf_text_plugin.py`。使用标准合成 PDF，通过原生适配器和生产 Windows Worker 比较相同结果。此候选未签名，Studio 安装与确认文件操作另行核对。
