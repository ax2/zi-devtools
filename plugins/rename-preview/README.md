# ZiDevTools 批量改名预览

在 Studio 工具中心搜索「批量改名预览」。切到「文件夹」，选择当前文件位置内的文件夹，确认共享名称后填写查找替换、前缀或后缀，再执行预览。规则只修改文件名主体，保留最后一段扩展名。没有填写规则时显示未变化。

结果列出原名、候选名以及未变化、仅大小写变化、多个原名指向同一目标、目标已占用或无效名称。目标占用检查包含同层文件夹。检查只基于提供的完整名称快照，并可能受拍摄后发生的目录变化影响。

一次接收 64 KiB 以内的一层目录快照，最多 64 项。原名称合计最多 12 KiB，候选目标名称合计最多 16 KiB，单项规则最多 128 个 UTF-8 字节，报告最多 48 KiB。超限会停止并显示原因。工具只根据名称和类型生成预览，文件内容、实际改名和撤销继续使用独立版入口。

清单声明 `resource.read` 和 `resource.directory.read`。候选包无签名，目录摘要及 Windows 生产 Worker 对照结果随包提供。
