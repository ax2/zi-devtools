# Python / Django 环境报告查看

在 ZiDevTools 独立版「Python / Django 环境」保存 JSON，回到 Studio 工具中心打开「Python / Django 环境报告查看」。选择并确认一份本机报告，可查看文件中记录的一套或两套解释器、虚拟环境状态、Django 分发版本、模块来源是否有记录，以及采集时 django-admin 入口位置的比较结果。分发版本和模块来源可分别出现。预览后可明确确认保存 UTF-8 TXT。

每次只读一份不超过 32 KiB 的原生导出。结果省略解释器、环境、模块及脚本路径，以及原始备注和运行环境指纹。插件校验报告结构与指纹格式，摘要反映历史快照。「未记录差异」沿用原报告标记，预期脚本位置是采集时推算的路径。当前解释器与 PATH 探测、运行 Python 或 Django、查验项目配置仍由独立版提供。两个环境的依赖兼容性需要另行判断。
