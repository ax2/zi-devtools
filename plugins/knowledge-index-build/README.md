# 从文本创建静态知识索引

在 Studio 工具中心打开「从文本创建静态知识索引」。选择并确认一份本机 UTF-8 TXT，填写一个引用名称（如「会议纪要.txt」），然后手动执行。工具创建独立的 ZiDevTools v1 SQLite 索引。原 TXT 保持原样，确定保存位置后可另外保存新文件。

输入最多 4 KiB，包括可选 UTF-8 BOM。沿用原生段落与分块方式。分块后合计正文最多 4 KiB、32 个片段，SQLite 文件最多 128 KiB。引用名称最多 128 UTF-8 字节，使用单个 TXT 名称；来源固定为 `studio-snapshot`，不记录本机路径或采集时钟。

保存后打开「本机知识索引关键词检索」，重新选择该 SQLite 文件并确认分享，即可执行 FTS5 BM25 或中文自动字面检索。目录扫描、增量更新、日常索引、打开原文和 OCR 继续使用独立版原生流程。
