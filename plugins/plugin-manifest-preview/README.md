# ZiDevTools 插件清单预览

在 Studio 工具中心搜索「ZiDevTools 插件清单预览」。选择并确认共享一份 ZiDevTools 独立版声明式 JSON 清单。运行后核对插件 ID、名称、版本、原文件的 SHA-256、工具数量和类型。按清单顺序每次显示最多八项。结果会提示下页起始序号，填入该字段即可继续查看，最多 64 项都可以访问。

此工具复用 ZiDevTools 独立版 `schema_version: 1` 的清单校验，覆盖工具 ID、版本历史、内置操作和 HTTP 适配器声明。HTTP 适配器只显示声明的请求方法，正文、样例、模型、地址、参数及原始错误细节不会回显。遇到重复 JSON 键、未知类型或不合规格的声明会明确拒绝。本工具检查原字节并保持原文件，在 Studio 中不安装或启用源清单，也不发起服务请求或校验签名信任关系。

输入文件最多 256 KiB。支持普通和带外围空白的清单，附有密集键、转义、内部空白或超长地址的清单可能提前拒绝。去除 JSON 外围标准空白后，文档字节数加每个对象字段 128 字节不得超过 288 KiB。引号外内容最多 32 KiB，按量计入的结构与转义最多 4096，单个 HTTP 声明地址最长 2048 字节。限制适用于本地预览，独立版原有安装及更新流程保持其原范围。
