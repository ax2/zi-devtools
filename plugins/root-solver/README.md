# ZiDevTools 非线性方程求根

在 Studio 工具中心搜索「非线性方程求根」或「区间二分」。输入实函数，例如 x^2-2，及一对递增的有限端点，例如 1 和 2。端点的绝对值最多 1e12。函数在区间内应连续，端点值应异号。如果端点值为零，会直接返回该端点。

区间宽度容差可设为 1e-12 到 1e-2，默认 1e-10。最多迭代 1–200 次，默认 100 次。三角函数默认使用弧度，也可切换到角度。可在本次请求显式提供常量，例如 {"scale":"3/2","shift":0.75}。字符串常量使用精确数值，JSON 数字使用浮点近似。

报告显示候选 x、该点残差和实际迭代次数。区间收敛只反映区间宽度、达到浮点分辨率，或求得零残差。算法不检测连续性，无法枚举全部根，偶重根也可能无法夹住。遇到极点时请结合函数定义域和残差判断。若用尽迭代次数，报告保留尚未收敛的状态。

公式最多 2048 UTF-8 字节、512 个词元、64 层。很长的公式与很宽的区间叠加时，工具可能提示执行预算不足。可收窄区间、放宽容差或简化公式后再试。计算离线运行，无需权限。输入及常量属于本次请求。独立版的变量会话、已保存工作表和收敛值接力仍在独立版处理。
