# ZiDevTools 公式计算器

在 Studio 工具中心搜索「公式计算器」或「表达式计算」。输入一个公式，例如 1/3+1/6、comb(52,5)、sin(pi/6) 或 5 km -> m。复用独立版的运算符、固定有符号 128 位位运算，以及长度、质量、时间、存储和温度单位。公式限 2048 UTF-8 字节、512 个词元和 64 层，单个函数最多 64 个参数。

精确计算使用受 i128 范围约束的有理数。精确结果及中间值溢出会提示错误。科学函数、复数等结果用有限的 f64 近似，三角函数默认按弧度，可切换角度。排列组合由 fact、perm、comb、gcd 和 lcm 计算，函数沿用原生整数、范围及溢出规则。

可为本次公式传入最多 64 个常量，例如 {"x":"3/2","offset":0.75}。字符串用于精确数，JSON 数字用于浮点近似。返回方便复制的文本和保留精度的结构化值。使用公式不会写变量、ans、历史或工作表。计算离线，无需权限。
