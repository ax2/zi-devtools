# Report export profile proposal

Proposed profile: `result.resource.create.v1@1.0.0-preview.1`.

Spring Actuator plugin 0.1.1 does not export JSON. It does not receive or write a local filesystem path. The HTTP Host result capture is a separate read-only workbench attachment and does not imply that the plugin can add `generatedBy` provenance or initiate an export.

This profile proposal gives a View a preview/commit flow owned by Studio. View `prepare` submits only allow-listed endpoint facts (`endpoint`, HTTP status, response byte length, and generic field count). It does not send report content, plugin identity/version, app version, generated timestamp or fingerprint. The Host binds every fact to an HTTP result captured for the same verified plugin/runtime session, rejects missing or ambiguous captures, duplicate endpoint IDs and mismatched values, and permits only successful 2xx or health 503 records. It then generates the report, derives endpoint count and health status, stamps `generatedAt`, derives the app version and verified source tool/plugin versions, and computes the canonical portable runtime fingerprint itself. It returns only an opaque draft ID and sanitized display summary and persists nothing. Studio shows the exact report/size and asks the user. `commit` requires `confirmed: true`; Studio stores the resource in its own resource system and reports saved status without exposing an internal `resultRef` to the View. The View may not supply a path, URI, filename path, generated report metadata, token, permission grant or provenance claim. Decline, cancel, revocation, expiry, or validation failure leave no saved resource. The Host never overwrites an existing artifact; conflict handling selects a new opaque identity or asks for a new preview. Saving/exporting from the user's machine remains a separate Studio action and confirmation.

`privacy-filter.md` defines the report allow-list. It contains endpoint, HTTP status, byte count, generic field count, and health status only; it excludes origin, response bodies/values, metric names/values, environment/configuration values, credentials, DNS addresses, Host errors' raw messages and local paths. The runtime fingerprint hashes portable fields only. The Host rejects duplicate endpoint IDs, requires `summary.endpointCount == checks.length`, and derives `healthStatus` from the unique health check; caller-supplied or mismatched fields are impossible because the View cannot submit report metadata. `vectors.json` includes preview/decline, commit, permission revoke, collision, interrupted/replayed commit and privacy cases; `conformance-vectors.json` contains the executable input/report cross-field vectors and negative cases.

The profile is not declared in `plugin.json`; no export action is shipped until Studio publishes and verifies it.
