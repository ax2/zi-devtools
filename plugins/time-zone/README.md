# 时区工作台

在 Studio 工具中心搜索「时区工作台」。填写来源的本地时间
`YYYY-MM-DD HH:MM[:SS]`、IANA 名称和 1 至 8 个不同的目的时区。
在目的时区字段填有序 JSON 数组，如 `["Asia/Shanghai","Europe/London"]`。
运行后可核对共同的 UTC 时刻，以及每个目的地的本地时间、偏移和缩写。

同一个本地时间可能对应两个 UTC 时刻。遇到这种情况，工具会显示较早和较晚的候选及各自偏移。
请按需要选择 `earlier` 或 `later` 后再运行。若当地时间因规则变化而不存在，
工具会显示变更前后最近的有效分钟，保留原输入供修改。转换使用独立版同一版本的离线
IANA 2025b 时区表，支持半小时、四分之三小时偏移和跨日期。

这个入口使用通用 Studio 表单与结果。独立版原生逐个添加和移除时区、即时重复/缺失提示及逐行复制仍用原有界面。
