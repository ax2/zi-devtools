# 时区工作台

安装并启用此包后，从 Studio 工具中心搜索「时区工作台」并打开。填写来源本地时间
`YYYY-MM-DD HH:MM[:SS]`，搜索并选定来源 IANA 时区，然后按需要添加 1 至 8 个不同的目的地。
搜索支持 IANA 名称和部分常用城市的中文名。列表按选择顺序换算，可随时移除目的时区。

每行展示目的地、当地时间、UTC 偏移和缩写。点击「复制」可复制这一行；浏览器限制写入时，
工具会选中该行文本，按 `Ctrl+C` 复制。键盘可用方向键浏览搜索结果，按 `Enter` 选择，按
`Escape` 收起未提交的搜索。

来源当地时间出现两次时，界面列出较早和较晚的两个 UTC 候选。选中一个再执行换算；当地时间
不存在时，界面显示附近有效分钟，保留原输入。换算使用与独立版相同的离线 IANA 2025b 规则。
运行期间可取消，输入发生变化时会忽略旧请求的返回结果。

原 `devtools.time-zone.convert` 结构化能力继续可从「IANA 时间换算」使用。它仍接受来源时间、
来源 IANA 名称及有序目的地数组，可通过 `ambiguousChoice` 选择重复时刻。时区 View 和换算均不
读取文件、联网或调用模型。已有用户通过修改当前 View 的会话输入产生的未保存提示保持有效。

目录快照由同一个锁定依赖生成。更新 IANA 版本时，先在 Provider 运行
`cargo run --locked -p zi-time-zone-core --example export_zone_names`，将其标准输出更新到
`zones.txt`，同时更新换算引擎、版本标记与固定用例。
