# ZiDevTools 本机 HTML 正文预览

在 Studio 工具中心搜索「本机 HTML 正文预览」，选择一份 .html 或 .htm 并确认共享，再运行。工具读取本次确认的 UTF-8 文件快照，显示标题、正文文本和省略提示。单份文件最多 16 KiB，正文摘录最多 6 KiB，保持完整 UTF-8 字符。

原生提取规则读取 main、article 或 body，跳过脚本、样式、模板、导航、页头、页尾及侧栏内容。结果为可复制文本。工具离线处理，CSS 隐藏规则、动态正文和原始视觉布局不属于静态解析范围。

结构复杂时会提示拆分文件。预检上限为 256 个小于号、512 个与号及每段 128 个、每份 768 个潜在属性分隔记号。属性分隔记号由预检保守计数，完整 HTML 由共享解析器处理。

独立版另提供粘贴、公开 HTTPS、2 MiB 本机文件、文本接力，以及知识源保存、去重与扫描。该候选只提供离线预览。
