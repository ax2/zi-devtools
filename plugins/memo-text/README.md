# ZiDevTools 备忘导入预览

在 Studio 工具中心搜索「备忘导入预览」。选择并确认共享一份 Markdown 或 UTF-8 文本。可填写最多 120 字的标题，留空时使用「导入的备忘」。Studio 的 Worker 使用已获授权的文件快照，标题来自表单。

工具用独立版批量备忘导入的文本规则校验整个文件。正文最多 128 KiB，容许开头有一个 3 字节 UTF-8 BOM。错误编码、正文中的 NUL 或超限会明确提示。正文最多显示前 6 KiB，并按 UTF-8 字符边界截取，显示准确的已显示和全文字节数。Markdown、换行、制表和空格均作为原样文本保留。备忘导入预览只读取已确认的快照。

独立版同时支持批量预览和事务提交、从文件名建议标题、导出、标签和知识接力。本候选的结果作为可复制的预览。
