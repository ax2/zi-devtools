# ZiDevTools ICS 重复截止预览

在 Studio 工具中心搜索「ICS 重复截止预览」。选择并确认共享一份 UTF-8 ICS 后运行。工具使用独立版日程算法计算一次有限重复的最后开始日期。首个 DTSTART 算在 COUNT 内，末次开始也计入重复。

COUNT 大于 1 时，可将原 RRULE 的 COUNT 替换为结果中的 UNTIL，其他条件保留。全天结果用日期，浮动结果保留同一个整分钟钟点。COUNT 等于 1 时使用单次日程，结果无 UNTIL。改写需要用户在原日历操作。

支持独立版已有的每天、每周、每月和每年规则及已支持的欠日处理。日期范围为 1901–2099。每份最多 16 KiB、512 个物理行，且有且只有一个日程。含 UTC、TZID、时区定义、例外、多条规则或其他限制条件的日程请在原日历检查。预览不导入、改写或安排提醒。

规范依据见 [RFC 5545，§3.3.10](https://www.rfc-editor.org/rfc/rfc5545.html#section-3.3.10)。
