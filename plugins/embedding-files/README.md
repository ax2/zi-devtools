# 离线向量比较

在 Studio 插件管理启用候选并授予 `resource.read`，再在工具中心搜索「离线向量比较」。可以选择并确认以下输入之一。

- 两份 JSON 数值数组。可使用 ZiDevTools 独立版「复制完整向量 A/B」生成的内容，每份分别保存为 `.json`。列表第一份是 A，第二份是 B。
- 一份已有的本机嵌入响应 JSON。`embeddings` 必须恰有两个向量，沿用同一顺序。

运行后查看维度、两份向量范数、余弦相似度和欧氏距离。结果不包含向量、模型名称或其余响应字段。两条向量应来自同一模型和版本，数组文件本身不含这些信息。此工具只读当前确认的输入，保留原件，完全离线进行比较。

两份向量需等维、非零，分量绝对值不超过 1,000,000。每份文件最多 256 KiB，向量最多 8192 维。Windows 已验证 8192 维整数、4096 维长小数、256 KiB 外围空白及明确超限拒绝。复杂度限制按去除外部 JSON 空白后的字节数，加每个小数点或指数标记 24 字节，合计最多 352 KiB。小数点和指数标记最多 10,000 个，逗号最多 16,416 个。响应中的额外字段也计入预算。模型运行、向量生成和访问本机 Ollama 仍在原工具的范围内。
