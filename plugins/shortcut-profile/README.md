# 比较并合并快捷配置

在支持快捷配置专用执行档案的 Studio 中，安装验证过的候选目录并启用，
然后从工具中心搜索「比较并合并快捷配置」。选择独立版导出的两份快捷配置 JSON 并确认共享。
填写列表中哪一份是导入文件，默认第二份。选择合并以保留基准配置没有同名覆盖的条目，
或选择替换以预览仅有导入条目的配置。

结果显示新增、改动、移除和冲突计数及有限示例。预览按配置中保存的自定义键序列和固定搜索键
`K` 检查重复及前缀冲突。冲突为空时可预览并确认保存新的 `result.json`，再用独立版的
现有流程导入为草稿。两个原件和运行中的快捷键设置保持原样。独立版还会结合当前设备工具、
默认序列和已启用插件检查导入草稿。

输入为便携格式 v1。每份最多 16 KiB、32 条绑定。合并结果至多 64 条；生成结果最多
48 KiB。保留空序列显式禁用、暂停使用的插件命令和旧录制命令。错误或冲突不生成文件。
跨应用热键、当前默认配置、应用生效和较大快照继续由独立版处理。
