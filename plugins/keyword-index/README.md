# 本机知识索引关键词检索

在 Studio 工具中心确认共享一份 ZiDevTools v1 SQLite 知识索引静态副本，输入关键词再运行。支持自动、字面短语、全部词和任一词。自动模式遇到 CJK 表意文字时走字面检索，词项模式使用独立版相同的 SQLite FTS5 与 BM25。可选填来源 ID，一次显示 1–10 项。结果提供引用、片段和索引记录的摘要，可预览并确认另存 TXT。

只接受 4 KiB 页、UTF-8、无需 WAL 或其他伴随文件的 v1 SQLite 静态副本。每份最多 128 KiB、32 个片段、正文合计 4 KiB。关键词最多 120 字符、512 字节；字面检索最多 12 个词，FTS5 最多 4 个词项并支持字母、数字与 ASCII 标点。使用 FTS5 时，正文 UTF-8 字节数乘查询词项数上限为 12,288。应先在独立版手动创建小索引并取得完整静态副本。结果标注为历史快照，路径作为文本引用。打开原文、实时索引、写入与同步、向量及模型能力继续使用独立版原生流程。

只读源文件，SQLite 在单次调用的独立内存中执行；使用确切的原生 v1 架构、固定绑定查询、禁动态扩展与额外数据库。对 FTS5 文档尺寸、普通内容和索引一致性校验后再查询，工作内存与执行期限沿用 Studio Worker 限制。Windows 本机构建复用提供方既有 SQLite/编译器固定版本。
