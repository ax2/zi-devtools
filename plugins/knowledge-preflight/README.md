# ZiDevTools 知识源文件预检

在 Studio 工具中心搜索「知识源文件预检」。切到「文件夹」，确认共享当前文件位置内一个目录的一层名称与类型，然后执行。报告按原生知识源规则列出可能纳入的 Markdown、TXT、HTML、PDF、DOCX 和图片文件，另计默认或自定义排除、不支持格式及未扫描的子目录。

支持原生排除语法。输入最多 8 条规则，合计 960 个 UTF-8 字节，以逗号、分号或换行分隔。可用 `*.扩展名`、相对文件名或目录名。预检只查看一层，深层规则留待完整扫描。

目录快照最多 64 KiB、64 项，名称合计最多 12 KiB。候选列表最多显示 24 个文件名，分类计数覆盖快照全部名称，结果最多 24 KiB。文件大小、完整性、正文、图片像素、版本指纹和索引属于后续的独立版知识源流程。

插件只读取确认的名称快照，清单使用 `resource.read` 与 `resource.directory.read`。候选包无签名，目录摘要与 Windows 生产 Worker 固定向量对照随包提供。
