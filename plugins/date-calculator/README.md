# ZiDevTools 日期与工作日

在 Studio 工具中心搜索「日期差」「日期加减」「工作日计数」或「工作日加减」。输入 YYYY-MM-DD 的公历日期。日期差返回结束日减开始日的带符号天数。

日期加减接受按天、月或年的整数偏移。遇到目标月份没有对应日期时，可明确选择「截到月末」。工作日计数只计周一至周五，包含结束日，可选择是否包含开始日。工作日加减支持正向、反向和零偏移。工作日规则不含节假日和调休。

范围为公历 0001–9999 年，偏移量绝对值不得超过 4,000,000。每次只做离线计算，插件清单无需权限。表达式、矩阵、非线性求根、工作表和日程接力继续使用独立版入口。
