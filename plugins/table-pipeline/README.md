# 运行表格管线并保存 CSV

在 Studio 工具中心打开「运行表格管线并保存 CSV」。选取一份独立版表格管线配方 JSON 和一份 UTF-8 CSV、TSV 或 JSON 表格。根据文件列表填写配方位置 1 或 2，留空用第 1 项。指定表格格式，确认共享两份文件并手动运行。结果可确认保存到新的 Studio CSV 产物，原配方和表格保持原样。

插件沿用原生格式 1–3、列变换、选列、筛选、最多四列的稳定排序和保留首条去重。启用原生 CSV 文本公式保护。接受无输出设置或开启公式保护的 CSV 设置。使用了 SQLite 或关闭公式保护的配方须先重新保存设置。

配方和表格分别最多 16 KiB，表格最多 96 行、16 列，支持最多 32 步的小表配方。每一步按中间表体积、单元格数量、排序键和 Unicode 大小写转换累计计入 128 KiB 等效工作量，超限可拆分表格或配方。中间表按 JSON 单元格和表头计最多 16 KiB，CSV 最多 32 KiB。独立版的流程创建、单步检查、应用/撤销、多实例、大表和 SQLite 输出在原工作台使用。
