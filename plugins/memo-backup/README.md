# 备忘备份提取 Markdown

在 Studio 工具中心打开「备忘备份提取 Markdown」，选择并确认一份 ZiDevTools 的版本 1 备忘与日程 JSON 备份。先留空执行，查看可提取的普通备忘标题和原序号。填入所需序号，再次执行即可得到一份 Markdown 结果。用户可预览，并用 Studio 的另存确认保存为新 .md 文件。

工具共用独立版的备份版本、普通记录、日期和标签规则。每份备份最多 128 KiB 和 64 条记录。回收站和日程不会列为可提取项。工具按原始备份顺序编号，可能存在间隔。导出的正文逐字节保持 UTF-8 内容，包括空正文、原换行和尾随空白，标题用于核对选择。

唯一权限是 resource.read，读取用户本次确认的文件快照。Markdown 作为 Host 的派生产物，另存由用户单独确认。原始备份保持。备份合并、恢复资料库、校验日程规则、还原提醒和超过边界的备份继续用独立版处理。
