# 时钟备份检查

在 Studio 工具中心搜索「时钟备份检查」。选择独立版时钟工作台保存设置中列出的 `clock.json`、
它的副本或旧格式校验备份。确认共享这一次选择的文件后，手动运行检查。
结果显示保存时间、文件版本、计时器、闹钟、秒表分段、提醒、世界时区和小窗尺寸的数量，
以及声效设置是否存入文件和备份记录的倒计时恢复方式。报告省略自定义名称、提醒标题和本机路径。

支持 v1、v2、v3。文件最多 512 KiB。为匹配 Studio 的现有运行额度，JSON 结构另有
224 KiB 加权上限。主体每字节计 1，反斜杠额外计 6，外围 JSON 空白每 4 字节计 1（向上取整）。
极密集的 Unicode、JSON 转义或附加空白可能达到结构上限，可在独立版使用原生检查和恢复预览。
Studio 的检查只报告所选备份结构。实际恢复、闹钟、声音、小窗和定时由独立版管理。
