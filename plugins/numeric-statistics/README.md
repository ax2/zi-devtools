# ZiDevTools 数值统计

在 Studio 工具中心搜索数值总和、算术均值、中位数、总体方差、样本方差、总体标准差或样本标准差。粘贴 1–64 个实数，以半角逗号、Tab 或换行分隔。单个值最多 96 UTF-8 字节，粘贴内容最多 4096 UTF-8 字节。支持电子表格最后一个换行。空值不跳过。总体方差和标准差可用一个值，样本方差和标准差至少需要两个值。

默认使用受 i128 范围约束的精确有理数，接受整数、十进制小数、科学计数法和整数分数。可选择有限 f64 的浮点近似，结果标记为近似。标准差的平方根始终为近似值。结果同时提供可复制文本和完整结构化值。

计算完全离线，无文件与网络权限。独立版保留排列组合、变量、图表和工作表等用法。
