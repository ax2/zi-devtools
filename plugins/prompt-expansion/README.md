# ZiDevTools 提示词模板工具

在 Studio 工具中心打开「提示词变量检查」或「提示词模板展开」。变量检查列出模板正文中已去重、排序的变量名。展开时可输入一个仅含字符串值的 JSON 对象，例如 {"project":"桌面应用"}。同名占位符共用一个值，必需但缺失或为空白的值会提示填写。

沿用原生格式。{{project}} 是变量，{{{{project}}}} 产生字面 {{project}}。变量名以英文字母或下划线开头，最多 32 字，其余可用英文字母、数字和下划线。正文允许中文和 Emoji。展开只处理模板中原有的占位符，插入值与正文中的有效空白原样保留。

模板正文最多 16 KiB 和 12 个不同变量，整个序列化请求及响应各最多 48 KiB。完整展开最多 128 KiB。结果正文最多预览 16 KiB，JSON 转义较多时会按响应字节上限再缩短。有截取时会明确显示正文的已显示字节与总字节数，字符保持完整。

两个工具只做离线检查和预览。模板命名、修订、标签、正文接力及模型参数处理由独立版提供。
