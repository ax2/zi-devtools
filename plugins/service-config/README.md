# 本地服务配置预检

在 Studio 工具中心搜索「本地服务配置预检」，选择 ZiDevTools 的 YAML 配置，确认提供文件后执行。工具检查单份 UTF-8 YAML/YML，支持开头 BOM 和 Windows 换行。文件最多 16 KiB，至多 64 个普通服务定义。密集字段、长列表及 YAML 别名展开按结构成本另行限制，遇到提示可分批检查。在单份文件中标点较多时，即使在注释或文本中也可能触及此限制。

预检共用 ZiDevTools 原生配置类型与导入前置规则。要求 services 非空，repo 和 command 必填且非空，已填写的 stop_command 不得为空，stop_timeout_ms 为 100–60000。支持原格式的缺省值。报告按 services 键排序并列出每项第一个问题，显示停止命令和健康检查配置数、环境变量项数及是否指定状态目录。无法解析时可显示解析器提供的行和列。报告不显示服务标识、路径、命令、健康地址或环境变量内容。

唯一权限为 resource.read。工具读取此次确认的文件快照，配置原件保持。通过预检只代表这些文件内规则成立。工作目录、端口、健康地址可用性、导入目标冲突、进程起停和日志均由独立版的原生功能处理。
