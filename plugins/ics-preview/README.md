# ICS 日程预览

在 Studio 插件管理启用 `com.zicode.devtools.ics-preview`，到工具中心打开「ICS 日程预览」。选择一份 UTF-8 的 ICS 2.0 文件，确认共享，再手动执行。

预览显示日程标题、起止时间及全天、浮动、UTC 或命名时区。保留文件中的原始日期和时区标识。全天结束是原文件给出的排除式日期。报告保留 RRULE 原文，提示存在重复例外，且 `recurrenceExpanded` 固定为 false。没有结束时间时以空值显示。

文件上限 16 KiB。按文件顺序最多显示 8 条，文字合计最多 6 KiB。标题超出 512 个 UTF-8 字节时在字符边界截断，并单独标明。实际事件数、重复事件数与预览的截断状态均随报告显示。

只读预览无需联网，也不会导入日程、换算时区、展开重复、响应邀请、创建提醒或写入原文件。源工具原有的日程编辑、冲突处理、同步、导出和时区/重复变换继续按原范围跟踪。

`scripts/verify_ics_preview_plugin.py` 使用合成日历对照 Windows 原生适配器和生产 Worker。候选未签名，Studio 安装和逐次文件授权另有回执。
