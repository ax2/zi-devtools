# 检索评测报告复核

在 Studio 工具中心搜索「检索评测报告复核」，选择一份 ZiDevTools 导出的 JSON 文件，确认提供该文件后执行。单份文件最多 64 KiB，最多 10 题，Top K 支持 3、5、8。结果以报告中的题序号标识。

- 仅检索报告 `zi-devtools-rag-eval` v2 按证据顺序复核首个命中预期来源及相对路径的名次。失败与未命中题的倒数排名为零，MRR 的分母为全部已完成题。复核会标明记录名次及汇总计数的差异，MRR 由复核工具根据记录推导。
- 双路报告 `zi-devtools-rag-compare` v1 从每题记录的两路排名复算关键词和混合检索的命中、四类对比计数和 MRR。任一路失败则整题不进入配对统计。该格式只有记录名次，无法从原始证据再排出名次。无可用分母时显示破折号。
- 报告来自取消后的部分运行时，仅分析已完成的题并显示总题数。输出只含统计数值、题序号、状态和差异，不显示题目、检索词、来源名称、相对路径、模型名和错误原文。

使用唯一的 `resource.read` 权限读取本次确认的单文件快照。报告内容由导出文件提供，用于内部一致性复核；其数据是否来自真实索引需另行核对。数据集编写、本机索引评测、模型回答和离线文件导出的原生流程仍由独立版提供。
