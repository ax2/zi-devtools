# ZiDevTools 文本流程配方检查

在 Studio 工具中心搜索「文本流程配方检查」。选择并确认一份本机配方 JSON，再执行检查。可使用 ZiDevTools 原生「流程配方」功能生成的文件。

检查支持配方格式 1 至 4，单文件上限 64 KiB、最多 16 步。执行检查后显示配方版本、起始/输出材料类型、每步的动作、版本和影响。文件 SHA-256 动作的副输出也会列出。预览文件或图片动作时，检查只读取配方本身。清单仅要求 `resource.read`。

未注册的动作、未知版本、材料类型不匹配或附带文件路径的配方会被拒绝。独立版的运行、编辑、保存、命名实例、配方库和结果接力仍在原入口使用。

候选包无签名。提供方附原生适配器与 Windows 生产 Worker 的固定向量对照结果。Studio 对冻结包的安装、启用、撤销授权和工具中心执行分别验收。
