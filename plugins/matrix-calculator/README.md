# ZiDevTools 矩阵计算

在 Studio 工具中心搜索矩阵加法、矩阵减法、矩阵乘法、矩阵转置、矩阵行列式、逆矩阵或矩阵方程求解。将表格粘贴到矩阵 A 和 B 输入框，列用 Tab 分隔，行用换行分隔。每个矩阵最多 8 行和 8 列、4096 UTF-8 字节，每个单元格最多 96 UTF-8 字节。逆矩阵和求解 AX=B 要求 A 可逆，B 可以有多列。

默认使用有理数精确计算，接受整数、十进制小数、科学计数法和整数分数，例如 1/3；也可输入 0x、0b 或 0o 开头的进制整数。分子、分母和计算中间结果受 128 位有符号整数范围约束。近似模式接受有限的 64 位浮点小数或科学计数法，结果标记为近似。近似模式下，病态矩阵可能损失精度。结果包含便于复制的文本和保留完整精度的结构化数值。单次请求最多 16 KiB，单次完整结果最多 12 KiB。

七项操作均离线运行，插件清单无需权限。独立版仍提供可编辑的网格、工作表、表达式、变量、复数、矩阵统计和非线性求根。
