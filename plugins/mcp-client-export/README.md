# MCP 客户端配置预览

在 Studio 工具中心打开「MCP 配置 · Codex TOML」或「MCP 配置 · 通用 JSON」，填写已知且信任的 ZiDevTools MCP 服务程序路径，点击运行后查看或复制完整配置。可在 Studio 预览并确认保存为产物。需要文件时，将复制的内容保存为相应格式。

支持 Windows 盘符绝对路径，最多 1024 UTF-8 字节。安装版文件名为 `ZiDevToolsMcp.exe` ，便携版文件名包含版本。可填写空格、中文和单引号，配置保留原路径。Studio 根据填写的文本生成内容，程序文件的存在与来源由用户核对。

Codex TOML 保留两个知识工具及 `writes` 审批模式。通用 JSON 只提供 stdio 启动字段，信任和审批请在目标客户端确认。填写的路径会出现在输出与已确认保存的产物中。工具仅生成文本，客户端连接、程序运行和实际知识库访问均由独立应用处理。自动发现程序及 Codex CLI 命令继续由独立版提供。
